- **yq: a write keeps a `<<` merge key that names nothing to merge** (#6318).
  `- <<: *seq`, where the alias is a sequence of scalars (five CI files of one crate in a sweep of 2,057 real YAML files), came back `- {}` from any write such as `.zzkey = 1`, losing the key and its alias; so did `<<: 5`, `<<:` and `<<: hello`. The entry stays now, written plain where yq writes `!!merge <<`, which reads back the same. A merge of a mapping is still expanded by a write, as before.
