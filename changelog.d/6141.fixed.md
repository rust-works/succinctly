- **jq: `--seq --stream` goes on reading past jq's end-of-stream stop, so a later `input` still meets what follows** (#6141). The first call after the read that hit the end of the file returns nothing at an empty record, and that ends only the call that met it: `input` raises `break`, `inputs` ends there, and the main loop ends only if it is the one that pops it. The reader ended the whole stream, so `printf ',"a"nultrue}-\x1e[1]\n\x1e[]\\' | jq -c -e --seq --stream 'limit(2;inputs)'` printed `[[0]]` and exited 0 where jq also prints `Invalid numeric literal at EOF` and exits 5. Random record sequences over 16 programs (`--stream`, `--stream-errors`, `-n`, `input`, `inputs`, `-e`) went from 13 differences in 4,000 runs against jq 1.7.1 to none.
