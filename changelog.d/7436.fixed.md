- **jq: a `-f` program file, `--rawfile` or `--slurpfile` with a byte that is not valid UTF-8 is read with U+FFFD** (#7436). They were refused with `Could not open <file>: stream did not contain valid UTF-8` (exit 2), where jq 1.7.1 and 1.8.2 read them: `--rawfile x` with `a\xffb` is `"a�b"`, `--slurpfile` with `"\xff"` is `["�"]`, and a program `"\xff" | length` is `1`. `-f` and `--rawfile` are decoded a 4,096-byte read at a time, as jq's `jv_load_file` decodes them, so a sequence the end of a read cuts is replaced as jq replaces it; a program with U+FFFD outside a string or a comment is a compile error (exit 3), as in jq.
