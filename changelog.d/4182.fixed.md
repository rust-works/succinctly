- **yq: a repeated key in `{...}` deep-merges its values, as yq does** (#4182).
  yq folds the entries of an object construction with `*`, so `{"a": {"x": 1}, "a": {"y": 2}}` is `a: {x: 1, y: 2}`;
  `succinctly yq` kept the last (`a: {y: 2}`) unless the construction also held a bare entry. A literal key that
  repeats and a computed key (`{($k): .., ($k): ..}`, compared at run time) are now built as yq's `COLLECT_OBJECT`;
  anything but a map over a map still takes the later value. Distinct literal keys and every jq construction are
  unchanged.
