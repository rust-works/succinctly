- **yq: a repeated key in `{...}` deep-merges its values, as yq does** (#4182).
  yq folds the entries of an object construction with `*`, so `{"a": {"x": 1}, "a": {"y": 2}}` is `a: {x: 1, y: 2}`;
  `succinctly yq` kept the last (`a: {y: 2}`) unless the construction also held a bare entry. A literal key that
  repeats and a computed key that turns out to (`{($k): .., ($k): ..}`) now merge where the object is assembled, on
  every route; anything but a map over a map still takes the later value. A construction whose keys are distinct
  costs the same as before, and jq is unchanged.
