- **jq: `--indent` refuses a malformed value, as jq 1.8 does** (#7501). `--indent abc`, `--indent ""`, `--indent 3x`, `--indent " 2"`, `--indent 3.0` and `--indent -c` ran, reading the value with `atoi` as jq 1.7.1 does; jq 1.8 fixed that (jqlang/jq#3195) and exits 2 with `--indent takes a number between -1 and 7`, and so does `succinctly jq` now. An optional sign and ASCII digits in -1 to 7 are still accepted (`+3`, `007`, `-1` for a tab). `--indent 0` keeps jq 1.7.1's compact output.
