- **yq: `ALIAS |= (. = X)` rebinds the position, not the shared node** (#6861). `.b |= (. = {"p": 3})` over `b: *x` rewrote the anchor and every alias of it (`a`, `b`, `c` and a list element all became `{"p": 3}`); yq replaces the node at that position only, as `.b = {"p": 3}` always did here, and leaves the shared node alone. A write below the target (`.b |= (.p = 9)`) still reaches the shared node. `|=` now sends a body to the anchor only when it does not assign to its own target (`. = X`, `. |= f`, `del(.)`, `setpath([]; X)`, at the top of a pipe, group or `as` binding). A body that writes below the target and then replaces it (`.b |= (.p = 5 | . = {"p": 3})`, `del(.p) | . = X`) still writes only the position's copy, where yq's first write reaches the shared node; recorded in `docs/compliance/yq/limitations.md`.
