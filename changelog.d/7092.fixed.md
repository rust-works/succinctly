- **`yq -o=shell` keeps the base letter of an accented key** (#7092). yq decomposes a key with NFKD before it keeps `[A-Za-z0-9_]`, so `effort_expeñded` is `effort_expended`, `ﬁ` is `fi`, `…` is `___` and a fullwidth `１` is `_1`; the key was dropped whole of any non-ASCII character here (`effort_expeded`). Checked against yq v4.53.3 for every code point from U+0080 to U+10FFFF.
