- **yq: a plain assignment from a static read copies the source scalar's quoting and explicit tag, and a container's tag** (#5257). `.c = .b` on `b: "q"` printed `c: q` and on `b: !!seq [1]` printed `c: [1]`; yq prints `c: "q"` and `c: !!seq [1]`. The source's style and tag are taken when the target is new, is not a scalar, is plain with no tag, or changes type, and the target keeps its own otherwise (`c: "old"` stays double-quoted); a custom tag already on the target stays, and a flow container copied onto a scalar keeps the target's same-line comment. 459 source-by-target pairs of styles, tags and comments match yq v4.53.3, 232 of them pinned. A copy a later stage rewrites, or a target that is not a static path, is still plain, recorded in `docs/compliance/yq/limitations.md`.
