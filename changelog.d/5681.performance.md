- **jq: `--stream` with a filter that reads each event runs about 2x faster** (#5681). A `--stream` event is a `[path, leaf]` array, and the filter used to receive it as JSON text that was written out, indexed and read back for every leaf. The filter now reads the event where it is and re-indexes only the stages the owned evaluator declines. On an Apple M5 Max, over 7 MB and 35 MB of records, `-c --stream 'select(length==2 and .[0][2]=="age")|.[1]'` takes 292 ms instead of 658 ms and 1.38 s instead of 3.14 s (jq 1.7.1: 306 ms and 1.47 s, so 0.48x becomes 1.05x of jq), `select(length==2)|.[1]` 0.44x-0.49x of the old time, `.[0]|length` 0.40x-0.51x, and `select(.[1]|type=="number")|.[1]+1` 0.71x; `.` is unchanged. Output is byte-identical to the old route on 4,480 program, flag and input combinations.
