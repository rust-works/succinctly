- **jq: a `foreach` UPDATE comma with a pipe on the accumulator, or a trailing `| .`, no longer drops a path or writes where jq raises over a `null` source** (#4063, a #4059 residual). `(foreach .a as $v (null; (now, (. | .b?)); try ($v|.b?))) = 9` on `{"a":null,"z":{"b":1}}` raises `Cannot index number with string "b"` in jq (it names `["a","b"]` and `["a","b","b"]`) and was `{"a":{"b":{"b":9}},"z":{"b":1}}` here, with `path(...)` answering only `[["a","b","b"]]`; `(foreach .a as $v (.; ((1,2), ($v|.b?)) | .; try ($v|.b?))) = 9` did the same. Over a `null` source the accumulator is identical to jq's register, so the sibling `. | .b?` navigates and the neutral builtin beside it is a by-value leaf on a *trackable* entry, which stated the register lost; and a trailing `| .` made the pipe read as opaque, so the comma's per-sibling statements went unread. A bare register-neutral builtin now states the register unmoved on a trackable entry too, and a trailing `| .` forwards the statement of the stage before it. The same change lets eight refusals of the register sweep (`del(try (any(now; .a) and .a))`, ...) match jq. A seeded grid of UPDATE shapes against jq 1.7.1 fixes rows with no regression.
