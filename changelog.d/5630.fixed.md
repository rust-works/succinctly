- **yq: `+ - * / % //` fold from the right, as in yq** (#5630). yq gives the six operators one precedence and its operator stack pops only a strictly higher one, so `2 * 3 + 4` is `2 * (3 + 4)` (`14`, was `10`), `10 - 3 - 2` is `10 - (3 - 2)` (`9`, was `5`), `100 / 10 / 5` is `50` (was `2`), and `//` ties with them, so `1 // 2 == 2` is `(1 // 2) == 2`. The comparisons and the assignments are one level too (`.a = 5 == 5` is unchanged; `x == y = z` is `x == (y = z)`). Output differs from earlier releases for any yq program that mixed these operators without parentheses; `succinctly jq` keeps jq's grammar.
