- **yq: `@sh` quotes a string as yq does** (#5837). `printf 'a: hello\n' | succinctly yq '.a | @sh'` printed `'hello'`, `a b` printed `'a b'` and `it's` printed `'it'\''s'`, where yq prints `hello`, `a' b'` and `it\'s`. yq leaves a run of characters in `[A-Za-z0-9_@%+=:,./-]` bare, opens a single quote at the first character that needs one and keeps it open to the end or the next `'`, which it writes `\'`. succinctly now does the same, and refuses a non-string under `-n` in yq's `@uri` wording, as it already did for a document node. `succinctly jq`'s `@sh` is unchanged.
