- **jq: `-n -s --stream` raises a fault in the stream from `input`, as jq does** (#6005). The whole stream was read before the program ran, so a fault ended the run at exit 5 even for a program that never calls `input`. jq reads on the first `input`: `printf '1 2 }' | jq -nc --stream -s 'try input catch "E"'` prints `"E"`, `input_line_number` prints `0`, and the call after the fault returns the array of the events (`[[[],1],[[],2]]`, with the ones that follow the fault too). A fault at the end of the stream comes after the array. 8,235 stream-by-program runs over one to three files (495 hand-picked, the rest random token soup) matched `/usr/bin/jq` 1.7.1 on stdout, stderr and exit status.
