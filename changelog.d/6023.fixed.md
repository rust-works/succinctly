- **`succinctly jq` reads standard input for an input file named `-`** (#6023). `echo '{"a":1}' | jq . -` and `jq . a.json - b.json` fail with `Could not open file -` (exit 2) where jq reads stdin; the same holds for `-s`, `-R`, `--stream`, `--seq` and `-n` with `input`/`inputs`. Stdin is read once, so a second `-` is empty, `input_filename` is `"<stdin>"` for it, and an error location names `<stdin>`. `--slurpfile`, `--rawfile` and `-f` with `-` still fail, as in jq. Compared with `/usr/bin/jq` over 1,120 stdin x program x file-shape cases.
