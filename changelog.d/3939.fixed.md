- **jq: a nested `foreach` over a `null` register now answers the member it moved to in path position** (#3939, a #3853 residual). `path(foreach (foreach . as {a:$a} (0; .; .)) as $x (.; .; .))` on `null` answered `[]` where jq answers `["a"]`, so a write through it landed on the wrong node (`(foreach (foreach . as {a:$a} (0; .; .)) as $x (.; .; .)) = 9` replaced the document with `9` where jq gives `{"a":9}`). jq's `foreach` does not backtrack its source, so the pattern's or source's own index step leaves the register on the member, and `jv_identical` admits the outer EXTRACT's `null`/`true`/`false` there by kind. The nested emission stated no register and read as lost; an emission at the register the fold's step left on a `null`/boolean node now states it. The same holds for a comma source, a deeper pattern (`{a:{b:$a}}` is `["a","b"]`), an array pattern, a navigating source (`.a as $a`) and an outer UPDATE or EXTRACT that navigates from the moved register. A `true`/`false`/`null` member is the accumulator's node by kind when INIT is that literal (`path(foreach (foreach . as {a:$a} (0; .; .)) as $x (true; .; .))` on `{"a":true}` is `["a"]`). Registers that are not `null`/a boolean still refuse, and a nested `reduce` still backtracks. A `?//` pattern chain in the nested source is still read by value and answers the root (#3948).
