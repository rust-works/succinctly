- **`jq` parse-error column over invalid UTF-8** (#5964). A parse error counts its column over the bytes jq read, so `printf '\xff }'` names column 2 where `succinctly jq` named column 4: the substitution turned each invalid byte into a three-byte U+FFFD before the position was counted. The default, `-s` and `--stream` routes, a program's `input` and the main loop all count the original bytes now.
