- **compare(jq): CLI probes can set environment variables, and cover `JQ_COLORS`, `NO_COLOR` and the locale** (#5552).
  `comparison/jq/probes/cli.tsv` takes an optional fifth column, a JSON object of variables set for both tools
  (the base stays `LC_ALL=C` with no `JQ_COLORS`/`NO_COLOR`), so the colour and locale behaviour the fixed
  environment hid can be probed. 248 new probes (field forms of `JQ_COLORS`, `NO_COLOR`, colour on 40 shapes
  and flag combinations; sort, case mapping, regex classes, number text, `@uri`/`@sh`/`@csv` and
  `strftime`/`strptime` under `C.UTF-8`, `en_US`, `de_DE` and `tr_TR`, and `LC_ALL`/`LANG`/`LC_TIME`
  precedence) found 26 differences, all ledgered as `to-triage`: an over-long or empty `JQ_COLORS`, `strptime`'s
  `%B` and weekday for an unset date, and `strftime`/`strptime` ignoring the locale. Every other locale probe agrees.
