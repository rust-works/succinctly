- **jq: a `--no-default-features` build no longer keeps every `def` call's tree** (#5422).
  The #3148 retention scope is backed by a `thread_local!`, so a `no_std` build had none and kept the bound body
  of every call it evaluated for the node's lifetime: `def fib(n): if n < 2 then n else fib(n - 1) + fib(n - 2) end; fib(24)`
  held 251 MB after one evaluation (`fib(21)`: 59 MB). A `no_std` build now declines to keep a body on a node's
  first reach and keeps it from the second, so the same program holds under 2 KB and peaks at 44 KB; a loop whose
  body calls `fib(18)` five times peaks at 37 KB where it peaked at 42 MB. A node reached twice pays one more bind
  than in a `std` build, and a hot body's own calls turn hot a reach at a time. The `std` build is unchanged.
