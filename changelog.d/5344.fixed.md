- **jq: module and directive metadata is a constant expression, as in jq** (#5344). `module {a:(1+2)};` was a parse error (`invalid metadata value`) where jq answers `{"a":3,...}` from `modulemeta`; the metadata of a `module` header and of an `import`/`include` was read as an object literal of literals. It is now read as an expression and folded the way jq folds it: arithmetic and comparison over constants, `({a:1}+{b:2})`, arrays of constants, keyword, quoted and parenthesised keys, and a trailing comma are accepted; a number literal keeps its spelling (`1.50`, `100000000000000000001`, `0.1e2` as `1E+1`) instead of being rounded through a double; and a value that is not constant (`-1`, which is a call in jq, `.`, `(1,2)`, an interpolated string, a failing operator) is `Module metadata must be constant`, one that folds to anything but an object `Module metadata must be an object`, as jq says. `$__loc__` and a pipe through the identity (`(.|1)`) are still refused where jq folds them.
