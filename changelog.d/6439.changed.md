- **jq: a counted repeat of a Unicode class up to a few thousand copies compiles, where it was refused at 10 MiB** (#6439). `"a" | test("\\w{1000}")` printed `Regex failure: Compiled regex exceeds size limit of 10485760 bytes.` and jq 1.7.1 answers `false`: the `regex` crate writes a counted repeat out copy by copy, and a Unicode class is large. The size limit of the compiled program is 128 MiB now (the `fancy-regex` route takes it too), so `\w{2500}`, `\d{5000}` and `.{100000}` compile; `\w{3000}` and `\w{100000}` are still refused, which `docs/compliance/jq/limitations.md` records with the memory each costs (a refused pattern allocates up to about 460 MB before it is refused, where the 10 MiB limit stopped at 30 MB).
