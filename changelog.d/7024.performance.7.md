- **jq: `-R` over more than 32 regular files reads them a window at a time** (#7024). `jq -R . logs/*.log` over a list of more than 32 files, 4 MiB or more between them, read every file whole, since the several-files route held each file open and stopped at 32 to keep the descriptor table small. Such a list is now judged by `stat`, and each file is opened when the run reaches it and closed after its lines, as jq opens them, so the run holds one file at a time. At 100 MiB of NDJSON in 64 or 256 files peak RSS for `-R .` falls from 108.5-108.7 MiB to 11.2-12.8 on x86_64 and from 105.8-106.1 to 5.8-6.6 on aarch64, flat from 10 MiB; `-nR 'reduce inputs as $l (0; . + ($l | length))'` reads 50% to 61% faster on both, and `-R .` and `select` read within the control's range on aarch64 at 100 MiB and 6% to 22% faster on x86_64 (the unchanged 16-file route read 5% to 9% faster in the same build, so part of that is layout). A run of 25 ms over 256 files of 40 KiB reads 5% slower on aarch64 on `select`. A file that will not open when the run reaches it (removed, made a directory, or without read permission since the run started) is reported in jq's words once its reader is past it, and the run ends after the next line with exit 2, as the whole-file route reports it.
