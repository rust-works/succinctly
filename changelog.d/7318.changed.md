- **`SUCCINCTLY_SIMD=sse2` also clamps the x86_64 JSON index builders** (#7318). The variable used to lower only the YAML parser's dispatch; `succinctly jq` and the other JSON routes always built their index with the AVX2 kernel on an AVX2 CPU, so the SSE2 kernel ran through the CLI only on a CPU without AVX2. It now selects the SSE2 kernel there too (it still only lowers the level, never raises it), and the `sse2-dispatch` x86_64 CI leg re-runs the JSON-reading CLI suites with it set. No change when the variable is unset.
