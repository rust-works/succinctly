- **yq: a flag after the file name is a flag, as in yq** (#6705).
  yq reads a flag wherever it appears, so `yq '.a' f.yaml -o=json`, `yq '.a = 1' f.yaml -i`, `-r`, `-I=4`, `-N`, `-e` and `-P` after the
  file all work; `succinctly yq` declared its `files` argument with `trailing_var_arg`, which made every word after the first file a file
  and failed with `failed to read file: -o=json` (`succinctly jq` had dropped it for the same reason, #3447). Checked against yq
  v4.53.3 over 37 command lines (flags before, between and after the filter and files, several files, `-o json`, `--indent 4`,
  `--output-format json`); the four that still differ do not depend on where the flag is (`-n` with a file, `-` as a filter,
  `--unwrapScalar=false`).
