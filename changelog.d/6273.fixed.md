- **jq: a range whose start is above its end inside a character class is `empty range in char class`, as in jq** (#6273).
  `"a" | test("[z-a]")` reported the `regex` crate's own parse error (exit 5 either way); the class is now read the way Oniguruma reads it, and a descending range between two characters, control or octal escapes below 0x80 (`\n`, `\101`, `\cA`), `\x{..}` or `\xHH` bytes is jq's refusal. A class longer than 2,048 characters before the `-` is left to the crate.
