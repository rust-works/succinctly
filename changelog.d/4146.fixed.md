- **jq: an `error(msg)` whose message navigates an input the path register is not on raises jq's path error, in path position** (#4146).
  jq defines `error(msg)` as `msg | error`, so the message is path-checked and a `try` catches the path-error
  string. The message was evaluated by value, so the payload was the value it read: `path(.a? or try error(.c) catch .)`
  on `{"a":false,"c":null}` printed `["a"]` where jq exits 5 with `Invalid path expression with result true`,
  and a stage over a constructed value (`path({"c":false} | try error(.c) catch .)`) refused with the wrong text.
