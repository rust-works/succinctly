- **jq: a regular file on standard input (`jq -c . < file`) is read a window at a time like a path is, so its peak memory no longer grows with the file** (#7024, #6920). A plain filter (no `-n`, no `input`, no `--slurp`, `--validate` or `--seq`) over a redirected regular file of 4 MiB or more used to read it whole and split every document into a span first, as it does a pipe; it now holds a 1 MiB window and the document being run (14 MiB at 60 MiB of NDJSON against 84 MiB through a pipe). Output, error wording, exit status and the `(at <stdin>:N)` lines are the pipe's, checked on faults at several positions, an unterminated last document, a BOM, invalid UTF-8 and a stdin that starts at an offset a parent has read to. A pipe and a terminal on standard input, and a stdin under 4 MiB, still read the input whole.
