- **yq: a bare `: ` entry inside an explicit key is `did not find expected key`, as in yq** (#6325).
  `? : x`, `- ? : x`, `? - : x`, `? - - : x`, `a:⏎  ? : x` and the key content on the next line (`?⏎  : x`) were read as an empty key with a null value; yq refuses them, as it does the keyless `:` of #6288. A tag or an anchor before the `:` (`? !!str : x`) stays an empty key. `M2N8/00` joins the YAML test-suite known failures.
