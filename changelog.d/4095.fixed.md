- **yq: `recurse(.[]?; cond)` stops at an alias and gives `key`, `path`, `parent`, `line` and `column` a position** (#4095). The owned walk it replaced expanded every alias (a 29-node document counted 51) and read no position, so `[recurse(.[]?; true) | path]` was a list of `[]`. It now answers what `..` does for `cond` = `true` with a single-output tail, node for node, and what `path(recurse(.[]?; cond))` does for a pruning `cond` that reads no `type` tag on a document without aliases. The walk asks `cond` as it reaches each node in the shapes it streams, so `limit` stops it where jq stops (`[limit(3; recurse(.[]?; debug | true) | path)]` asks `cond` twice), and a bare `recurse(.[]?; cond)` prints what `..` prints, including a document's leading head comment, which the owned walk's output dropped. A write through it, `path(recurse(.[]?; cond))` over aliases, and a `cond` the walk cannot ask at a position (one that reads `key`, `path` or `tag`) are unchanged ([#4223](https://github.com/rust-works/succinctly/issues/4223)).
