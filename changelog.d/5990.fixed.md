- **jq: a raw control character in a string is refused even when an invalid UTF-8 byte comes before it** (#5990). `"\xe1\n"` read as a lone U+FFFD, because the invalid-UTF-8 drop quirk (a lead byte with too few bytes left in its string takes the rest of the string, #1743) ran before the parse; jq's lexer refuses the control character first, so it is now `Invalid string: control characters from U+0000 through U+001F must be escaped` at the newline, with jq's line and column, on every input route.
