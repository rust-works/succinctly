- **yq: `from_yaml` and `from_json` apply yq's header slurp to their string** (#6363). yq reads that string through its YAML decoder, so a leading `--- text` line loses its line break (`"--- x\ny" | from_yaml` is `"xy"`, not `"x y"`) and a run of leading `---` lines is one document (`"---\n---\nx" | from_yaml` is `"x"`, which read `null`). The lost-break rule moved from the yq runner into the library (`succinctly::yaml::glue_after_leading_marker_text`) for it.
