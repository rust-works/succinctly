- **jq: `path()` and updates accept a non-matching `ltrimstr`/`rtrimstr`** (#4016). jq returns the input as the same `jv`
  when the input or the literal argument is not a string or the edge does not match, so `path(.b|ltrimstr("x"))` on
  `{"b":"s"}` is `["b"]` and `(.b|ltrimstr("x")) = 9` writes; succinctly raised `Invalid path expression`. A matching
  edge (an empty argument matches) builds a fresh string and still refuses, as in jq. A non-literal argument still
  refuses. jq mode only.
