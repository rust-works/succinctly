- **A look-behind before an end anchor reads as jq's search does** (#6510). jq 1.7.1's Oniguruma searches a pattern that matches only the empty string and ends in `\z`, or in `$`/`\Z` on a text with no final newline, from the end of the text alone, and on that search a look-behind sees only one character past where the search began. `"ab" | test("(?<=b)\\z")` is now `false` and `"ab" | test("(?<!b)\\z")` `true`, as in jq, where both were the other way round; `"b" | test("(?<=b)\\z")` and `(?<=b)(?=\z)`, which Oniguruma searches as usual, still match. Five random draws of look-behinds and lookaheads beside `\z`, `$` and `\Z` (1,282-1,328 patterns each, on ten texts) fixed 82-112 patterns and broke none.
