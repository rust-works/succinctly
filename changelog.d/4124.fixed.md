- **jq: a call to a zero-arity `def` whose body is a literal keeps the path register, so `try path(...)` over it answers as jq does** (#4124).
  `try path(. as $x | def f: 1; f | $x)` printed nothing at exit 0 (and the bare `path` refused) where jq
  prints `[]`: the call read as a stage that may have moved the register, although `1 | $x` already did not.
  A call now leaves the register where its body does (looking through at most 16 nested calls), and an
  `if` with a literal condition reads only the branch it runs (`if false then .. else 1 end`). A body that
  navigates (`def f: .a`) still refuses, as jq's does.
