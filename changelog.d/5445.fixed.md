- **yq: `[.[] | key]` keeps each key's quoting and `~` spelling** (#5445). Over `"qk": 1` / `~: 3` it printed `- qk` / `- null` where yq prints `- "qk"` / `- ~`; a sequence of key nodes now takes the presentation the nodes carry, as every other sequence built from document nodes does since #5429. `keys`, `to_entries | map(.key)`, `map(key)` and a key inside a constructed mapping still print the bare key.
