- **yq: an assignment after `..` updates every node it selects before the first result is printed** (#6860). yq's `|` runs its right side once over the whole list its left side produced, so `.. | select(tag == "!!int") |= . + 1` answers the document with every int incremented, then each node of it, itself updated; `succinctly yq` ran the assignment per node, so the first result (the document, which holds all the others) came out as it was read. The same holds for `=` and `+=` with a literal right side. `A | .. | select(...) |= f` (`A` navigation) is written `A | .. | select(...) | ((.. | select(...)) |= f)`, so a node the update moves is still listed where it was, as yq lists it. Found by a differential sweep of real YAML files, where the unparenthesised form differed on 411 of 819 files.
