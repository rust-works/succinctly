- **yaml: a line after a quoted or flow explicit key, more indented than the `?`, is refused as yq refuses it** (#6382). `printf '? "a"⏎  b⏎: v⏎' | succinctly yq -o json .` printed `{"a":"b"}`, the line read as the entry's value and the `: v` line lost; yq stops with `did not find expected key`, with a comment after the key or without one, and `succinctly yq` now does too, for a quoted scalar and a flow sequence or mapping (`? [a]⏎  b⏎: v`, `? 'a' # c⏎  d⏎: v`). The `:` of the key's value, a comment line, the next key and a node still open across a line break read as before. Over 3,600 generated documents with such keys, the 961 that differed from yq now agree and none changed the other way.
