- **jq: a `(?P` inside a regex comment is no longer refused** (#5550). `"ab" | test("ab # (?P\n"; "x")`, `test("(?x) ab # (?P<n>\n")` and `test("(?#(?P)ab")` failed with `undefined group option` because the pre-pass read the raw pattern text; they are `true`, as in jq, which ignores a `(?#...)` comment and a `#` comment where the extended mode is on (the `x` flag, or an inline `(?x)`, `(?x:...)` or `(?-x)`, tracked group by group). Without `x`, a `#` is a literal and the `(?P` is still refused, as in jq. A `[` or `\<` in a comment is no longer rewritten either. `succinctly yq` is unchanged.
