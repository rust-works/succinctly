- **yq: an integer written `0x1f`, `0o17`, `01`, `+5` or `007` keeps its spelling** (#2802).
  `tostring`, string interpolation, `join`, `sort`, `max`, `unique` and `==` read the text yq reads (`.a | tostring` on `a: 0x1f` is `"0x1f"`, `.a == 31` is `false`), a tag or style assigned to the node (`.a tag = "!!str"`) quotes it as written, and `.[] | key | tostring` of a `01:` key is `01`.
  yq's JSON writers still print the number (`31`), and a value that crosses the reindex bridge carries its spelling in a bridge-only token.
  Arithmetic on a hex or octal integer still drops its base (#3027) and `tonumber` of a spelled string is unchanged (#1356).
