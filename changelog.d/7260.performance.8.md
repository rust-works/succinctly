- **jq: startup on macOS binds 44 fewer imports, and `--arg`-heavy command lines parse once** (#7260).
  A macOS 12 binary binds every import at launch, and each one is searched for through libSystem's
  re-exported libraries; the libm functions only the math builtins call (all but `fmod`) are now looked up on their first
  call instead. The named-flag order is read off clap's own matches instead of building and running a second
  `jq` command definition. On an Apple M4 Pro, `-n 1` and the other startup-bound runs take ~6% less time
  (`-n 1` 1.58 -> 1.48 ms, against jq 1.7.1's 1.73 ms), and eleven `--arg`/`--argjson` flags 1.67 -> 1.58 ms
  (jq: 1.76 ms); on an AMD Ryzen 9 7950X the `--arg` row is 3% faster and the rest unchanged.
