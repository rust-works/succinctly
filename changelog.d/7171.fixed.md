- **yq: `filter(f)` over an empty context answers nothing** (#7171). yq runs `filter` once per node of its context, so `.b[]? | filter(. == 1)` prints nothing there; it was parsed as the array construction `[.[] | select(f)]` and printed `[]` once (and `. *=? (.b[]? | filter(. == 1))` failed with `cannot multiply !!map with !!seq`). It now binds the context node first, which is once per node, and reads the children from it; the answer for every node is unchanged. Pinned against rows captured from yq v4.53.3.
