- **`succinctly yq` writes no head comment for a scalar root after a byte-order mark** (#7089). With a mark yq sets no header aside, so `# lead` / `5` leaves the comment on the node, and its encoder writes a head comment for a collection and not for a scalar: `-P .` prints `5`, and so do `.a = 1` over the scalar and `. = 6` over a scalar, mapping or sequence root, where the comment was printed above them. A plain read of the document keeps it, and so does a collection result (`. = [7]`). A random fuzz of 500 BOM-prefixed documents against yq fixed 106 cases and changed none that already matched. A comment-only document written into a collection, a `null` root merged into a mapping and the head of a scalar or flow document with two blocks are not part of this fix.
