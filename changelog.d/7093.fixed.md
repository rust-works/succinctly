- **`yq --unwrapScalar=BOOL` and `-r=BOOL`** (#7093). yq's boolean flags take their value after `=` and the resolved value (its own when given, else true for YAML and properties output and false for the rest) decides how a value is written, so `--unwrapScalar=false` and `-r=true` were refused here. `-o=shell -r` now writes values unquoted, and `-o=props --unwrapScalar=false` and `@props` put a value with a space in it in Go's quotes (`-o=json '{"a":"x y"} | @props'` is `a = \"x y\"`). The `=false` form of a top-level YAML scalar is recorded in `docs/compliance/yq/limitations.md`.
