- **jq: a document number's decode no longer tries an integer parse that fails on every fraction, nor re-checks UTF-8 that its grammar already proved** (#7287). The shared number parse ran `i64`'s `FromStr` first, which builds an error at the `.` of every fraction; an exact equivalent now stops at the first byte that is not a digit. The JSON cursor ran `str::from_utf8` on a number token just accepted as RFC 8259 number text, whose grammar admits only ASCII; the token's text is now taken straight from that check. Over the `numbers` pattern at 10 MB, instructions on an AMD Ryzen 9 7950X (cachegrind) fall 6.7% for `.numbers|add` (1.525G -> 1.423G), 7.3% for `.numbers|max` (1.389G -> 1.287G) and 1.5% for `.numbers|sort` and `.numbers|map(.+1)`; identity and `[.numbers[]|floor]` are unchanged. Every output is unchanged, yq mode included.
