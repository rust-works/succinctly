- **yq: `style = "tagged"` writes the value's type tag** (#4066, the last piece of #2707). It exited
  with `not yet supported`; `.a style = "tagged"` now prints `a: !!int 1`, `!!str x`, `!!float 1.5`,
  `!!bool true`, `!!null null`, and `!!seq`/`!!map` on the header line of a block container
  (`a: &an !!map`, before a flow or empty one), derived from the value as it is at write time. A
  string is not quoted for reading back as another type (`!!str 1`, `!!str null`), only for what
  the syntax needs (`!!str 'x: y'`), a multi-line one is `!!str |-`, and the empty string is the tag
  alone. Checked against yq v4.53.3 on about 2,000 random strings and the triage matrix. Not
  matched: a non-decimal integer's spelling (`!!int 31` for `0x1F`, #2802), `!!timestamp`, an
  explicit source tag (#1416).
