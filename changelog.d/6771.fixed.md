- **yq: `env(NAME)` reads the value as YAML, and an unset `strenv(NAME)` is the empty string, as in yq** (#6771). yq's `env(NAME)`
  decodes the variable's value and answers the first document, so `myenv=12` is the number `12`, `true` a boolean, `{b: fish}` a
  mapping and `~` a null (`.replicas = env(REPLICAS)` puts a number into the document); an empty value is `not provided`. `succinctly yq`
  answered the text for every value, so it was `strenv`'s twin and yq's own environment-variable examples failed. yq's `strenv(NAME)`
  never checks that the variable is set, so an unset one is `""` (`succinctly yq` raised `not provided`). `succinctly jq`'s own
  `env(NAME)` and `strenv(NAME)` extensions are unchanged. `env(NAME)` reads through `from_yaml`'s decoder, so a timestamp keeps the tag
  `!!str` and the YAML 1.1 spellings `0b11` and `1_000` stay strings (see `limitations.md`).
