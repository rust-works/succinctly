- **jq: a `--rawfile` file that is UTF-8 throughout becomes its string without a second copy** (#7814).
  Since #7436, `--rawfile`, `-f` and `import ... {raw: true}` decoded every file one 4,096-byte read at a time
  into a new string, so the file's bytes and its text were held at once and every byte was copied again. A
  file that is valid UTF-8 now becomes the string in place, and only a file with a byte that is not UTF-8
  takes the per-read walk, starting at the read that holds the first such byte, with the same answers as
  before. Modules and `~/.jq` no longer copy a valid file either. `-n --rawfile s F '$s|length'` over the
  100 MB users input is back to the instruction count it had before #7436 (88.9M -> 80.2M; cachegrind on
  the AMD Ryzen 9 7950X box; 10 MB: 9.65M -> 8.81M).
