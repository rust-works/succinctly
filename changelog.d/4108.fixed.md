- **jq: `first`/`limit`/`nth` over `to_entries`, `sort`, `add`, `map(f)` (for an `f` that navigates nothing), `reverse` or `input_line_number` keep jq's path register, so a write is no longer silently skipped under a `try`** (#4108). `del(.a? as $y | try ((.a)? and first(to_entries)) | try ($y | .b))` on `{"a":{"b":1},"k":2}` printed the document unchanged, exit 0, where jq 1.7.1 deletes `.a.b` (`{"a":{},"k":2}`): the wrapper was refused where the bare stage was answered, and the `try` swallowed the refusal as though it were jq's own path error. `stage_is_register_keeping` now reads the leaf verdict for the peeled stage, and `input_line_number` joins the by-value stages that verdict lists. Checked against jq 1.7.1 on 44 rows through `path`, `del`, `|=` and the `-n` route. `first(path(f))` is still refused: admitting `path(f)` to the leaf verdict turned a loud refusal into a silent skipped write on a shape `test_transparent_bind_source_matches_identity_bind_3402` pins, so it needs its own fix (#4118).
