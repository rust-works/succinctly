- **The release binary puts the functions a run executes first, so far less of it is resident** (#7260).
  One codegen unit with fat LTO scattered the 1-2 MB a query runs over 12-15 MB of machine code, and every
  page a run touched stayed resident: `succinctly jq -n 1` had 5.0 MB of its own text resident on Linux
  (a file fault maps 64 KB or a whole large folio) against jq 1.7.1's 0.3 MB. The release builds for x86_64
  Linux and Apple silicon now link the functions in `scripts/link-order/symbols.txt` first. Peak RSS drops by
  a median 5.8 MB per row on an AMD Ryzen 9 7950X and 1.1 MB on an Apple M4 Pro over every benchmark query
  at 1 MB (`startup` 10.1 -> 4.5 MB and 3.8 -> 2.8 MB, against jq's 3.5 and 2.7 MB), and startup-bound runs
  are 4-6% and 2-3% faster. Output is unchanged, and 100 MB rows move by -0.7% to +1.4%.
