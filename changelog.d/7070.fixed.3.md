- **yq: a string a write appends to a sequence takes the first element's quote or block style, as yq copies it** (#7070). `yq '.a += "cat"'` over `a: ['dog']` is `a: ['dog', 'cat']` and over `a: ["x"]` is `["x", "cat"]`, `.a |= . + "z"` and `.a = .a + "z"` the same, a double-quoted block sequence appends `- "z"` and a literal block appends `- |-` / `z`; `succinctly yq` printed the appended element plain (`['dog', cat]`), so a list of quoted strings lost the convention on every append. A pipe of such writes appends each. 231 rows over 21 documents are pinned against yq v4.53.3; a number appended, a comma target and a `style=` stage after the write still differ (limitations.md).
