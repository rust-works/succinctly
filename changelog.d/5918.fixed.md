- **yq: `map(f)` over an empty mapping is that mapping** (#5918).
  `{} | map(.)` printed `[]` (`!!seq`) where yq v4.53.3 answers `{}` (`!!map`) without running `f`, so `map(.) | . + {"a": 1}` and `[map(.)]` differed too.
  Only an empty mapping behaves that way: a non-empty mapping, an empty sequence, `null` and a scalar already matched, and `jq` mode still answers `[]`.
