- **yq: an empty plain key is written single-quoted on the streaming route** (#6443). A key that is an empty plain scalar (`&a : 1`, `!!str : 1`, `? ` / `: 1`, `- &a:` as in the Google Cloud SDK's `resources.yaml`) printed as `"": 1` with `.`, where yq writes `'': 1` (go-yaml's emitter cannot leave a simple key empty) and a write already did; an empty plain value (`a: !!str`) and a key the source quoted are unchanged. Found by a differential sweep over 7,398 real YAML files, where it was 4 of the 114 files that differed from yq. Pinned against yq v4.53.3 in `tests/yq_cli/i6443.rs`.
