- **A plain `succinctly jq --stream-errors` walk reads its events as the program asks for them** (#7571). Without `-n` it read every event of the input into a list before the program ran, about 34 times the input at its peak (350 MB for a 9.7 MB NDJSON file, where jq 1.7.1 stays near 2.5 MB); it now takes the route a plain `--stream` walk has taken since #5498, the stream reader behind the input queue, reading its files a chunk at a time. Peak RSS of `--stream-errors 'select(length==1)'` on an Apple M4 Pro: 27.1 to 4.3 MiB at 0.6 MB of NDJSON, 213.0 to 4.3 at 6.1 MB and 2,029 to 4.3 at 62.7 MB (three runs a cell, an A/A control of each binary within 0.3%), the output unchanged and equal to jq's.
