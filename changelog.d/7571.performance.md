- **A plain `succinctly jq --stream-errors` walk reads its events as the program asks for them** (#7571). Without `-n` it read every event of the input into a list before the program ran, a large multiple of the input at its peak (where jq 1.7.1 stays flat); it now takes the route a plain `--stream` walk has taken since #5498, the stream reader behind the input queue, reading its files a chunk at a time. Peak RSS of the plain `--stream-errors` walk is now flat in the input's size (3.7 to 3.8 MiB at 1, 10 and 100 MB of `--stream-errors -c .` on an Apple M4 Pro, and 15.3 MiB, the benchmark driver's own size before exec, on an AMD Ryzen 9 7950X), the output unchanged and equal to jq's.
