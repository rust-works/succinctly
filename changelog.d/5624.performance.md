- **jq: the filter `.` over a `--stream` event, a `--seq` record or a DSV row no longer writes the value out, indexes the text and converts it back** (#5624).
  An input that is already a value (anything but a document read from a file) was evaluated by writing it as JSON, indexing that text and running the filter against the new cursor, so even `.` paid it: about 9,000 instructions for a 35-byte `--stream` event.
  A program that is `.`, `(.)` or a pipe of them now prints the value as it is, under every output option (`-S`, `--tab`, `--indent`, `-a`, `-r`, `-j`, `-C`, `-e`); `--preserve-input` keeps the old route.
  `--stream -c .` retires 62% fewer instructions over 7 MB of records (15.3G to 5.8G, Apple M5 Max; jq 1.7.1 retires 10.8G) and `--input-dsv , -c .` 53% fewer; the wall-clock figures from the interleaved A/B on an Apple M4 Pro and a 7950X are in the pull request.
