- **jq: a braced hex escape `\x{...}` is read as Oniguruma reads it** (#6251).
  `\x{110000}`, `\x{D800}` and `[\x{110000}]` were refused with `invalid regex: regex parse error` and now match nothing, as in jq 1.7.1.
  A ninth digit (`\x{000000041}`, which matched `A`) is `too long wide-char value`, a missing brace (`\x{101`) is `invalid code point value`, and `\x{}` or `\x{ 1}` is the letter `x` followed by an ordinary brace.
  A surrogate or past-U+10FFFF value as the end of a range in a class (`[a-\x{D800}]`, which jq clamps) stays refused.
