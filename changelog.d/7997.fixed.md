- **`succinctly yq` reads `$__loc__` as an ordinary variable without `--jq-extensions`** (#7997). yq has no `$__loc__`, so a program can bind the name: `1 as $__loc__ | $__loc__` is `1`, where it printed nothing because every `$__loc__` was jq's location pseudo-variable, and `--arg __loc__ X` now sets it. Unbound, it still yields nothing (`[$__loc__] | length` is `0`). Under `--jq-extensions` it is jq's `{"file": "<top-level>", "line": N}` object, which it was not before (it printed nothing there too), and a binding of the name still shadows it (`1 as $__loc__ | $__loc__` is `1` there as well); `succinctly jq` is unchanged.
