- **jq: a number written with a trailing dot and no fraction (`5.`, `99999999999999999.`) reads as the integer in `fromjson`, `--argjson`, `--jsonargs` and `tonumber`, and a large one is no longer rounded** (#6052). `"1." | fromjson` and `--argjson x 1.` were errors, where jq answers `1`; and `succinctly jq -c .` on `99999999999999999.` printed `100000000000000000` where jq prints `99999999999999999` (the dot sent the token to a lossy `f64` read), as did `tonumber` (`1e+17`). The dot is dropped before the literal is kept, so every spelling jq reads (`-5.`, `+5.`, `007.`, `-0.`, `[1.]`) prints as it does there, and a dot with no integer part (`.`, `1.5.`, `1..`) is still refused. yq is unchanged.
