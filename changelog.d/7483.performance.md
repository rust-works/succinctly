- **jq: a recursive `def` that threads a state through its calls no longer copies the state at each call** (#7483, #7473).
  `def f($n): if $n == 0 then .a = 1 else f($n - 1) | f($n - 1) | .a += 1 end; {x: [range(k)]} | f(12)`
  wrote the whole state out as JSON and indexed it again at every call, so its time grew with the size of `x`,
  a member the program never touches: 2.86 s at k = 32,000 on an AMD Ryzen 9 7950X, where jq 1.7.1 takes
  17 ms; it is now 22 ms at every k. A call, a definition, a pipe a call or an assignment leads, an `if` whose
  condition reads the state and a `$`-parameter's binding run on the built value itself, which each assignment
  they reach writes in place. A recursive `def` that loops in place, `def f: if .i >= n then . else
  (.p["k\(.i)"] = 1 | .i += 1 | f) end`, copied the growing `p` every round and was quadratic in its rounds
  (5.66 s at 16,000); its writes now land in place too, and it takes 11 ms (jq 1.7.1 49 ms). The answers are
  unchanged.
