- **yq: a chain of merges that each name the previous source twice is read in linear time** (#7224). `m0: &m0 {k: 0}` followed by `mN: &mN {<<: [*m(N-1), *m(N-1)], iN: N}` took twice as long for every level, so `.m14` (58 s in a debug build) and `.m14.k` (40 s) ran for hours a few levels deeper, from a few hundred bytes of YAML. The kind of a `<<` source is now read off the index, as `--yaml-fix-merge-anchor-to-spec` already did, and a key lookup remembers what each source answered; a chain 60 deep answers in 3 ms in a release build. The output is unchanged.
