- **yq: a fractional number key against an array is refused, as in yq** (#4749, #4404). `[10,20,30] | .[1.5]` read `20` (jq's truncation) and yq raises `cannot index array with '1.5'`; `.[1.5] = 9` wrote `[10,9,30]` and `del(.[1.5])` gave `[10,30]` where yq raises on both. A computed key (`.[1/3]`, `1.5 as $k | .[$k]`, `.a[.k]`), a comma group (`.[0,1.5]`, `del(.[0.5], .[0])`) and a YAML sequence are refused the same way, and `?` suppresses a read. A computed float of `1e6` or more (`.[1.0*1000000]`) is refused too, where yq's `%g` writes an exponent; `.[3/3]` and `.[1.0*999999]` still index. A `null`, mapping or scalar target keeps its own rule, `succinctly jq` still truncates, and the refusal keeps this build's wording (`Cannot index array with number`). Not part of this change: a mapping's numeric `del` and a multi-key past-the-end `del`.
