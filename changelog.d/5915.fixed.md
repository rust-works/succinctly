- **jq: a computed object key that is not a string is rejected only once its value yields** (#5915).
  Over a computed value, `{"n":1} | {(.n): .[0]?}` raised `Cannot use number (1) as object key`
  where jq prints nothing, and `{"n":1} | {(.n): .[0]}` reported the key where jq reports the value's
  own error (`Cannot index object with number`). The streaming route checked the key as soon as it
  was produced; it now waits for the first value, as the eager and generic routes and jq do.
