- **json: converting an element of a document whose last string never closes no longer panics** (#5541). `JsonIndex::build` accepts a document such as `[{"d":"2}]}]`, and the library's whole-element conversion (`to_owned_cursor`) then sliced the text one byte past its end (`range end index 35 out of range for slice of length 34`) instead of reporting the malformed value. The string's span now stops at the end of the text, so the conversion returns a decode error, as `/usr/bin/jq` answers `Unfinished string at EOF`. The CLI was never affected: its document splitter rejects the file first (`Invalid JSON text`, exit 5).
