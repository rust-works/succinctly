- **json: reading a string that never closes no longer panics** (#5541). `JsonString::end`/`raw_bytes` ran one byte past the end of the text for a document such as `[{"d":"2}]`, so `to_owned_cursor` (and the tail-gap check under it) panicked with `range end index 35 out of range for slice of length 34`. The CLI's document splitter already refused such a document, so only a caller of the library API (`JsonIndex::build` accepts it) could reach it; the span now stops at the end of the text.
