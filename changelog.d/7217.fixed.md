- **jq: `input`/`inputs` over 2 to 32 files read a file to its end when the run reaches it** (#7217). A program reading `input`/`inputs` over several regular files (4 MiB or more between them) read each file to the length it had when the run opened it, so a line appended to a later file while the run was still in an earlier one was dropped, where jq, which opens each file when its reader reaches it, reads it. Each file is now read to the end it has then, with its descriptor still held from the start (a path removed or replaced meanwhile keeps its old bytes). A list of more than 32 files already read this way (#7197), so the answer no longer depends on how many files are named.
