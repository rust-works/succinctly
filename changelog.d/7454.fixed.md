- **jq: input that ends inside the UTF-8 byte-order mark is empty input** (#7454). `printf '\xef' | jq .` and the same with `EF BB` were a numeric-literal parse error (exit 5), where jq 1.7.1 and 1.8.2 print nothing and exit 0 (`-s .` is `[]`, `-n input` is `break`), on standard input and in files, for `.`, `-s`, `-n`, `--stream` and `-e`. A mark that goes on to something else is still a fault. The "both exit 5" sentence of the #5804 entry in `docs/compliance/jq/limitations.md` was wrong for this shape and is corrected.
