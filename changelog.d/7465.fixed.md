- **jq: `path($k)` accepts a path component's key read at two elements, as jq does** (#7465). `[.[] | path(.a)[0]] | .[0] as $k | .[1] | path($k)` on `[{"a":1},{"a":2}]` raised `Invalid path expression with result "a"` where jq 1.7.1 and 1.8.2 answer `[]`: jq loads the `"a"` of `.a` (and the `0` of `.[0]`) as one constant per program site, so every path that site builds holds the same key. The path-mode interpreter built a new string for it at every step; it now keeps one per site, as it already did for literals, so a path step allocates no key. Two sites of the same text stay two keys, and a slice's key is still built per evaluation, as in jq.
