- **jq: the experimental call machine compiles a program once per run** (#7977, step 5 of its migration plan).
  Under `SUCCINCTLY_CALL_MACHINE=1`, a routed program was compiled when its route was pinned, decided again on the first document, and compiled again for every document, so a run over 100,000 NDJSON records compiled 100,002 times.
  The decision now pins its compiled code with the route, and every document of the run runs that code: the same run decides once and compiles once.
  The code owns what it holds (a leaf keeps a copy of its subtree), and a run's state stays with the machine, so labels keep counting across documents as jq's do.
  `SUCCINCTLY_DEBUG_CALL_MACHINE_LOG` now records each compilation as a `compiled` line beside the `taken`/`declined` decisions, and `scripts/call_machine/per_record.py` compares a routed program's per-record cost over NDJSON against one document holding the same records.
  With the switch unset or `0` nothing changes.
