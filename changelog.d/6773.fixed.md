- **jq: `--seq -s --stream-errors` puts the fault a record left open ends in inside the slurped array when two reads follow the last file with bytes** (#6773). A `--seq` record left open (`\x1e[1,`) that runs on into a file meets its fault at the read of the last file, and the fault is an event of the stream, so jq has it in the array: `jq --seq -s --stream-errors . trunc pa missing missing2` printed the array without `["Unfinished JSON term at EOF at line 1, column 7",[1]]`, and so did `trunc pa missing empty` and `trunc pa missing dir`. One failed file after the last file with bytes, `--seq -s --stream`, and every other flag set are unchanged.
