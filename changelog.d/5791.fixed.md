- **jq: `map_values(f)` reads only the first output of `f`, as in jq** (#5791). `[1] | map_values((1, error("x")))` raised `x`; jq prints `[1]`, because `map_values(f)` is `.[] |= f` and never runs the rest of `f`, and so does `succinctly jq` now (for arrays and objects alike). `succinctly yq` still raises, as real yq does. A side effect of a later output (`halt_error`'s stderr text, `debug`) still fires, because `f` is still run to its end; that residual is recorded in the limitations page.
