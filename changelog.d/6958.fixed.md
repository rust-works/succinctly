- **yq: an underscored `!!float` keeps its text** (#6958). `a: !!float 1_0.5` is the number 10.5 and, as yq prints it, the text `1_0.5` through `tostring`, `to_yaml`, YAML output and a copy, where `succinctly yq` printed `10.5`; and `!!float 1_000` is `1000.0` in JSON, not `1000`. An underscored float is now carried as its text, as an underscored `!!int` already was, across the evaluator and the reindex bridge (its own token family, because the text alone reads as an integer), and it carries the `!!float` tag where the text alone would not read as one (`a: !!float 1_0.5`). `-P` over one and `to_yaml` under YAML output are recorded residuals.
