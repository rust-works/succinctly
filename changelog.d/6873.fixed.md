- **`succinctly dev compare jq` and `bench run` name an aarch64 Linux CPU** (#6873). An Arm Linux kernel prints no `model name` in `/proc/cpuinfo`, so a run on an AWS Graviton recorded `Unknown CPU`, and `--write-docs` could never match it against the `**CPU**:` line of a section of `docs/benchmarks/jq.md`. The core is now named from the `CPU implementer` and `CPU part` fields (`ARM Neoverse-V2` for implementer `0x41`, part `0xd4f`, as read on a Graviton 4; Neoverse-N1, V1, N2, V3 and N3 by the part numbers of the kernel's `cputype.h`), and a core outside that list is named by the two fields. `docs/benchmarks/jq.md` gains the empty `jq-linux-aarch64` block of its Neoverse-V2 section for the run to fill.
