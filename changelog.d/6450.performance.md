- **`-n` with `input`/`first(inputs)` over several files scans the last file a chunk at a time** (#6450). The last file was split, re-parsed with `serde_json` and line-counted whole before the first value. It now gets the 64 KiB-and-doubling scan a lone file has, so a program that stops early reads little of it. On an Apple M4 Pro, `-n 'first(inputs)|.id' one-line.json big.ndjson` went from 5.3 to 3.1 ms at 1 MB, 24.5 to 5.2 ms at 8.7 MB and 220 to 20 ms at 87 MB (jq 1.7.1: 2.4-3.0 ms); a program that reads every input is unchanged. The earlier files are still scanned whole (#6455), and the whole-file read and UTF-8 check are #6451.
