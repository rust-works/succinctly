- **jq: a module or data import that names a directory, or a file that will not open, reports it as jq does** (#7663). `import "d" as $d;` with a directory `d.json` said `module not found: d`, where jq 1.7.1 and 1.8.2 say `error loading data file <path>: Could not open <path>: It's a directory`; the same holds for `import "d" as m;` and `include "d";` (a directory `d.jq`), for the `d/jq/main.jq` and `d/d.jq` spellings, and for a directory in an earlier `-L` entry ahead of a file in a later one, which jq stops at. An unreadable file now carries jq's `Could not open <path>:` before `Permission denied`, a symlink loop moves on to the next search directory as in jq, and `modulemeta` on a module that will not read is `null` with nothing on stderr.
