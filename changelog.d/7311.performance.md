- **jq: an object that repeats a key no longer holds every field and every key to collapse it** (#7311).
  jq's rule (a repeated key keeps its first position and takes its last value) was applied by
  materializing the object's fields and owning each key in a map, so one repeated key in a 100 MB
  object of 7.1 M keys cost 2.99 GB of memory to print with `.` or `-c .`. Only the keys whose hash
  another key shares are decoded now, and the other fields are streamed as before: the same print
  peaks where printing that object without the repeat does. `-C`, `select(true)` and the other
  printer routes, `map(f)` and `.[]` over such an object get the same treatment.
