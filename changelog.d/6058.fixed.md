- **yq: a single-quoted scalar with an empty line is written back across lines, as yq writes it** (#6058). `printf "a: 'x\n\ny'\n" | yq .` kept the value `x\ny` but `succinctly yq` wrote `a: 'x` and `y'` on adjacent lines, which a YAML reader folds back to `x y`: the YAML output read back as another value. Each `\n` of the value is now written as an empty line with the text after it indented, as yq does, in block and flow position, after a write elsewhere in the document, and under `style="single"`; JSON output and the value were never affected. A flow sequence nested in a flow sequence and an explicit `? ` key still print the older spelling.
