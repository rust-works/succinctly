- **`succinctly jq` `strftime`/`strflocaltime` follow the locale** (#5754). `%a %A %b %B %h %p %c %x %X %r` use the names and layouts of `LC_ALL`/`LC_TIME`/`LANG`, as jq's `setlocale(LC_ALL, "")` makes them: `LC_ALL=de_DE.UTF-8`, `1425599621 | strftime("%A %B")` is `Donnerstag März`, and `LC_ALL=en_US.UTF-8` makes `%x` `03/05/2015`. An uninstalled locale, or one invalid category, leaves the process in C, as in jq. The default (C) output is unchanged. Windows, bare `std` and `no_std` keep the English names. `strptime` reads the same names (`%a %A %b %B %h %p`): `LC_ALL=de_DE.UTF-8`, `"Donnerstag, 05. März 2015" | strptime("%A, %d. %B %Y")` parses and the English names no longer do, and `%a`, `%A` and `%p` reject text that is not a name instead of skipping any run of letters (`"Xyz Mar 05 2015" | strptime("%a %b %d %Y")` is an error, as in jq).
