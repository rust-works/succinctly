- **jq: a loop that reads the tail of a built array is no longer quadratic** (#6692). `[range(0; N; 2) as $i | .[$i:][0]]` (and `.[$i:][-1]`, `.[$i:] | length`, `.[$i:][:2]`, inside `first`, `select`, `limit` and `try` too) built each tail, `N - $i` elements decoded and copied, before reading one element or two of it. `eval.rs`'s two pipe drivers now answer the slice and the read from the slice's resolved range, as the generic evaluator already did (#4195, #4288), and a second literal slice (`.[a:b][c:d]`) is composed onto the first's range for both evaluators. Output is unchanged (0 of 21,776 differential rows differ from jq 1.7.1 and the previous build).
