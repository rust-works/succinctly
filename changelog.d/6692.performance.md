- **jq: a loop that reads the tail of a built array is no longer quadratic** (#6692). `[range(0; N; 2) as $i | .[$i:][0]]` (and `.[$i:][-1]`, `.[$i:] | length`, `.[$i:][:2]`, also inside `first`, `select`, `limit` and `try`) built each tail, `N - $i` elements decoded and copied, before reading one element or two of it. `eval.rs`'s two pipe drivers now answer the slice and the read from the slice's resolved range, as the generic evaluator already did (#4195, #4288), and a second literal slice (`.[a:b][c:d]`) is composed onto the first's range for both evaluators. At N = 20,000, `.[$i:][0]` takes 8 ms where it took 6.0 s on a Ryzen 9 7950X (4.8 s to 7 ms on an M4 Pro), and `.[$i:] | length` 8 ms where it took 10.4 s; at N = 160,000 it takes 51 ms (36 ms). Output is unchanged: 0 of 23,096 differential rows differ from jq 1.7.1.
