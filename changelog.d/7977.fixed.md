- **jq: the experimental call machine keeps the first store of a pattern that binds a name twice inside a leaf** (#7977).
  Under `SUCCINCTLY_CALL_MACHINE=1` a destructuring pattern inside a leaf ran on the path-mode interpreter, which keeps the last store of a name bound twice where jq keeps the first that runs (an array pattern's last element), so `def r: if false then r else . end; [[1,2]] | [.[] | [(. as [$x, $x] | $x)?]]` answered `[[1]]` where jq and the shipped route answer `[[2]]`.
  Such a pattern, and one that computes a key, is now compiled by the machine itself, or declines the program where the machine has no code around it.
