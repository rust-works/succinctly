- **`rust-version` is now 1.89.0, the oldest toolchain that builds the crate, and CI checks it**. It said 1.73.0, which nothing built with: the committed `Cargo.lock` needs 1.85 (edition-2024 dependencies such as `indexmap`, `hashbrown` and `clap`, which cargo 1.84 cannot parse), and the `simd` feature's AVX-512 VPOPCNTDQ popcount kernel needs 1.89 on x86_64, where its intrinsics stabilized. Without `simd`, or on aarch64, 1.85 builds the library and the CLI. A new `MSRV` job reads `rust-version` from `Cargo.toml` and runs `cargo check --locked` with that toolchain on x86_64 Linux, for the library with default features and for `--features cli,simd,regex,serde`; the floors are in `docs/guides/release.md` (MSRV Policy).
