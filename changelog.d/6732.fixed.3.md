- **`succinctly jq --stream-errors` stops printing a spurious `Unfinished JSON term at EOF` event when a directory is the last file** (#6732). When an earlier file leaves a token open (`[`, `[1,`) and the file before the directory finishes a container (`{"a":1}`, `1]`), `jq -c --stream-errors . open.json obj.json dir` printed an extra `[\"Unfinished JSON term at EOF at line 1, column 8\",[0]]` after the two events; jq prints the two events and exits 2, and so does succinctly now (the same for `first` and `halt_error`). A program that reads `input` still sees that event, as in jq (`[inputs]` prints it inside the array and says `Is a directory`). A newline after the closing bracket, or an empty file before the directory, keeps the event, as before.
