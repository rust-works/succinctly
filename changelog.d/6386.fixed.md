- **yq: a key with no value, followed by a quoted or flow-collection key, keeps its null** (#6386). `a:` / `"b": 1` read `{"a": "b", "b": 1}` (and `a:` / `[x]: 1` read `{"a": [], "": 1}`): the empty value's node was written at the start of the *next* line, and a node is decoded from its first byte, so a quote or a bracket there made the key's text its value. It happened when the next line was at the key's indent or a dedent (`x:` / `  a:` / `"b": 1`), in a sequence item's mapping (`x:` / `  - a:` / `"b": 1`) and with a property on the empty value (`- a: &x`).
