- **jq: a lone `--seq` file is read in windows from 64 KiB, and an array of field reads walks its object once** (#7260).
  A `--seq` file under 4 MiB whose records are not all plain took the whole-file route, which turns every record
  into an owned value; it now takes the windowed route from 64 KiB. `[.a, .b]`-style arrays of field reads find all
  their fields in one walk of the object, and `keys` over an object whose keys have no escapes sorts without the
  probe that collapses a repeated key. `--seq -c .name` over 1 MB with a malformed record is 18% faster on an AMD
  Ryzen 9 7950X (11.2 -> 9.1 ms, against jq 1.7.1's 11.4 ms) and 26-27% faster on an Apple M4 Pro (12.6 -> 9.3 ms,
  jq 13.5 ms); `[.id,.name]` over NDJSON or `--seq` is 6-20% faster and `keys` 1-9% faster.
