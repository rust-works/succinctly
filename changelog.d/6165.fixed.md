- **jq: a stacked repeat, or a repeat of an empty group, on a pattern only `fancy-regex` can take is no longer refused** (#6165). `"ab" | test("(?:\\Ka)**")`, `(?=a)a**`, `(?=a)a+*`, `(?>a)**` and `(?=a)a{2}*` failed with the `regex` crate's parse error where jq answers (`true`, the repeat of a repeat). The `fancy-regex` route read the pattern for its safety check in the crate's default dialect, which refuses a second repeat and a repeat of an empty group, and then built it in Oniguruma mode, which takes both; it now falls back to Oniguruma mode (not for a pattern with a `(?#...)` comment, which jq refuses a repeat after). That also closes two documented gaps: `"abc \n" | match("(?:)+\\s+$")` is `[3,2]` as in jq, and `n` and `l` now apply to `(?:)+?|a` and `(?:){1,2}a?||`. A sweep of 23,275 pattern, text and flag combinations over empty-group and stacked repeats found 794 now agreeing with jq 1.7.1 that did not, none that stopped agreeing, and the possessive-then-repeat shape (`a?+*`) recorded as #6172.
