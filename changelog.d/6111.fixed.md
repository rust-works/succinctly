- **jq: `strftime(f)` and `strflocaltime(f)` with a format that is not a string report the input's fault first, as jq does** (#6111). They raised `expected string, got strftime format` for every input. jq tests the input before the format: `null | strftime(1)` is `strftime/1 requires parsed datetime inputs`, a broken-down-time array is `strftime/1 requires a string format`, and a number outside the range is `error converting number of seconds since epoch to datetime` (`strflocaltime/1` in the local-zone builtin's wording). A number that converts still raises succinctly's own error, since jq aborts there (#3046).
