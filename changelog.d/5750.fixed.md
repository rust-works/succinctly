- **jq: `JQ_COLORS` is parsed as jq's `jq_set_colors` does** (#5750, #5751). A field longer than 12 bytes (jq's 16-byte colour buffer less `ESC [ m` and the NUL) now rejects the whole variable (`Failed to set $JQ_COLORS`, defaults kept), where the long field used to be applied (`JQ_COLORS='1;2;3;4;5;6;7;8;9'`). The field loop ends when the text left after a `:` is empty, so `JQ_COLORS=` keeps every default colour (it used to blank the null colour) and `JQ_COLORS=:::` leaves the number colour at `0;39` (it used to blank it); `1:` sets only the null colour. Output is byte-identical to jq 1.7.1 on every spec tried. Four `to-triage` ledger entries are gone.
