- **yq: `@csv` and `@tsv` encode as Go's `encoding/csv` does, as yq's do** (#6131). `[1, a, b] | @csv` printed `1,"a","b"` and yq prints `1,a,b` (a field is quoted only where it holds the separator, a double quote, a line break or a leading space); an array of arrays is one record each (`cat,thing1,thing2` / `dog,"thing,3",thing4`), an array of flat objects is the first object's keys then one record each, a scalar input is its own text, and `@tsv` quotes rather than backslash-escapes. Both raise yq's own errors for what they cannot encode. A `null` element is spelled `null` where yq keeps the source spelling (`~`). `succinctly jq` is unchanged.
