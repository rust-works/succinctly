- **yq: `=` from a computed right side that still names one node copies that node** (#5249). `.c = (.b // 0)` and `.c = (.b | select(true))` over `b: *x` printed `c: 1`; `.c = (.a // 1)` over `a: !Foo x` printed `c: x`, dropping the tag from the data. They now print `c: *x` and `c: !Foo x` as yq does, with the node's quoting, trailing comment and flow style, and a tagged key (`.a = (.b // 1)`). A right side that builds a value (`[.a]`, `{"z": .a}`), computes one (`.b + 1`), yields several nodes (`.a, .b`) or sits behind a compound assignment still writes a plain value.
