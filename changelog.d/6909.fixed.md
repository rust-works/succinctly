- **yq: `style = ""` keeps the quotes of a quoted string that reads as another type** (#6909). go-yaml's encoder quotes a string whose plain spelling it reads as a timestamp or an underscored number, so `a: "2023-07-12"` stays `a: "2023-07-12"` after `.a style = ""` (and `'2023-07-12'` becomes double-quoted); `succinctly yq` wrote it plain, which changes the node's type for the next reader. Spellings the core schema already types, a plain scalar and `style = "single"` / `"double"` are unchanged. Found by a differential sweep of real YAML files (`CABAL_CACHE_VERSION: "2023-07-12"` under `.. style = ""`).
