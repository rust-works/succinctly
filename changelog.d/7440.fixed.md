- **jq: `-e` makes `halt_error(N)` for a negative `N` exit with `abs(N)`** (#7440). `jq -e -n 'halt_error(-300)'` exits 44, `halt_error(-1)` exits 1 and `halt_error(-2.9)` exits 2, as jq 1.7.1's `exit(abs(status))` does (a fraction truncates toward zero, an out-of-range code saturates, and `-256`, `-0.5`, `-1e10` and `nan` still exit 0). `succinctly jq` exited 0 for every negative code. Without `-e` a negative code exits 0 in both, as before; `succinctly yq --jq-extensions` keeps exiting 0 either way.
