- **`succinctly yq -p base64` and `-p uri`** (#6925). Each decodes the whole input to one string, as yq v4.53.3 does: base64 through a port of Go's stream decoder (its whitespace trimming, padding, `unexpected EOF` and chunk-relative `illegal base64 data at input byte N` included), `uri` through `url.QueryUnescape` (`+` is a space, `invalid URL escape "%zz"`). Under `-p auto` a first file named `*.base64` or `*.uri` picks the format and prints in it, and the extension is now lowercased with its aliases read, so `a.JSON` and `a.j` are JSON. The decoders agree with yq on 1,300 random inputs.
