- **jq: a path-mode run that cannot hand an object key out keeps the document's keys as read** (#7489). #7401 gave every object key its own identity in the path-mode interpreter (the route for path expressions that do more than navigate), one or two allocations per key, but a key's identity is only asked of a key handed out as a value, by `.[]` on an object, `..`, `keys`, `keys_unsorted` or a jq-defined builtin built on them (`to_entries`, `paths`, `map`, ...). The interpreter now decides once per run whether the program can reach one, and leaves the keys alone when it cannot; answers are unchanged. Peak RSS of `. as $d | path($d)` (Apple M4 Pro, medians of 10 runs, an A/A copy of the base within 0.3%): 854.7 to 597.4 MiB over 71 MB of the generator's `users` pattern, 1,274.5 to 1,177.2 MiB over 84 MB of `comprehensive`, which is the 8% #7401 added. Programs that can hand a key out keep the identities and are unchanged.
