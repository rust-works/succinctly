- **jq: a junk byte right after `[`, `{` or a key's closing quote is refused instead of skipped** (#5644). `[@1]` parsed as `[1]` and `{"a":@-3}` as `{"a":-3}`, because the index reads a byte that begins no JSON token (`@`, `#`, a control byte, ...) as whitespace; jq 1.7.1 stops with `Invalid numeric literal` at the column of the byte, and so does `succinctly jq` now, with the same message and exit status. The check covers the first element of an array, the first key of an object and the value after a `:`. A form feed in those gaps is refused too, since JSON does not count it as whitespace.
