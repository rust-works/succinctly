- **yq: `map_values(f)` leaves a value whose `f` yields nothing, as yq's `.[] |= f` does** (#6129). `[1, 2, 3] | map_values(select(. > 1))` printed `[2, 3]` and `a: 1` / `b: 2` lost `a`; yq keeps every value (`[1, 2, 3]`), as it does for `map_values(.[])` over a sequence with an empty member (`[1, [], 3]`). `succinctly yq` now reads `map_values(f)` as `.[] |= f`, which also keeps a value's comment, anchor and style through it. `succinctly jq` still deletes the entry, as jq does.
