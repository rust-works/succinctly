- **yq: `map_values(f)` leaves a value whose `f` yields nothing, as yq's `.[] |= f` does** (#6129). `[1, 2, 3] | map_values(select(. > 1))` printed `[2, 3]` and `a: 1` / `b: 2` lost `a`; yq keeps every value (`[1, 2, 3]`), as it does for `map_values(.[])` over a sequence with an empty member (`[1, [], 3]`) and for a repeated key (`a: 1` / `a: 2` stay). `succinctly jq` still deletes the entry, as jq does.
