- **`succinctly yq -p toml`** (#6925). Reads a TOML file as yq v4.53.3 does: a port of go-toml's parser and of yq's decoder over it (numbers and booleans keep their spelling, a date-time is checked as Go reads it and a local date, time or date-time is an error, comments are kept, a key is a glob, tables are merged with their arrays appended and `[[a]]` writes into the last element, with the parser's own error messages). Under `-p auto` a first file named `*.toml` reads and, with `-o auto`, prints as TOML, and `-i` writes it back. It agrees with yq on 5,036 TOML files found on a machine and 14,000 random documents, apart from the rows recorded in `docs/compliance/yq/limitations.md`; a run of `[[array]]` tables is linear here where yq's is cubic.
