- **yq: `-o xml` keeps the comments through a write, so `-i` on an `.xml` file no longer strips them** (#7156, #7117). `succinctly yq -i '.a.d = "z"' pom.xml` rewrote the file without a single `<!-- -->`, where yq leaves them where they were. A write (`=`, `|=`, `+=`, `del()`), `sort_keys` and a mapping built around the document now encode each result with the presentation tree the YAML printer prints it with, and the first document's leading block as it was before the write. Agrees with yq v4.53.3 on 300-document sweeps of `=`, `|=`, `del`, `sort_keys` and a nested write, and on `-i` over an XML file; `with_entries`, `to_entries | from_entries`, `. * {..}` and `--eval-all` still drop them (limitations.md).
