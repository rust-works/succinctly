- **yq: `--split-exp` starts the second and later files of a run with `---`, as yq does** (#7053). yq writes every `--split-exp` file through one printer, so the first result of a document after the run's first carries the document separator under YAML and kyaml output: the file for the second document, or for the second input file, begins `---`. Two results of one document (`.[]`, a null input's) are written back to back, as they are on stdout; `-N` removes the separator; JSON, `-o=props`, `-o=xml` and the other encoders have none; a document whose filter gives no result does not count. `succinctly yq --split-exp` wrote none. Every case was captured from yq v4.53.3.
