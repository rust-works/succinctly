- **yq: `sort_keys` keeps every entry of a repeated mapping key** (#5426). Over `a: 1` / `a: 2` / `b: 3` it answered `{"a":2,"b":3}`; it now stable-sorts all three entries (`{"a":1,"a":2,"b":3}`). yq answers `{"a":2,"a":2,"b":3}`, copying the last value over the earlier entries, which would destroy a document value; this is a recorded divergence (ADR-0018, `docs/compliance/yq/limitations.md`).
