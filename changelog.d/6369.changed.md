- **`YamlString::BlockLiteral` and `YamlString::BlockFolded` carry a `unicode: bool`** (#6369). It is set from the index when the scalar holds U+0085, U+2028 or U+2029 (`YamlIndex` lists such scalars as it is built), and `as_str` and `raw_bytes` read the scalar's lines with those as line breaks, as go-yaml does. Code that matches either variant without `..`, or builds one, needs the new field; an index rebuilt with `from_parts` lists none and reads every block scalar as before. `json_sourced` was added to the quoted and plain variants the same way (#3380, #3445).
