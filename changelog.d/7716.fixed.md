- **jq: a malformed object key is two compile errors, as in jq** (#7716). `{1+2:3}`, `{.a:1}`, `{"a"+"b":1}` and `. as {1:$a} | $a` report the syntax error and then jq's `May need parentheses around object key expression`, counted `jq: 2 compile errors`, where `succinctly jq` stopped at the first. The parse goes on past the key as jq's grammar recovers there, to the next `:`, `,` or `}`, so the errors after it are reported too (`{1:3, 2:4}` is four, `{1} | {2:3}` three), and a syntax error within three tokens of the recovery is not, as bison does (`{1:}` is one error).
