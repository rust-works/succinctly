- **`succinctly jq` `isfinite` is true for a NaN** (#6041). `nan | isfinite` answered `false`; jq defines `isfinite` as `type == "number" and (isinfinite | not)`, so a NaN, which is not infinite, is finite there (`[nan, infinite, 1.5] | map(isfinite)` is `[true,false,true]`). Found by a builtin x value sweep against jq 1.7.1.
