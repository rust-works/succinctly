- **jq: `input`/`inputs` over more than 32 regular files read them a window at a time** (#7197, #7024). A program that reads `input`/`inputs` over 2 to 32 regular files has been read a window at a time since #7162, which holds each file open from the start and so stopped at 32 to keep the descriptor table small; a longer list read every file whole. Such a list is now judged by `stat`, each file is opened once before the run to be checked as UTF-8 and closed, and the run opens each file by its path when it first reads it and closes it with its documents, as jq does, so it holds one file at a time. At 100 MiB of NDJSON in 64 or 256 files peak RSS falls from 112.6 MiB to 15.2 on x86_64 and from 107 to 7.3-12.9 on aarch64, flat from 10 MiB, and `first(inputs)` reads 80% and 77% faster on x86_64 and 33% and 25% on aarch64; programs that read every document read within a few percent, with `reduce inputs` over 64 files on x86_64 the one cell at +7.7% (the same program over 256 files reads -4.9%). A path that will not open when the run reaches it (removed, made a directory or replaced since the run started) is read as the whole-file route reads the files as they then stand: a missing one is reported in jq's words once its reader is past it and the run ends with exit 2.
