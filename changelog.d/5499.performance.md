- **jq: `$var.field` in a `reduce`/`foreach` update no longer rebuilds the whole object** (#5499). Each loop element was converted to a literal tree, converted back to a value, and only then asked for one field. The field is now spliced in directly when the object holds it. `reduce .users[] as $u (0; .+$u.score)` over a 70 MB `users` document: 1.23 s to 0.77 s on an M5 Max (jq 1.7.1: 0.75 s, was 0.58x). An absent field, a non-object, a longer pipe and a path-position read keep their old route and error text.
