A bare `catch empty` now returns before seeding or running its handler, a `.[]?`/`try .[]` over a trackable scalar answers nothing without stepping `.[]`, and `eval_each_owned` answers it before the re-index bridge. jq mode only; a handler that is not `empty`, an untracked value (`1 | .[]?` still raises jq's path error), a container and every yq-mode query evaluate as before, and output (stdout, stderr and exit status) is identical to the parent binary on 1,558 query/document pairs, including documents jq cannot read.
