- **`jq --stream` reads a pipe named by path** (#7295). `printf '[1,2]' | succinctly jq -c --stream . /dev/stdin` (and `/dev/fd/0`, or a FIFO) exited 2 with `jq: error: Illegal seek` and printed nothing, valid input included; it now streams `[[0],1]`, `[[1],2]`, `[[1]]` and words a fault as jq 1.7.1 does. The reader probed each file for a BOM, closed it and opened it again at the byte after the BOM, which a pipe can neither be nor be seeked; a source that is not a regular file is now kept open and read on from the probe.
