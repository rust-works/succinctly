- **jq: a plain filter over more than 32 regular files reads them a window at a time too** (#7024). `jq -c . logs/*.json` over a list of more than 32 files read every file whole, since the several-files route held each file open for the second read that words a fault and capped the list to keep the descriptor table under 64 slots. Such a list is now judged a file at a time and closed, and each file is opened again as the run reaches it, and again by that second read, only while it is still the file judged (the same device and inode). A run over hundreds of files holds a few descriptors and its peak memory stays flat. A file removed or replaced at its path after the run starts is a read failure where the run reaches it (`jq: error: Could not open <path>: ...`, exit 2).
