- **jq: `modulemeta` reads a module's bytes lossily, as `import` does** (#7429). A module with a byte that is not UTF-8 in a comment or a string (`def f: "\xff";`) answered `null` with `stream did not contain valid UTF-8`; it now answers `{"deps":[],"defs":["f/0"]}` as jq 1.7.1 does, and the byte reads as U+FFFD in a string or a metadata value. A byte outside a comment or string is still a syntax error, as in jq.
