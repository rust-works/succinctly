- **jq: `implode` of an array a stage built no longer takes the reindex bridge** (#6523). `explode | implode`, `explode | map(. + 1) | implode` and `[.[] | explode | reverse | implode]` wrote the array out as JSON text, indexed it and read each number back; the array is now read in place and the string written once (a codepoint `char::from_u32` rejects is still U+FFFD, a fractional or non-number element still takes the bridge). `.strings | map(explode | implode)` over generated string files, against jq 1.7.1, interleaved on a Ryzen 9 7950X: 122 to 14 ms at 1 MB, 1204 to 119 ms at 10 MB and 12164 to 1171 ms at 100 MB (jq: 32, 311, 3142 ms, so 0.2x became 2.4x to 2.7x); on an Apple M5, 10 MB: 918 to 71 ms (jq 186 ms).
