- **jq: `implode` of an array a stage built no longer takes the reindex bridge** (#6523). `explode | implode`, `explode | map(. + 1) | implode` and `[.[] | explode | reverse | implode]` wrote the array out as JSON text, indexed it and read each number back; the array is now read in place and the string written once (a codepoint `char::from_u32` rejects is still U+FFFD, a fractional or non-number element still takes the bridge). `.strings | map(explode | implode)` over a 9 MB file: 918 ms to 71 ms (jq 1.7.1: 186 ms, so 0.20x became 2.6x) on an Apple M5.
