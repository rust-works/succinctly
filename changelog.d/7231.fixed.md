- **`succinctly yq` writes a node a chain writes twice in the style yq does** (#7231). When an earlier stage changes the node's kind or empties it (`.a = 5 | .a = [9]` over `a: [x, 1] # c1`), the node took its original flow style back (`a: [9] # c1`); it is now block with its comment held for the next line (`a:` / `  - 9` / `z: 1 # c1`), as in yq v4.53.3, whose assignment gives such a node the style of the value written. A chain that writes one node twice is reconciled a stage at a time, and a copy onto a node an earlier stage changed is judged by what that stage left. A random fuzz of 2,342 write chains against yq fixed 50 cases and changed none that already matched.
