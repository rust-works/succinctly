- **`succinctly yq` writes a node a chain writes twice in the style yq does** (#7231). When an earlier stage changes the node's kind or empties it (`.a = 5 | .a = [9]` over `a: [x, 1] # c1`), the node took its original flow style back (`a: [9] # c1`); it is now block with its comment held for the next line (`a:` / `  - 9` / `z: 1 # c1`), as in yq v4.53.3, whose assignment gives such a node the style of the value written. A chain of static writes (a literal, a copy, `+=` of a literal, `del`) that touches one node twice is replayed a stage at a time, with a copy's presentation placed at its own stage, so a copy also keeps what it brought when a later stage writes into it, replaces it or rewrites its source (`.c = .b | .b = 5` keeps `c: [1] # t`). A random fuzz of 3,832 write chains against yq fixed 101 cases and changed none that already matched.
