- **jq/yq: a literal-bound slice of an array no longer validates the elements it drops** (#6231). `.[:1]` on `["a","bad\x",3,4]` is `["a"]` and `.[2:]` is `[3,4]`, where both were a parse error (jq rejects the document); a slice that keeps the bad element still raises, as does a bad structure anywhere in the array (`[1 2 3]`, `[,]`, `[1,2,]`). `(.[1:])[0]` on `[tru]` is `null`, as the fused `.[1:][0]` always was. The computed spelling `E[S:T]` already behaved so for a bad value; recorded in `limitations.md` ("A slice of an array validates only the elements it keeps") and on the yq page.
