- **yq: an unspaced operator after a `.` or a name belongs to the name, as in yq's lexer** (#4237, closing #4079).
  yq's unquoted path element runs to the next space or one of ``; } { : [ ] , | . ( ) = ! `` and a newline, so
  `.a+1`, `.a>1`, `.a<3`, `.a%2`, `.>1` and `.+1` are the keys `a+1`, `a>1`, `a<3`, ... and not a sum or a comparison:
  `[1,2,3] | .[] | select(.>1)` selects nothing in yq and `select(.>=2)` selects all three (`.>` is a key assigned `2`).
  `succinctly yq` read them as operations. `.a + 1`, `.a >1`, `. > 1`, `.a==1` and `.a!=1` still compare, and
  `succinctly jq` is unchanged. A filter that relied on `.a+1` meaning a sum needs the spaces yq needs, and the same goes for a compound assignment:
  `.a+=1` is the assignment `.a+ = 1` and writes a key `a+` (as in yq); `.a += 1` increments `a`.
