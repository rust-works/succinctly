- **jq: `--seq` with `--stream` or `--stream-errors` reads each record as stream events** (#6115). The stream flag was ignored under `--seq`, so the filter saw whole documents: `printf '\x1e[1]\n\x1e{"a":2}\n' | succinctly jq -c --seq --stream .` printed `[1]` and `{"a":2}` where jq prints `[[0],1]`, `[[0]]`, `[["a"],2]` and `[["a"]]`. The records are now read by jq's streaming parser in its `--seq` mode. A record cut short emits the events read before the fault. Under `--stream-errors` a fault is the input `[message, path]`; under `--stream` it is jq's `ignoring parse error` warning, which a plain run and `-s` read past and a program's own `input` raises. A run over 734 flag, input and program combinations matches jq 1.7.1's stdout, stderr and exit code.
