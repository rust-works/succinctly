- **yq: a sequence built from nodes of the document keeps each node's tag, comment, anchor and quoting** (#5429). `[.Outputs[]]` over a CloudFormation template printed `Value: Bucket` where yq prints `Value: !Ref Bucket # the bucket`, so a template read back as a different document. The same filters now answer as yq does: `[.[]]` and `[.[] | select(...)]`, `[(.a, .b)]`, `[.a] + [.b]`, a literal-bound array slice (`.[1:]`, `.a[:2]`), `flatten` and `flatten(n)`, and `map_values(f)` over a mapping. `-o=json` is unchanged. A filter that goes through a variable (`.a as $x | [$x]`), takes a further stage after the construction, or iterates inside a construction operand still prints the plain value (`docs/compliance/yq/limitations.md`).
