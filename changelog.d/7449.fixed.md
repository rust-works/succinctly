- **jq: `not`, `if`, `and`, `or`, `select`, `//`, `any` and `all` on a malformed scalar token raise jq's parse error** (#7449). A token the index could not read (`tru`, `nulll`, `nul`, `x`, `1.2.3`, `-`, `1e`) read as truthy, so `[tru] | .[0] | not` was `false` and `[nul] | .[0] | not` was `false` where `[null]` gives `true`, all with exit 0, as a top-level document, an array element, an object value or an NDJSON line, where jq rejects the document. They now print jq's `parse error` with its line and column and exit 5, as `type` on the same token already did. A container is still truthy whatever it holds (#2692), and a string whatever its escapes spell (#5308).
