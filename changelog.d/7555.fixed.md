- **jq: `all(f)` and `any(f)` over an array with a stray, doubled or missing `,` raise jq's parse error, as `all(.[]; f)` does** (#7555). `[1,] | all(. < 5)` answered `true` and `[1 2] | all(. == 1)` answered `false`, computed from the `2` after the missing comma, where jq (which defines `all(f)` as `all(.[]; f)`) rejects the document. The walk now checks each element's `,` as it reaches it and the gap before the `]` when it runs out, as `.[]` does, so an answer decided before the fault still stops there. Arity-0 `any`/`all` on the zero-member `{,}` raise too, as they already did on `{"a":1,}`; on an array they still answer, by design (#2692).
