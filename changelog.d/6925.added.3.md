- **`succinctly yq -p csv` and `-p tsv`** (#6925). Reads a table as yq v4.53.3 does: a port of Go's `encoding/csv` reader (its errors with Go's line and column, blank lines skipped, a field count that must match the header's), each record a mapping of the header's names, and each cell a snippet of YAML (`5 # c` an integer, `[1,2]` a sequence, `'x'` the string with its quotes) unless `--csv-auto-parse=false` / `--tsv-auto-parse=false`; `--csv-separator` is read too. Under `-p auto` a first file named `*.csv` or `*.tsv` picks the format and prints in it, and `-i` writes it back. It agrees with yq on 6,500 random tables and 7,000 random byte strings, apart from the rows recorded in `docs/compliance/yq/limitations.md`.
