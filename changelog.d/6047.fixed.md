- **jq: `-C` no longer colors a top-level string under `-a` with `-r`, `-j` or `--raw-output0`** (#6047).
  jq writes such a string quoted and escaped through a branch that has no color flag, so
  `echo '"é"' | jq -C -r -a .` prints `"é"` with no escape sequences, for any string and not only
  a non-ASCII one. `succinctly jq` colored it. A string inside a container, a non-string, and `-C` with
  only `-a` or only `-r` are unchanged.
