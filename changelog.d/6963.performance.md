- **yq: a run of `---` markers on one line is read in linear time** (#6963). `--- --- --- ... a` cost the length of the line for every marker, because `yq`'s header preprocessing copied the rest of the line out for each one: 80,000 markers took 9.4 s on an AMD Ryzen 9 7950X and 4.2 s on an Apple M4 Pro, 160,000 took 39.3 s and 16.8 s, and 320,000 did not finish in a minute. A marker followed by text is now settled from the bytes around it, and the rest of the line is an offset, not a copy: 1,280,000 markers (5 MB) read in the same 0.07 s (7950X) and 0.09 s (M4 Pro) as 5,000, which is the floor of the memory-capped harness. The output is the same, checked over all 402,234 short header inputs against the copying implementation and 16,000 end-to-end runs against an older build.
