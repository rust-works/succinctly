- **yq: an empty `as` source runs its body once, and an empty index operand stands for every child** (#4139).
  `select(false) as $z | .a` is `.a` in yq (the variable stays unset); it printed nothing here. `.[E]` with no output
  is `.[]`, so `.b[$typo] = 1` sets every element, `.b[$typo] += 1` and `.[$typo] |= f` update them, `del(.[$typo])`
  deletes them all and `.b[$typo]` prints them, while here the same filters left the document unchanged and exited 0.
  `has(E)` with no output is `false`. A scalar operand has no children, so those writes stay no-ops. jq mode is
  unchanged.
