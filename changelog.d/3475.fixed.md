- **yq: `[.]` over a mapping with a collection as its key prints the key as yq does** (#3475).
  `printf '? [a, b]\n: 1\n' | yq '[.]'` prints `- ? [a, b]` / `  : 1`, where it printed `- '': 1`. It follows from an array of the
  document's own nodes streaming from the nodes instead of copying them, so a document with a comment or an alias keeps the
  old output.
