- **A `foreach` UPDATE comma with a non-navigating pipe sibling no longer drops the write** (#3959). `del(foreach .a as $v (.; (($v | .b?), (.|length)); try ($v | .b?)))` left the document unchanged with exit 0 where jq deletes; a sibling pipe of stages that cannot move the register (`(.|length)`, `(2|.+1)`, `(.|tostring)`) is now read as leaving it where the pipe entered, as a bare `length` already was (`=`, `|=`, `del()` and `path()`).
