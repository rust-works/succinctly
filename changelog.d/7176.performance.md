- **jq: a program that reads `input`/`inputs` over several files no longer walks every file through jq's parser model before it starts, when every file opened** (#7176). `read_inputs` ran `first_stream_fault` over all the files twice (for `ends_cleanly` and for the end-of-text flag of `defer_open_failures`), but both answers only place a file that failed to open; with none, `all` over no failure is true and the flag is read by nothing. They are skipped when no file failed. Interleaved A/B with an A/A control (outputs identical): `-n 'first(inputs) | .id'` over 100 MiB of NDJSON in 4 or 33 files reads 762 ms to 51 ms on a Ryzen 9 7950X and 860 ms to 15 ms on an M4 Pro (and 78 to 6.4 ms and 92 to 4.6 ms at 10 MiB), `-n 'reduce inputs as $x (0; . + 1)'` 47% and 52% faster, `-c '[., input] | length'` 27% to 36% faster; peak RSS is unchanged.
