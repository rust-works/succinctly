- **jq: `EXPR as $x | body` no longer decodes the bound node unless `body` reads it** (#3856). A bind used to decode its whole source whether or not `$x` was read, so `. as $root | .users[] | .name` decoded the entire document for a variable it never named (6.5x the memory and 4-5x the time of the same filter without the bind). The node is now held as a name (`Expr::DeferredVar`) that each read re-resolves to a cursor, when the body never names `$x` (a subtree; a scalar is decoded as before and kept only if that decode failed) or when `$x` is only read where the ambient input is provably a node of the same document (`deferred_bind_is_sound`: at the bind's input, or under `.[]`; not after a stage that may leave no cursor such as `.missing`, `1`, `length`, nor inside `map`, `reduce`, `path(...)`, a `def` or string interpolation, which keep the eager decode). Apple M5 Max, release build, instructions retired (min of 3-5, interleaved against the commit before) and peak RSS, `users` documents of 0.7 / 7 / 26 MB: `. as $x | 1` -72% / -86% / -87% instructions and 17 MB -> 10 MB / 81 MB -> 18 MB / 262 MB -> 42 MB; `. as $r | .users[] | .name` -57% / -66% / -66%; `.users[] | . as $u | .name` -56% / -64% / -65%; `. as $x | .users[] | select(.age > 20) | .name` -45% / -50% / -51%; `. as $r | .users | map(.age + 1) | length` -51% / -58% / -59%; `.users[] | . as $u | {id: $u.id, a: ($u.age + 1)}` -30% / -32% / -33%. Scalar binds (`.users[] | .name as $u | $u`), `reduce`, dollar-parameter `def` calls, `path(.a as $y | ...)`, a recursive `fib($n)` and `succinctly yq` over YAML (including an alias/merge-key document) are within +-0.5%, which is the harness's noise on a loaded laptop (one binary read +0.9% and +0.3% across two runs). Output identical on every row. On a document with a member the index cannot read, `. as $x | 1` and `. as $x | $x.a` now answer and `. as $x | $x` echoes the node as `.` does, where they raised at the bind; anything that decodes the node still raises where it does (`docs/compliance/jq/limitations.md`). Pinned by a differential sweep of deferred against decoding binds over generated bodies and documents through both the collecting and the streaming entry (`deferred_bind_agrees_with_the_decoding_bind_3856`, mutation-checked), the predicate's table (`src/jq/deferred_bind.rs`), and `test_deferred_bind_matches_jq_3856` against `/usr/bin/jq` 1.7.1.
