- **jq: a `foreach` whose EXTRACT is an array or object of reads of the state is faster** (#6629).
  `[foreach range(n) as $i ({a: 1, b: 2}; .a += 1; [.a, .b])]` builds the EXTRACT's constructor on the
  owned tree, as one holding the state itself already did (#6581); the numbers follow the measurement.
  Whether an EXTRACT is such a constructor is now decided once per fold rather than walked for every step,
  and a fork stops offering a shape the state never fits after four declines. Output is identical to jq 1.7.1's.
