- **`succinctly yq`'s `@base64d`, `@urid` and `load_str` write one U+FFFD per invalid byte, as yq does** (#7000). A truncated UTF-8 sequence in the decoded bytes (`"4oI=" | @base64d`, the bytes `e2 82`) is two U+FFFD under `-o json`, Go's count, which yq's JSON encoder writes for the raw bytes it keeps; it was one, Rust's maximal-subpart rule. An `@base64d` fuzz over 500 random binary payloads now agrees with yq v4.53.3 on every one.
