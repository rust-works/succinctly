- **yq: `array_to_map`** (#5458). Real yq (v4.53.3) turns an array into a map keyed by index, skipping null elements
  (`.l | array_to_map` over `[{k: 1}, null, [2]]` is `{"0": {"k": 1}, "2": [2]}`), returns a map as it is and answers `{}` for
  anything else; `succinctly yq` answered `array_to_map/0 is not defined`. It is a parser-level desugar over
  `to_entries`/`from_entries`, so its keys are strings where yq's are ints (`keys` differs) and a nested container prints in
  block style; values and `-o=json` output agree. `succinctly jq` is unchanged.
