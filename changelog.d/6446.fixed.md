- **yq: a folded scalar that starts with blank lines is written with the blank lines it had** (#6446). The streaming route (`.`) widened the run of breaks a `>` scalar starts with, one empty line too many, which changed the value when read back (`a: >` / blank / blank / `  x`, the value `"\n\nx\n"`, came out with a third blank line), and a `>+` of nothing but blank lines gained a trailing one. go-yaml's folded writer widens nothing for a string that starts with a break and adds no trailing extra to a value of only breaks; the write route (`.zzkey = 1`, `-P`, `-i`) already agreed with yq. Over a fuzz of random folded scalars every document whose yq output reads back as the same value is now byte-identical to yq on `.`. A break beside a more-indented line keeps the lossless spelling ADR-0018 and #836 chose, where yq adds an empty line that changes the value. Pinned against yq v4.53.3 in `tests/yq_cli/i6446.rs`.
