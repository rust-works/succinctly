- **`succinctly jq` runs a builtin once per value of a generator argument, as jq does** (#7474). A builtin whose argument jq binds per value (`ltrimstr`, `has`, `getpath`, `setpath`, `test`/`match`/`capture`/`scan`, `sub`/`gsub`'s regex and flags, `split`, `join`, `contains`, `indices`, `flatten`, `nth`, `bsearch`, `strftime`, `format`, `pow` and every two- and three-argument math function, 81 builtin/argument positions in all) ran that argument to the end before its first output, so `"xa" | first(ltrimstr(repeat("x")))` never answered and grew memory, and `first(ltrimstr(inputs | tostring))` read every input. The argument is now bound first, in jq's own nesting order, so `first`, `limit` and an error stop it where jq does; a call whose arguments each yield one value is unchanged.
