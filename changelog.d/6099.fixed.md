- **yq: `sort_by(key)` on a mapping sorts by the key** (#6099). yq sorts a mapping's entries by the key filter with `key` naming the entry's key node (its "Sort a map by keys" example, `sort_by(key | downcase)` too). `succinctly yq` ran the filter on the entry's value, where `key` names nothing, so the mapping came back in its input order. `key` at the head of the filter (`key`, `key | f`, a comma of those) now reads the entry's key, which sorts by the kind the text resolves to (`null`, then booleans, numbers, strings), so `10` follows `9`. A `key` below another step (`.a | key`) is unchanged. A quoted key that reads as a number or boolean sorts as one: the mapping reaches the sort as JSON text, which no longer says it was quoted.
