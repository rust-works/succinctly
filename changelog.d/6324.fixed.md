- **jq: `strptime` and `fromdate` read the date string and the format as C strings, so a NUL byte ends each, as jq's do** (#6324). `"2015-03-05T23:51:47Z\u0000junk" | fromdate` is `1425599507` in jq 1.7.1 and was an error here; `"\u0000" | try fromdate catch .` now says `date "" does not match format ...` and `"2015-03-05" | strptime("%Y-%m-%d\u0000junk")` parses. Found by a differential of every zero-arity builtin against 80 edge-case inputs, where these two were the only builtins that differed.
