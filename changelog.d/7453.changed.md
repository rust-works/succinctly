- **`succinctly jq` negates a number literal as jq 1.8 does: the result is still a literal** (#7453). jq 1.7.1 turned `-1.500` into the double `-1.5`; jq 1.8 keeps the decimal (jqlang/jq#3242, fixing the bug jqlang/jq#2704), and `succinctly jq` now follows it. `-1.500` prints `-1.500`, `-1e1000` `-1E+1000`, `-9007199254740993` keeps every digit, and `-1` compares with an input `-1.00000000000000000001` exactly (unequal). The same holds for `-(1.500)`, `-$x` and `-.` on an input or `--argjson` literal. As in jq 1.8, a zero negates to positive zero (`-0` is `0`, `-0.0` is `0.0`), and a negated literal is a fresh value for `path()` (`[-1] | path(.[0] | -1)` is refused). A computed number is negated as before. `succinctly yq` is unchanged.
