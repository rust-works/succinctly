- **yq: `-o` defaults to `auto`, so a `.json` file prints JSON, as in yq** (#6703).
  yq's `--output-format` defaults to `auto` (the run's own input format, picked once from the first file's extension),
  so `yq '.b' data.json` prints JSON; `succinctly yq` defaulted to `yaml` and printed YAML, which broke a script that piped a JSON
  file through `yq` and read the result as JSON. The default is now `auto`: a `.json` file prints JSON (`-I`, `-P`, `-r`, `-N`,
  writes and several files included), and standard input, `.yaml`, `.yml`, any other name, `-n`, `-R`, `--front-matter` and an
  explicit `-p` keep YAML. An explicit `-o=yaml` still prints YAML for a JSON file. A mixed `--slurp -o=auto` over a YAML and a
  JSON file now keeps the JSON mapping's flow style as yq does (#1493's recorded gap). Checked against yq v4.53.3 over 32 runs.
