- **yq: a metadata write buried in a destructuring pattern's computed key is refused, not dropped** (#3203).
  `. as {((.a line_comment = "x") | .a): $v} | .` printed the document and exit 0 with the comment
  silently missing, because the gate that decides whether the metadata pass runs
  (`is_alias_sensitive_assign`) looked only at the `as` body and never at the pattern's keys; it now
  refuses it with `only supported as a top-level pipe stage`, like every other buried write (#798). A
  value-shaped write in a key (`=`, `|=`, `del`) still opens nothing: it runs against the bound value
  to build a key, never against the document the body returns.
