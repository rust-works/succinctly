- **jq: `--stream-errors` and `--stream` over input that opens with a broken byte-order mark say `Malformed BOM`, as jq does** (#7603). `printf '\xef1\n' | jq -c --stream-errors .` printed a `["Invalid numeric literal at line 2, column 0",[]]` event and exited 0, where jq 1.7.1 and 1.8.2 print `jq: parse error: Malformed BOM` and exit 5: jq's parser returns that error before it scans a byte, on every read, and `--stream-errors` does not turn it into an event. Under `-n` every `input` now raises `Malformed BOM` (`[try input catch ., try input catch .]` is `["Malformed BOM","Malformed BOM"]`), and `--stream` words the fault that way too.
