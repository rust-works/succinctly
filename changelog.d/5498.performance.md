- **jq: `--stream-errors` reads a string or number token without the document parser's index** (#5498, first slice).
  The `jv_parse.c` port built a `JsonIndex` for every scalar token it handed out; a string with no escape and
  valid UTF-8 is now its own bytes, and a number is read by `OwnedValue::from_number_bytes`, which keeps the
  literal's spelling. `-n 'reduce (inputs|select(length==2)) as $e (0;.+1)'` over a generated `users` document,
  interleaved A/B on an AMD Ryzen 9 7950X, best of 7: 10 MB (6.9 MB) 0.47 s -> 0.32 s, 50 MB (35 MB)
  2.40 s -> 1.65 s, output byte-identical; the index route (`--stream`) is the control and unchanged at 0.37 s
  and 1.68 s. Peak memory is unchanged (216 MB at 10 MB): `--stream` still holds the event list, which later
  slices of #5498 remove. Not measured on ARM.
