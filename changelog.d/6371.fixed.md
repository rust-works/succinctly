- **yaml: an explicit key's plain scalar that a comment ended takes no more lines, as in yq** (#6371). `printf '? a⏎  b # c⏎  d⏎: v⏎' | succinctly yq -o json .` printed `{"a b":"d"}`, the line after the comment read as the entry's value and the `: v` line lost; yq stops with `did not find expected key`, and so does `succinctly yq` now, for a line more indented than the `?` that follows the comment (`? a # c⏎  b⏎: v`, a comment line between, a deeper `- x` or `k: v`). A comment followed directly by the `:` line or the next key still reads. Over 3,600 generated explicit-key documents with comments and continuation lines, the 1,430 that differed from yq now agree and none changed the other way.
