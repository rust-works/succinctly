- **`succinctly jq -s --stream` keeps the events read before an end-of-input fault, as jq does** (#6061). jq closes the slurp array at the call that consumes the last byte, so an event that byte completes is in the array and the fault comes after it: `printf '1[' | jq -cs --stream .` prints `[[[],1]]` and then the parse error, `[1,` prints `[[[0],1]]` and `[{}` prints `[[[0],{}]]`; it printed nothing. A fault met by that call or an earlier one (`[1,2`, `1 [`) is still the whole result. Checked on 10,640 runs against jq 1.7.1.
