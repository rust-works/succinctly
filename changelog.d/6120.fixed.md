- **jq: a module name that starts with `/` is joined onto each search directory** (#6120). `import "/a" as a` with `-L lib` found no module (`module not found: /a`) where jq reads `lib//a.jq`, i.e. `lib/a.jq`, and `import "<abs path>/a"` found one jq reports as not found; `include`, a data import (`import "/d" as $d`) and `modulemeta` followed. The name is now joined onto every search directory the way jq does, with `-L /` the one way to reach an absolute path.
