- **`succinctly jq --stream` and `--stream-errors` report a directory given last when a read reaches it, as jq does** (#6624). A last value that completes only at the end of its file (`1` with no newline) reads on into the directory, so the program's next read now prints `jq: error: Is a directory` (`jq -c --stream input p.json dir`, `jq -n --stream '[inputs]' p.json dir`), and so does a read after the one that found the stream at its end. A plain `--stream .` and a `-n` program that stops before either never say it, as jq's main loop reads no more once a read has failed. Before, the chunked stream reader counted the directory (exit 2) and never printed it.
