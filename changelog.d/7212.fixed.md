- **yq `-p xml -o xml` keeps a comment on the node yq's decoder gave it** (#7212). A comment after a closing tag (`<x/><!-- c --><y>2</y>`, `</x><!-- c --></r>`) was attributed by the YAML text the read hands the run, so it moved to the next element, onto the last child of a block, to the end of the document, or gained a break (`<!-- c` and a line break before `-->`). The decoder's own comments are now what the XML encoder writes, entry by entry while a write leaves the key at its place. A sweep of 772 local XML and plist files with a comment differs from yq in 0 files, where 31 differed before. A run that reads several XML files keeps the old attribution.
