- **yq: a comma body of `|=` applies every assignment in it** (#6854). yq evaluates the body of `.a |= BODY` against the target node itself, so an assignment in it changes that node in place and the update, which takes the first output, ends with all of them: `.a |= (.x = 7, .y = 1)` sets both `x` and `y`. `succinctly yq` applied only the first. A comma whose first branch answers the node (an assignment, `del`, `.`, `select(..)`, alone, piped or grouped) is now read as `with(PATH; BODY)` reads its update: the writes run in order on the evolving node and any other branch is still evaluated for its errors. A body that starts with a value (`5`, `.x`) keeps its first output, and `succinctly jq` is unchanged. 22 rows in `tests/yq_cli/i6854.rs` match yq v4.53.3, among them the merged-member form `.list[] |= (.x = 7, .y = 1)` over mappings that merge one source, which #6827 had listed as still differing.
