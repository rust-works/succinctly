- **jq: a comma between a `def`'s parameters is a syntax error** (#7457). `def f(a,b): a; f(5;6)` was accepted with the comma taken for a `;` and printed `5`; jq refuses it (`unexpected ','`, exit 3) and so does `succinctly jq` now, for bare and `$` parameters and in `-f` files and modules. Parameters are separated by `;` only; a comma in a call's argument is still the comma operator (`f(1,2)` is one argument).
