- **jq: `--seq -s --stream-errors` says `Is a directory` for a last directory after a program's `input`** (#6789). Under `--seq -s --stream-errors`, a program that reads one `input` over an unfinished record and a last directory printed the fault as an event but never said `jq: error: Is a directory`; jq says it on that read, since the slurp's own read went through the directory and the program's read after it is the next one the reader is asked for. A slurp's last directory is now said by the first read the program makes after the slurp's own, wherever that read comes from, as well as by the read that finds the stream at its end (`jq -c --seq -s --stream-errors input trunc pa dir` now exits 2 with `Is a directory`, as jq 1.7.1 does).
