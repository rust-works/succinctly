- **jq: `\X`, the extended grapheme cluster escape, is read as in jq** (#6220). `"éa" | match("\\X";"g")` failed with the `regex` crate's `unrecognized escape sequence`. It now matches one cluster as Unicode UAX #29 defines it (CR LF, a lone control, a prepend run, a regional-indicator pair, a Hangul syllable, an emoji joined by ZWJ, then the extending marks), as an atomic group, so a cluster is never given back in part, and is refused inside a look-behind as in jq. Checked against jq 1.7.1 over 85,259 strings drawn from every break class and 800,000 random strings; the differences left are characters whose break class changed after jq's Unicode tables (U+1B44 and U+A9C0 in Unicode 15.1, and the Unicode 16 additions), listed in `docs/compliance/jq/limitations.md`.
