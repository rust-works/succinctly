- **jq: `delpaths` over a string or a `null` words its error as jq does for a path of two or more components** (#6012). jq reads the first key of such a path with `jv_get` before it reaches the next one. On a string an object key is a slice descriptor, so `"abc" | delpaths([[{"a":1},0]])` is `Array/string slice indices must be integers` (it was `Cannot index string with object`), and a descriptor that is valid (`{"start":1,"end":2}`) names a substring the rest of the path cannot delete from, `Cannot delete fields from string`. On a `null` root a `null`, boolean or array key is `Cannot index null with <kind>`, where this answered `null`; a `null` child is still skipped before jq descends, so `[null,[1]] | delpaths([[0,[1],0]])` is unchanged. Checked against jq 1.7.1 over 429 rows (29 paths, 13 inputs of every kind): all match, 44 differed before. yq is unchanged.
