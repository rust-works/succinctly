- **`succinctly yq -p xml`** (#6925). Reads XML as yq v4.53.3 does: a port of Go's `encoding/xml` decoder (`RawToken` by default, `Token` under `--xml-raw-token=false`, lenient unless `--xml-strict-mode`, its error messages, the single-byte charsets a declared `encoding` opens) and of yq's `decoder_xml.go`: an element is a mapping of its attributes (`+@name`) and children in document order, a repeated name a sequence, its text `+content`, every value a string, a processing instruction `+p_<target>`, a directive `+directive`, and a comment a head, line or foot comment by where it sits. `--xml-keep-namespace`, `--xml-skip-proc-inst` and `--xml-skip-directives` are read with the flags `-o xml` already took. Under `-p auto` a first file named `*.xml` or `*.x` picks the format and prints in it, `-i` writes it back, and an empty element read from XML is written back empty. Agrees with yq on random documents and their mutations under `-o json` (`scripts/yq-xml-input-sweep.py`); the rows that differ (a Go panic on markup after the root's end tag, the blank line and depth of some comments, the multi-byte charsets) are in `docs/compliance/yq/limitations.md`.
