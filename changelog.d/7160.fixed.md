- **yq: `-o toml` writes the comments yq's TOML encoder writes, where it dropped every one** (#7160). The root mapping's head comment goes first, a table's above its `[header]`, an attribute's head comment above it and its line comment after it (`printf 'a: 1 # l\n' | yq -o toml .` is `a = 1  # l`), an array's the same, and an array whose elements have head comments is written in the multi-line form with each above its element. Read from the node the result came from and, for a write (`=`, `del()`, `sort_keys`), from its presentation tree, as `-o xml` does (#7117, #7156). A run that read TOML writes no comment, as before: the `-p toml` read cannot place them on the value nodes the encoder looks at. Pinned against 38 rows from yq v4.53.3, 300-document sweeps of the read and five write filters and 255 rows over tables, arrays of tables and arrays with no difference; `with_entries`, `. * {..}` and `--eval-all` still drop them (limitations.md).
