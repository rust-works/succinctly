- **jq: `--stream -s` leaves the last closing event out of the slurped array when nothing follows it** (#5548).
  `printf '[1,2]' | jq -c --stream -s .` prints `[[[0],1],[[1],2]]` and then `[[1]]` as a value of its own, because jq's
  streaming parser emits the closer of a top-level array or object that ends in a scalar only once its input is
  exhausted, after the array is done; `succinctly jq` put it in the array. Any byte after the closer (a newline, a space)
  or a closer that ends in a container (`[1,[2]]`) keeps it in the array, as in jq, and only the last file decides. The
  held-back event is an input of its own for the program (`-s length` prints `2` and then `1`) and reads
  `input_line_number` 0.
