- **cli: the default build starts about 22% faster on macOS** (#5551). `ctrlc` was a dependency of the `cli` feature, but only the benchmark runners use it (to write partial results on Ctrl+C), and on Apple targets it links `libobjc`, `Foundation` and `CoreFoundation`, which dyld loads on every start. It is now a `bench-runner` dependency: the shipped binary links `libSystem` and `libiconv` only, and `succinctly jq -n 1` starts in 2.86 ms instead of 3.68 ms (median of 300 interleaved spawns, Apple M5 Max; `--version` 2.82 ms instead of 3.67 ms). Without `bench-runner`, Ctrl+C during `dev bench`, `utf8 bench` and the like ends the run the default way instead of writing the results so far; `bench-runner` builds keep the handler.
