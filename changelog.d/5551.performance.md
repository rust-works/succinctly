- **macOS: `sjq`/`syq`/`succinctly` start about 0.8 ms faster and use about 4.5 MB less memory** (#5551).
  The `cli` feature no longer pulls in `ctrlc`, which on Apple targets brought `objc2` and linked
  Foundation, CoreFoundation and `libobjc` into every process. `succinctly jq -n 1` now starts in 2.36 ms
  instead of 3.18 ms and peaks at 4.8 MB instead of 9.4 MB on an Apple M4 Pro, level with jq 1.7.1's
  2.36 ms. `dev bench {jq,yq,dsv,utf8}` only catch Ctrl+C (to write partial results) in a
  `bench-runner` build; without that feature Ctrl+C ends the run at once.
