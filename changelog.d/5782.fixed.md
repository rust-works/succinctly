- **jq: dropping a value built millions of levels deep no longer aborts the process** (#5782). `succinctly jq -n 'reduce range(10000000) as $i ([]; .[0] = .) | length'` overflowed the native stack in `OwnedValue`'s drop glue (exit 134) and now prints `1`, as does the object form (`.a = .`). jq 1.7.1 segfaults on the same program from about 300,000 levels, so there is nothing to match (ADR-0018). A unique array or object that holds a unique container now takes its subtree down on a heap worklist, reusing the root's own `Vec` for it; a container of scalars or shared handles still drops through the ordinary glue after one read-only scan.
