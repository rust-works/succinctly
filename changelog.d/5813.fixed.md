- **yq: an alias key printed as its text keeps its anchor's quoting** (#5813).
  When the soundness pass drops a key alias (`*a : 1`) because the anchor is gone (`del(.b)` on `b: &a "true"`), the key used to print bare, so the string `"true"` became the bool key `true`.
  It now takes the quoting of its anchor's node: `"true": 1`, `'1': 1`, `"12": 1` for `!!str 12`.
  Where the anchor survives the key is still `*a`, as in yq.
