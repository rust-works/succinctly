- **jq: `--stream` over a document with a syntax error part-way through prints the events before it** (#5635). `[1,2,3 x]` and `{"a":1,"b":[2,@]}` printed nothing for that document; they now print `[[0],1]` `[[1],2]` and `[["a"],1]` `[["b",0],2]`, as jq 1.7.1 does, and then raise the error (exit 5). The events come from the port of jq's streaming parser that `--stream-errors` reads with, so `input_line_number` names the line jq had read when it yielded each, and a program using `input`/`inputs` reads them before the fault it resumes after. A number or literal that the fault's own byte completes (`22]`) is no longer printed, as in jq. A stream that fails to parse is expanded to events up front, so a large input with a late syntax error holds its earlier documents' events in memory first.
