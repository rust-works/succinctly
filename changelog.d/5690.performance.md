- **jq: a program that only reads a container named argument gets it as one shared value, not a literal tree rebuilt at every `$name`** (#5690). `-n --slurpfile d users.json '$d[0].users|length'` over 10 MB takes 75 ms instead of 177 ms and over 100 MB 711 ms instead of 1718 ms (-57% to -59%; `--argjson` and `$ARGS` likewise) on an Apple M5 Max, and a 1 MB file's `map`/`select` reads are 36% to 40% faster. A program with an assignment, a fold, a path expression (`path`, `paths`, `del`, `getpath` target, `pick`) or a definition keeps the literal, as before, so a write through the value and a dynamic path target answer as they did.
