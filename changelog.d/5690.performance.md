- **jq: a program that only reads a container named argument gets it as one shared value, not a literal tree rebuilt at every `$name`** (#5690). `-n --slurpfile d users.json '$d[0].users|length'` is 58% to 66% faster on an AMD Ryzen 9 7950X (10 MB: 379 ms to 127 ms; 100 MB: 3.53 s to 1.31 s) and 55% to 57% faster on an Apple M4 Pro (100 MB: 1.68 s to 0.72 s); `[$d[0].users[]|select(.age>40)]|length` is 48% to 60% faster; `--argjson` and `$ARGS` likewise. A program with an assignment, a fold, a path expression (`path`, `paths`, `del`, `pick`, a `getpath` or `setpath` target) or a definition keeps the literal, as before (within noise), so a write through the value and a dynamic path target answer as they did.
