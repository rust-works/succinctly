- **jq: a fold whose INIT navigates and then computes no longer writes through the wrong node** (#4013, a #4007 follow-up). `(foreach (null) as {a:$x} (.a|tostring; .; $x)) = 5` is `{"a":{"a":5}}` in jq and was `{"a":5}` here (and `path(...)` was `["a"]` for jq's `["a","a"]`; `reduce`, `|=` and a `length` INIT the same): INIT's navigation moved jq's register off the root, but the fold seeded its register from the ambient value, so the loop pattern walked from the wrong place. A fold whose INIT can have moved the register now has no register to walk from, so the program refuses (exit 5) where jq answers; an INIT that only computes (`tostring`) or only navigates is unchanged.
