- **jq: `-R` holds half the memory it did, over a pipe and over a file** (#7323).
  Over a pipe, the 4 MiB probe was copied whole to make the first window while the probe was still held
  (since #7264), and every window was read while the text of the one before was still held, so `-R` over a
  file held two 1 MiB windows at once. The probe is now the first window's own buffer, and a window's text
  is dropped before the next is read. `cat ndjson-100mb.json | succinctly jq -R length` peaks at 4.02 MiB
  of heap in DHAT instead of 8.02 MiB on an AMD Ryzen 9 7950X (peak RSS 12.2 MiB instead of 15.9 MiB), and
  the same file named on the command line at 1.02 MiB instead of 2.02 MiB (9.5 MiB RSS instead of 11.6
  MiB), the same at 16 MB and 100 MB, with wall-clock time unchanged. What is left over a pipe is the probe
  itself, which the route reads to decide whether to window the stream.
