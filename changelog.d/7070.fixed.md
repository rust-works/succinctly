- **yq: `+=` of a scalar onto a sequence copies the first element's quote style** (#7070). `.a += "cat"` on `a: ['dog']` printed `a: ['dog', cat]` where yq prints `a: ['dog', 'cat']`: yq's `+` gives a scalar it appends the style of the sequence's first element (`toNodes`), and the write route replayed the old document's presentation, which the new element has none of. A lone `+=` onto a static path now copies a single or double quote from the first element, as the construction form `.a + "cat"` already did. A number or boolean (yq quotes it too), a comma of targets, a computed right side and `.a = .a + "z"` keep the old output (limitations.md). Pinned against 19 rows captured from yq v4.53.3.
