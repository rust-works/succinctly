- **`succinctly yq` reads the argument of `env(..)` and `strenv(..)` as yq's lexer does** (#7070). The name is the raw text up to the first `)`, so the docs' own `yq -n 'strenv("MYENV")'` is an empty line (it looks up a variable called `"MYENV"`, quotes included) and `env("NAME")` names `"NAME"` in its `not provided` error; it was `parse error ... expected identifier, found '"'`. `strenv( X )`, `strenv(a;b)`, `strenv(1)` and `strenv(.a)` name the variables ` X `, `a;b`, `1` and `.a`. 19 rows from yq v4.53.3 are pinned. jq mode keeps the identifier.
