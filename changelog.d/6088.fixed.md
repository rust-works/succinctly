- **yq: `$i | path`, `key`, `parent`, `line`, `column` and the other node reads of a `SRC as $i ireduce (INIT; UPDATE)` loop variable answer from the node `$i` is bound to** (#6088). The fold bound the element's value, so `$i | path` was `[]` and yq's documented prune example, `(.b.c2, .c.c1) as $i ireduce({}; setpath($i | path; $i))`, printed the last value (`z`) instead of the pruned document; `$i | key` printed nothing and `$i | line` printed `0`. They now print what yq does, as do `tag`, `style`, `anchor`, the comment readers and `document_index`. A read followed by more stages (`$i | path | length`) is covered; a node reached through a step first (`$i | parent | key`) still sees a value.
