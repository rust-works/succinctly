- **jq: `-R` stops after the first line past a missing file, as jq's main loop does** (#6464). `jq -R . missing.txt lines.txt` printed every line of `lines.txt` and jq 1.7.1 prints the first (`"line1"`), the same rule JSON documents already followed (#5472): once the reader has read from a file past one that did not open, the value that took it there is processed and the loop ends. `jq -R . lines.txt missing.txt lines.txt` prints up to the first line of the second `lines.txt`, joined to the last line of the first as jq does.
