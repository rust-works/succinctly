- **jq: a `reduce` whose UPDATE is a `try ... catch` handler that navigates is refused in path position, as jq refuses it** (#4126).
  `del(reduce 1 as $k (.; try (., error) catch (.a)?))` wrote `null` over the whole document, and
  `path(reduce (1,2) as $k (.; try (., error) catch (.a)?))` printed `[]`, where jq raises
  `Invalid path expression with result ...` (exit 5). Over a source and INIT that cannot move jq's register,
  the handler now runs with `.` on the register, so its `.a` moves it off the accumulator and the final path
  check refuses. A navigating source (`reduce .[]? as $k (...)`) still answers `[]`, as jq does.
