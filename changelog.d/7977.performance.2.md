- **jq: the experimental call machine builds a call-free `[...]` or `reduce` in one pass** (#7977, step 3 of its migration plan).
  Under `SUCCINCTLY_CALL_MACHINE=1`, a call-free subtree may now hold `.[]` and `range(n)` where it takes all their outputs itself, under a `[...]` or in a `reduce`, so a call-free `[...]` or `reduce` is one leaf run by the path-mode interpreter, where the machine took a fork point and a backtrack per element.
  `def w($n): if $n == 0 then first(.[]) else w($n - 1) end; [range(1000000)] | w(1)` retires 179M instructions, against 503M before and 217M with the switch off (Apple M5 Max); this was the one routed ladder cell slower than the shipped route.
  A generator a consumer can stop (`first(.[])`, `limit`, a label) is still run one element at a time.
  An object constructor or string interpolation that holds a collected generator (`{a: [.[]]}`) is now run by the machine rather than declining the program.
  A leaf reads its free variables from the machine's slots through a borrowed view instead of building an environment frame per variable on each run.
  With the switch unset or `0` nothing changes.
