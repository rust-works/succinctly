- **jq: a fault `input` raises in bytes moved across several files names the file jq read them in** (#6004, item 1).
  A file that is only an open tail hands it on to the next, so a fault in those bytes was named after the later file they now sit in. For the files `[`, `\xe1\n` and `]`, `jq -nc '[inputs]'` says `jq: error (at b:1): Invalid numeric literal at line 2, column 0` as jq does, where `succinctly jq` said `(at c:1)`. Each file's share of the moved bytes now records the file it came from.
  Over 3 and 4 files (4,800 programs each, nasty pool) the multi-file differential changes 177 runs from different to identical and none the other way; the two items of #6004 that remain (`<unknown>` after a number run into `[`, and `-s .` printing `[1]`) are untouched.
