- **jq: a compound stage mixing a navigating and a by-value branch keeps the path register per branch** (#3644). `path(. as $x | (.a // 1) | $x)`, `if true then 1 else first(.a) end | $x` and `try 1 catch first(.a) | $x` refused with `Invalid path expression` where jq 1.7.1 answers `[]`: the register was judged for the `//`/`if`/`try`/`,` stage as a whole, though jq backtracks to the fork and the by-value branch's register is the one it entered with. Each branch now states its own (trackable entries only). Refuse-only before; `(sort, add)`, `(flatten(1), reverse)` and `(last(.a) // .k)` inside a path now answer too.
