- **yq: a line comment on a flow collection's element keeps the collection in flow style** (#2708).
  `.a[1] line_comment = "y"` on `a: [1, 2]` printed the block form (`a:` / `  - 1` / `  - 2 # y`);
  it now prints yq's `a: [1, 2, # y` / `]`, with the comma first after a scalar, the comment after
  the closing bracket for a nested collection (`[[1] # y` / `, 2]`), `]` at the enclosing indent,
  `}` at column 0, and each flow level continuing at go-yaml's rounded indent (`-I3`, `-I4`, `-I6`).
  A comment written below the container's direct children (`.a[0][1]`, `.a.b[0]`) used to be dropped
  silently; it is now kept. Checked against yq v4.53.3 on about 1,000 random flow collections.
