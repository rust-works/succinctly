- **`jq --stream` prints a number whose exponent is 1e9 or more as `e+308`, as jq does** (#5491). `echo '[1e9999999999]' | succinctly jq -c --stream .` printed `1.7976931348623157E+308`; jq prints `1.7976931348623157e+308`. The input bridge wrote `DBL_MAX`'s display text into the document it re-indexes, and the re-index read it back as an ordinary finite literal. It now writes the bridge's infinity token, which reads back as the infinity it is. `1e999999999` and `1e400` were already right.
