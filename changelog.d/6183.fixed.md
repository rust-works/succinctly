- **jq: an inline option in a lookaround or atomic group ends with the group, and a repeated run letter counts once** (#6183). `"aAbB" | [match("(?=(?i)a)a";"g")]` also matched `A`, and `(?<=(?i)a)B`, `(?>(?i)a)B` and `(?i)(?=(?-i)a)A` were wrong the same way, because `fancy-regex` keeps an option set inside such a group for the rest of the pattern where Oniguruma ends it at the `)`. A body that holds an inline option run is now wrapped in `(?:...)` before the engine sees it. A letter named twice in a run (`((?ii)a)B`) is applied once, as Oniguruma does. Checked against jq 1.7.1 over 7,560 lookaround, atomic and plain group shapes.
