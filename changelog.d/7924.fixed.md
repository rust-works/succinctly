- **jq: a number literal past decNumber's exponent range compares, sorts and negates as jq rounds it** (#7924). jq parses a literal into decNumber with an `Etiny` of -1147483646 and an `Emax` of 999999999, rounding half-up, and compares the rounded value. `succinctly jq` already printed that rounded value but compared the digits as written. As a result, `1e-1999999999 == 0` and `12e-1147483647 == 1e-1147483646` were `false`, `[1e-1999999999, 0] | unique` kept both, and `-1e-1999999999` printed `-0E-1147483646`, an answer neither jq release gives. All of these now match jq, from a program literal, an input document or `--argjson`. Negation follows jq 1.8.2 (`0E-1147483646`), as #7453 does for every literal. At the other end of the range, a literal past `Emax` is decNumber's infinity: `1e1000000000 == 2e1000000000` is `true`, and so is a document's `Infinity == 1e1000000000`.
