- **yq: `-o=json` of a float that is `+Inf`, `-Inf` or `NaN` fails as yq's encoder does instead of printing `null`** (#6867).
  `yq -n -o=json '1 / 0'` is `Error: json: error calling MarshalJSON for type *yqlib.CandidateNode: json: unsupported value: +Inf` and exit 1, and a document `.inf`/`.nan` scalar fails with `strconv.ParseFloat: parsing ".inf": invalid syntax`;
  the message carries yq's wrap once per node from the number up to the root, so `[1 / 0]` has it twice.
  `-r` on a bare scalar prints the number's own text (`+Inf`, `NaN`, `.inf`), as yq does.
  A result the streamed route has begun has its part before the number on stdout when the failure comes, where yq prints none of it (recorded in `docs/compliance/yq/limitations.md`);
  the results before it are whole and the exit code and error line are yq's.
