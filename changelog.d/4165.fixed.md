- **library: `GenericResult::into_owned` / `collect_owned` report a deferred array that cannot be decoded as an error, not as "no value"** (#4165).
  Forcing a lazy result whose scalar fails to decode produced an `Error` result, which both methods mapped to
  `Ok(None)` / an empty `Vec`: `eval_with_cursor_using` of `[., 1]` over `[1.2.3]` returned `Ok(None)` where the
  CLI exits 5. They now return the decode failure as `Err`, as they already did for a lazy object (#4044). A
  jq error raised while forcing the array, and a result that is already an `Error`, are unchanged.
