- **`succinctly yq` accepts yq's `--string-interpolation` and `--verbose=false`** (#7025). `--string-interpolation=false` keeps `\(expr)` in a string literal as text (`-n '"x\(1 + 2)y"'` prints `x\(1 + 2)y`), in the program and in an `eval(..)` text, with yq's rule that the backslash pair before a `(` is left alone. A boolean flag takes its value after `=` in Go's `strconv.ParseBool` spellings, so `--verbose=false` is accepted too. Both were `error: unexpected argument` or refused.
