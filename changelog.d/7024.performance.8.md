- **jq: `input`/`inputs` over several regular files reads them a window at a time** (#7024). `jq -n 'reduce inputs as $x (...)' a.json b.json` (up to 32 regular files, 4 MiB or more between them, each of them UTF-8) read every file whole, and before the program started ran jq's parser model over all of them, where one file has been read a window at a time since #7023. Each file is now a lazy source of its own, read a window at a time and in turn; a fault, or a number a file ends in that the next goes on with, hands the rest to the eager reader there, which words it as before. At 100 MiB of NDJSON in 4 or 16 files peak RSS falls from 111 MiB to 13-17 MiB on x86_64 and from 106-108 MiB to 8-19 MiB on aarch64, flat from 10 MiB, and the runs read 24% to 53% faster (`first(inputs)` 98.6%), against an A/A control within 2.2%.
