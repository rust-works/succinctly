- **yq: a mapping that merges one source and then writes an own key the source also has lists that key where it was written, as yq's JSON rendering does** (#6851). With `x: &G {a: 1, b: 2, c: 3}`, `y:` / `<<: *G` / `a: 9` renders `{"b":2,"c":3,"a":9}` in yq (`-o=json`, `tojson`, `with_entries`, `map_values`, a value nested in a construction) and rendered `{"a":9,"b":2,"c":3}` here, with `a` at the merged position. Found by a differential sweep of 11,125 real YAML files, in a GitLab CI pipeline and gcloud's `delete.yaml`. The iteration (`.y[]`) already listed `a` first, as yq does, and a `<<` with several sources keeps its own order (#4983).
