- **jq: `--seq` with a program that can `halt`, over a redirected file with no RS, names the end of the file** (#7889).
  `jq --seq halt < file`, for a file of more than 16,384 bytes with no RS in it, reported
  `Unfinished abandoned text at EOF at line 1, column 0` whatever the file held, where jq 1.7.1 and 1.8.2 name the
  line and column the file ends at (`line 9001, column 0` for 9,000 lines of `1`). Such a file is scanned to its
  end without being held and handed on as the place it ended (#7260); since #7775 a program holding `halt` or
  `halt_error` walked the empty stream instead of reading that place. Standard output and the exit status were
  right, and a file named as an argument, a pipe, `-s`, `--stream` and a program that cannot halt were not affected.
