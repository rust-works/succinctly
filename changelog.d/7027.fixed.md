- **`succinctly yq` reads its first positional as yq does** (#7027). `yq file.yaml` was `parse error ... unexpected character '.'` because the first positional was always the expression; it now prints the file. A first argument that names an existing file (a symlink counts, a directory does not) or is `-` is an input and the expression is `.`; one that ends in `.yq` and is a file holds the expression (`yq x.yq d.yaml`, `yq -n x.yq`); anything else is the expression, as before. `-n` with input files is now `Error: cannot pass files in when using null-input flag`, where the files were ignored. An empty `--expression` counts as none. 23 rows from yq v4.53.3 are pinned. A file named like an expression (`.a`) is read as a file, which is what `--expression` is for.
