- **`succinctly jq`'s `input_line_number` and `(at FILE:N)` marker count past 4,294,967,295 lines** (#7472). jq 1.7.1 and 1.8.2 count input lines in a `size_t`, so a value on line 4294967302 is on that line; `succinctly jq` answered `6` on the routes that read through the `input` queue (`input_line_number`, `-n 'reduce inputs ... | error(..)'`, `--seq`, `--stream`, `-R`), and a value on exactly line 4294967295 read as `<unknown>`. Lines are 64 bits now; the per-value line tables keep their 8-byte entries and add a run of high words only where a line passes 2^32, so nothing grows below that. The library's `current_input_location`, `ProducedInput` and `UNKNOWN_INPUT_LINE` carry the line as `u64`, and `seed_remaining_inputs_with_line_highs` seeds a queue from a `LineTable`.
