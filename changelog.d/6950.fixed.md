- **yq: `document_index` after a write is the document's own number** (#6950). `.x = 5 | document_index` over a two-document stream printed `0`, `0` where yq prints `0`, `1`, so `.x = 5 | select(documentIndex == 1)` matched nothing; the same held for `|=`, `del`, `*`, `+`, `with`, and for an absent key (`.zz | document_index`) over several files. A node the filter builds (`[.x]`, a literal) now answers the document being evaluated too, where yq answers `0` (recorded in `docs/compliance/yq/limitations.md`).
