- **yq: `==`/`!=` on an array or object follow real yq** (#2799, part 1). yq's `isEquals` answers `false` for every pairing that holds a container, so `[1] == [1]`, `{} == {}` and `. == .` are `false` and `!=` is `true` there; succinctly answered jq's structural equality. A script that compares whole arrays or objects with `==` now sees yq's answer (comparing `tojson` of both sides is a structural comparison in both tools, unless a string value holds a `*` or `?`, which the right-hand side still reads as a glob), and `select(. == .)` keeps only the scalars. Scalar comparison, `unique`/`group_by` and `sort` are unchanged here; the dedup keys and `sort` comparator are the issue's next slices.
