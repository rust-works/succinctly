- **`add` of objects or strings, and `reduce ... (. + {(k): v})` or `(. + "s")`, stay linear in a program that holds a path target the shipped evaluator cannot take** (#7610). Such a program (`1 |= 1`, `del(1)`, `path(1)`, even in a branch that never runs) runs through the path-mode interpreter, whose `reduce` copied an object or a string state on every `. + $x` step, as it did an array state before #7564: user CPU grew four times per doubling of the input (`[range(n) | {("k\(.)"): .}] | if false then (1|=1) else . end | add` and string `add` alike). An object or a string state that nothing else shares now grows in place, as jq's `f_plus` lets `jv_object_merge` and `jv_string_concat` do, and the cost is linear in the number of steps.
