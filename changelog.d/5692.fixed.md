- **jq: a path through a container named argument is the argument's own** (#5692). `--argjson d '{"a":1}' '$d | path($d)'` is `[]`, `'$d | del($d)'` is `null` and `'$d | path($d.a)'` is `["a"]`, as in jq 1.7.1; all three were refused with `Invalid path expression`. A program with a path expression (`path`, `paths`, `del`, `pick`, `getpath`, `walk`) now gets a container `--argjson`/`--slurpfile` argument as the one shared value #5690 gave read-only programs, which also makes `--slurpfile` programs that delete or list paths faster (about -50% and -40% for `del` and `paths` over a 7 MB file, Apple Silicon). An assignment to the argument itself, `$ARGS.named.d | path($d)` and a scalar argument are still refused (`docs/compliance/jq/limitations.md`).
