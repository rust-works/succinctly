- **jq: a path through a container named argument is the argument's own** (#5692). `--argjson d '{"a":1}' '$d | path($d)'` is `[]`, `'$d | del($d)'` is `null` and `'$d | path($d.a)'` is `["a"]`, as in jq 1.7.1; all three were refused with `Invalid path expression`. A program with a path expression (`path`, `paths`, `del`, `pick`, `getpath`, `walk`) now gets a container `--argjson`/`--slurpfile` argument as the one shared value #5690 gave read-only programs, which also makes `--slurpfile` programs that delete or list paths faster (over a 4.7 MB file, min of 5 release runs: `del` 182 to 78 ms, `paths` 262 to 146 ms, and 20 records each reading it 920 to 600 ms; Apple M5 Max). An assignment to the argument itself, `$ARGS.named.d | path($d)` and a scalar argument are still refused (`docs/compliance/jq/limitations.md`).
