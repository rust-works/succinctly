- **yq: a `-` directly followed by a digit after a value is refused, as in yq** (#7998). yq's lexer reads `-` plus a digit as the sign of a number token wherever it stands, so `1 -16`, `1-16`, `.a -1` and `(1) -2` are a value and a negative number side by side, which yq v4.53.3 refuses with `bad expression, please check expression syntax` (exit 1); `succinctly yq` subtracted. It now refuses them with the same words. A `-` before a space, a newline, `(`, `.` or another `-` is still a subtraction (`1 - 16`, `.a - -1`), a negative number where a value may start is unchanged (`1 + -1`, `[1,-1]`), and `succinctly jq` still reads `1 -16` as `-15`, as jq does.
