- **`succinctly dev compare jq` times and measures piped stdin input** (#6914). Every `perf.tsv` row passed its input as a file argument, so the committed speedups and memory ratios covered the file route only, while `curl … | jq` is the common way to run jq and takes its own path in the evaluator. A query whose flags carry `@stdin` now feeds its input through a real pipe (not a redirected file) in the output gate, the timed runs, the peak-memory runs and the cachegrind run; six `*_stdin` rows (`identity`, `identity_compact`, `users_field`, `users_map_select`, `ndjson_field`, `ndjson_inputs_reduce`) run at 1, 10 and 100 MB, and the report sets each beside its file-route twin. They are kept in `perf_stdin`, so the headline geomeans stay file-route figures.
