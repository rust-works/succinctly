- **jq: `pick(f)` over a `recurse(g)` walk is no longer quadratic in the paths it picks** (#5390). `[pick(recurse(.[]? | .) | select(type == "number"))] | length` over 40,000 one-element arrays (80,001 nodes) took 16.5 s in a debug build, against 0.56 s for the same selection through `..`, and did not finish in 120 s at 524,289 arrays; it is now 1.5 s wall (0.32 s CPU) at 80,001 nodes, linear as `..` is. The path interpreter ran jq's own `reduce path(f) as $a (null; setpath($a; $in | getpath($a)))`, which copied the accumulated result once per pick; `pick` now folds in place, as `=` and `|=` do (#5256).
