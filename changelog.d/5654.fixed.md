- **jq: `--argjson`, `--jsonargs` and `--slurpfile` skip only JSON whitespace around a value** (#5654). A form feed, a vertical tab or a Unicode space around the text (`--argjson x $'1\f'`, `--jsonargs ' 1'`, a `--slurpfile` file holding `1<NBSP>`) was trimmed and accepted; jq 1.7.1 refuses each (`invalid JSON text passed to --argjson`, `Bad JSON in --slurpfile`, exit 2) and so does `succinctly jq` now. `--argjson x ''` (and `' '`) is refused too, where it was `null`. A form feed after a container in a `--slurpfile` file (`[1]<FF>`) is still taken as whitespace by the document splitter; #5650 changes that.
