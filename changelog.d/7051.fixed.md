- **yq: a repeated value flag takes the last value, and `-C` beats `-M`, as yq's do** (#7051). yq's flags are Go `pflag` ones, so `yq -o json -o yaml .` prints YAML and `-I 4 -I 0 -o json` prints compact JSON; `succinctly yq` refused the second occurrence with `the argument '--output-format <FORMAT>' cannot be used multiple times` for `-o`, `-p`, `-f`, `-I`, `--doc`, `--split-exp`, `--expression`, `--split-exp-file`, `--from-file` and the separator, prefix and name options of the encoders (`--csv-separator`, `--properties-separator`, `--lua-prefix`, `--xml-attribute-prefix` and the rest). Each now overrides itself. yq's `-C` forces colour whichever of `-C` and `-M` comes last, where here `-M` won. A test over the live `YqCommand` fails for any new single-value flag that forgets the override. Pinned by 19 rows captured from yq v4.53.3.
