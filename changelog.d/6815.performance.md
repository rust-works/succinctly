- **yq: a write with YAML output holds the presentation tree in 37-49% less memory** (#6815).
  A node of the tree that carries comments, styles and anchors to the output was 224 bytes whether or
  not it had any, and a write builds it twice (the document's, then the result's). It is now 32 bytes:
  the node's metadata is boxed only when it says something, and an object's field and key maps sit
  behind a pointer each. `.zzz = 1` with `-o yaml` on a 100 MB `users` file peaks at 2898 MB instead of
  4905 MB on an AMD Ryzen 9 7950X and 2852 MB instead of 4960 MB on an Apple M4 Pro, in 13.5% and
  5.8% less time; `navigation`, `comprehensive` and `nested` fall 42-49% the same way, and `-P` and
  `del()` writes 37-48%. The output is byte for byte the same, and the JSON-output write and the
  fast path are unchanged.
