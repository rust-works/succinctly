- **yq: a write with YAML output peaks at 36-49% less memory on record and nested documents** (#6815).
  A node of the tree that carries comments, styles and anchors to the output was 224 bytes whether or
  not it had any, and a write builds it twice (the document's, then the result's). It is now 32 bytes:
  the node's metadata is boxed only when it says something, and an object's field and key maps sit
  behind a pointer each. `.zzz = 1` with `-o yaml` on a 100 MiB `users` file peaks at 2897 MiB instead of
  4902 MiB on an AMD Ryzen 9 7950X and 2886 MiB instead of 5036 MiB on an Apple M4 Pro, in 14.2% and
  4.8% less time; `navigation`, `comprehensive` and `nested` fall 41-45% the same way, and `-P`,
  `del()` and copying writes 36-49%. The output is byte for byte the same, and the JSON-output write and the
  fast path are unchanged.
