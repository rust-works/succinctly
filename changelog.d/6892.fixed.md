- **yq: `del(PATH[] | select(...))` over a document without `PATH` leaves it as it is** (#6892). `del(.spec.template.spec.containers[] | select(.name == "sidecar"))` over a stream of Kubernetes manifests raised `Cannot iterate over null (null)` and exited 1 on every document that was not a Deployment, where yq deletes nothing and prints the document unchanged. The raise stays for any other target shape, a comma among them (`del(.zz[] | select(.n == 1), .kind)`), where a missing key's `null` can stand for a write yq vivifies, and for a field write through the same path (`(.zz[] | select(.n == 1)).x = 5`, which yq answers by adding `zz: []`); both are recorded in the yq limitations. A path that is there deletes as before.
