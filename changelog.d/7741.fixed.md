- **jq: `--stream` and `--stream-errors` with a terminal on standard input end at jq's `^D`** (#7741).
  The reader read standard input again after a read that had returned end of file, and a terminal returns end of file once per `^D`, so an empty input, a blank line or `1` and Enter needed a second `^D` and `1` with no newline a third, where jq 1.7.1 needs one and two.
  Standard input's end of file is now sticky for the run, as jq's stdio makes it.
