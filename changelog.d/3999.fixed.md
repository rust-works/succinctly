- **jq: a fold's `?//` pattern walk retries past an alternative it can prove the register refuses** (#3999, a #3840 residual). `del(try (.a and (reduce . as {a:$a,b:$b} ?// [$a] (0; .))))` on `{"a":1,"b":2}` is `{"a":1,"b":2}` in jq, whose first alternative fails `path_intact` (the right operand's `.` is the root, jq's register sits on `.a`) and whose second alternative's error the `try` catches; the walk treated the first refusal as a guess at an unknown register, so it never retried and the program exited 5. A fold entered on an untracked stage whose register value is still known now compares the element with it: an element that is not equal to the register is provably not its node, so the refusal is jq's own verdict and the next alternative runs (`reduce` and `foreach`, any number of alternatives, `and` and `or`). An element equal to the register by value, or a register the stage has lost, stays the loud guess of #3840. A row jq answers by stepping from the register's own node still refuses.
