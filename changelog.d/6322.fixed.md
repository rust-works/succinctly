- **yq: an explicit key whose own content is an explicit key (`? ? a⏎  : b⏎: c`) is read as the mapping-as-key it is** (#6322). `succinctly yq -o json .` stopped at the inner `:` with `inconsistent indentation`, and read `? ? a⏎: c` as the plain-scalar key `? a` (`{"? a":"c"}`, silently); yq answers `{"":"c"}` for both. The inner key now waits for its value in front of the outer one, and the outer one takes the next shallower `:`; a tag or an anchor before the nested `?` (`? !!str ? a`) and a `:` that lands between the two stay refused, as yq refuses them. Over 4,200 generated explicit-key documents, 1,630 that differed from yq now agree and none changed the other way.
