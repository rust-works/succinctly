- **yq: a comment after a sequence dash survives a write** (#4231). On `- # own` / `  c: 2` any write that takes the DOM route (`.a[0].b = 5`, `.z = 1`, `del(...)`) dropped the comment, where yq keeps it as the head comment of the item's first key (or first element), on the dash's line; a scalar, an empty or a flow item puts it above the dash. `succinctly yq` now carries it through, matching yq on all of these shapes.
