- **jq: `utf8bytelength` and `contains("lit")` of a string are answered from the string** (#5675). `-R 'utf8bytelength'` and `-R 'contains("lit")'` wrote each line out as JSON text, indexed it and decoded it again, about 0.5 us a line, because #5691's string door answered only `length`, `startswith` and `endswith`. Both now join that door, so a `select` or `until`/`while` condition reaches them too. `contains` answers only a string in a string; every other pair, any container and a non-literal or fan-out argument still take the general route and keep its error text.
