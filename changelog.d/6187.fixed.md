- **jq: a plain group holding only an option group of a zero-width body is no longer refused** (#6187). `"cab" | match("(?:(?i:\\K))*"; "g")`, `(?:(?i:\\K))+b`, `(?:(?i:(?=a)))*b` and `(?:(?:(?i:\\G)))*` failed with the `regex` crate's parse error where jq answers. #6164 made a repeated option group a valid target by making it atomic; the same group one or more plain `(?:...)` groups down is now rewritten the same way. `(?:\\K)*` and `(?:(?:\\G))*`, which hold no option group, stay refused, as in jq.
