- **yq: `//` under `--eval-all` reads both operands over the whole document list** (#7173). `yq ea '.a // 5' a1 a2 a3` over three files of which one has `a` printed `1 5 5`; yq prints `1` and then six `5`, because its `//` is a cross-function operator like `+` and `==`: with every context node flagged `EvaluateTogether` it evaluates the left side over the list, keeps each truthy output, and replaces every other one with all of the right side's outputs over the list (the output itself when that yields none). A left side with no output runs the right side once, and an error in the right side is raised only when a falsy output needs it. `.a // .c`, `.zz // fi`, `(.a, .c) // 7`, `.a // (5, 6)` and the `//` inside `+`/`==` operands (where the left side is read-only) answer as yq's do; 26 rows are pinned in `tests/yq_cli/i7173.rs`. Without `--eval-all`, `//` is per document as before.
