- **`succinctly jq` reports the errors in a def reached only through an unresolved call's argument** (#7443). `def rs: foo; def run: count(rs); run` printed `count/1 is not defined` and `1 compile error`, where jq 1.7.1 and 1.8.2 also report `foo/0` first: the argument is never compiled, but its reference keeps `rs`, a closure of the main block, which has no error of its own. `def h: nosuchfn2; nosuchfn(h)` stays one error, as in jq, since there the main block has one.
