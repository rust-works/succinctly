- **A fault followed by a stray quote on its line no longer carries the rest of a file onto the next one** (#7750, #7751, #7753). The stitch that joins a token a file ends inside to the next file judged an open container or string by its brackets and quotes alone, so `0 [x"]` then `1\n2\n` looked like a string the next file goes on with; jq's parser stops at the fault and parses on from the next line of the same file. A program reading past the fault with `try input` lost every value after a file that did not open later in the list (`"E" 2` where jq prints `"E" 2 4 101`), `input_filename` named the next file for the values after the fault, and a fault in a document still open at the end of its file was reported after a later file that did not open, with exit 2 where jq exits 5. A tail is now carried only when jq's parser meets no fault reading it. Over 54,216 lists of split files with a missing file, a directory or a mode-000 file among them (`scripts/jq-filelist-differential.py`), the differences from jq 1.7.1 went from 1,259 to 0 with the companion fixes for #7752 and #7754.
