- **yq: a write keeps the blank lines between a head-comment block and the node below it** (#4093).
  `# lead` / blank / `version: 2` lost the blank line on any DOM write (`=`, `|=`, `del()`, `-P`, `-i`):
  the single most common divergence from yq in a sweep of 2,178 real YAML files (any file that opens
  with a comment header and a blank line). They are kept, one entry per blank line, for a node at
  column 0; yq drops them for an indented node and for a block that itself follows a blank line (it
  reads that as the previous node's foot), and so does this.
