- **jq: a `-f` program file that holds a NUL byte is refused** (#7434). `.a\0| .b` was a compile error (exit 3) and `# c\0` followed by `.a` on the next line ran `.a`, where jq 1.7.1 ended the program at the NUL. `succinctly jq` now follows jq 1.8.2, which refuses the file before compiling it (CVE-2026-41256): `jq: program file contains NUL bytes` on stderr, exit 2, even when the input file does not exist. The difference from the pinned 1.7.1 is recorded in `docs/compliance/jq/limitations.md`.
