- **yq: the 47 remaining jq-only names need `--jq-extensions`, as yq's lexer rejects them** (#4808). Real yq has
  no `if`, `try`, `def`, `label`, `empty`, `values`, `recurse` and the rest of this group (`lexer: invalid input
  text`, v4.53.3), yet `succinctly yq` parsed them without the flag while every other jq-only name was already
  gated (#1512, #3560). They now fail with the same `is not part of yq's syntax; pass --jq-extensions` error as
  `limit` or `paths`. The group is the control flow and definitions (`if`/`then`/`elif`/`else`/`end`,
  `try`/`catch`, `label`/`break`, `def`), `while`/`until`/`repeat`/`recurse`/`recurse_down`, `empty`/`halt`/
  `halt_error`/`stderr`, the type selectors and tests (`values`, `strings`, `isnull`, ...) and `in`,
  `keys_unsorted`, `ltrim`/`rtrim` and a few others. A yq script that used one adds the flag; yq's own `keys`
  (already document order), `..`, `select(tag == ...)`, `trim` and `select`/`//` cover most uses without it.
  `succinctly jq` is unchanged.
