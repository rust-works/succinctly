- **yq: a write over the node it reads keeps the source's alias** (#6716). `.b = [.b]` over `b: *x` printed `- 1` where yq prints `- *x`, and `.b = .b[-1]` over `b: [0, *x]` dropped the alias the same way, because the alias pass read the right side from the tree the write had already replaced. The first write of a chain now reads it from the document as it came in; later stages still read what the earlier ones wrote. A 85-row sweep against yq matched 17 more rows and regressed none.
