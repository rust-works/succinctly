- **yq: `.[]` and `map(f)` over a mapping collapse its complex keys into one slot, as yq does** (#7292). A sequence or mapping key has empty text in yq's traversal, so every such key of a mapping is the same key, and the same as a plain `""` key: the first keeps its position and the last one's value stays. `? [1, 2]` / `: p` / `? [3]` / `: q` / `r: 1` under `[.[]]` printed `["p","q",1]` and now prints `["q",1]`. `length`, `to_entries` and `keys` keep every member, as in yq, and an alias key is read as before.
