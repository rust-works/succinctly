- **yq: a plain `<<` value carries the `!!merge` tag yq gives it** (#5833). `printf 'a: <<\nb: [<<, x]\n' | succinctly yq '.'` printed `a: <<` / `b: [<<, x]` where yq prints `a: !!merge <<` / `b: [!!merge <<, x]`, and `.a | tag` answered `!!str` where yq answers `!!merge`: YAML resolves a plain `<<` to the merge tag wherever it sits, and only a `<<` key carried it here. Both output routes now write the tag, `tag` and `type` report it, and a computed `"<<"` (`.z = "<<"`, or a `!!str <<` whose tag `-P` drops) is written quoted, as yq writes it, rather than as a plain `<<` that reads back as the merge tag. A quoted `"<<"` and a JSON string stay `!!str`.
