- **yq: a write with YAML output peaks at 20-49% less memory on a document with plain, comment-free parts, and runs 8-17% faster, 25% with `-P`** (#6880).
  A write builds the presentation tree (comments, styles, anchors) of the document and then a second
  one for its result, a node for every node of the document even where there is nothing to carry. The
  snapshot now holds one word in place of each subtree that says nothing, and the result's tree is
  not walked over it. `.zzz = 1` with `-o yaml` on a 100 MiB `users` file peaks at 1760 MiB instead of
  2899 MiB on an AMD Ryzen 9 7950X (39% less, 8.52 s instead of 10.32 s) and at 1966 MiB instead of 3061
  MiB on an Apple M4 Pro; `-P` on 20 MiB falls 49% (718 to 365 MiB, 7950X), `.users[0].name |= "X"`
  39%, `del(.users[0])` 20%, and `comprehensive` and `nested` 31-36% at 100 MiB. A document that carries a quoted
  string or a comment in every record (`navigation`: a quoted timestamp each) saves almost nothing
  (3%), and one with an alias, a metadata write (`style =`, `head_comment =`, `tag =`) or a plain `=`
  from a read (`.c = .a`) builds the full tree as before. The output is byte for byte the same.
