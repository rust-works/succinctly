- **yq: `filter`, `collect`, `sortKeys` and `to_string`** (#4213). All four exist in yq v4.53.3 and were `X/N is not defined`. `filter(f)` is `[.[] | select(f)]` (a scalar has no children, so `[]`; a map filters its values), `collect(f)` is `[f]`, `sortKeys` is another spelling of `sort_keys`, and `to_string` is `tostring` for a scalar (a container still renders as JSON here where yq writes YAML text). yq names only, so jq mode may define its own.
