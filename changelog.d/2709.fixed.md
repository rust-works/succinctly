- **yq: a side effect ahead of a metadata write fires once** (#2709). `.a = (.b | debug) | .a line_comment = "y"` printed `["DEBUG:",2]` twice, `.a = (.b | stderr) | .a line_comment = "y"` wrote `2` twice, and `halt_error` there printed its payload twice before exiting: the metadata pass re-ran every stage ahead of the write to learn the document the write sees, and that re-run wrote to stderr as well. The re-run is now silent, so the real evaluation is the only one to fire `debug`, `stderr` and `halt_error`; a `debug` inside the write's own right-hand side (`.a line_comment = (.b | debug | tostring)`) still prints once. Output, exit codes and the comments written are unchanged.
