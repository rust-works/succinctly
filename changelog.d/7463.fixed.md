- **jq: `fromstream(inputs)` and `truncate_stream(inputs)` hand each value on as its events arrive** (#7463).
  Both collected every value of their argument before the first was emitted, so `first(fromstream(1|truncate_stream(inputs)))` over a big array under `--stream` read and held all of it (1,685 MiB over 100 MB of records on an Apple M4 Pro and 1,725 MiB on an AMD Ryzen 9 7950X, now 4.5 MiB and 15.3 MiB, the benchmark driver's own size before exec), never ended on an endless pipe, and `input_line_number` after each value named the input's last line.
  They now stream as jq 1.7.1's `foreach`-defined builtins do.
