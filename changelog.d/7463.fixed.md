- **jq: `fromstream(inputs)` and `truncate_stream(inputs)` hand each value on as its events arrive** (#7463).
  Both collected every value of their argument before the first was emitted, so `first(fromstream(1|truncate_stream(inputs)))` over a big array under `--stream` read and held all of it (1,910 MiB for a 52 MB array on an Apple M4 Pro, now 4.2 MiB; jq 1.7.1: 2.2 MiB), never ended on an endless pipe, and `input_line_number` after each value named the input's last line.
  They now stream as jq 1.7.1's `foreach`-defined builtins do.
