- **yq: the non-specific tag `!` is dropped from the YAML output** (#6948). It names no kind, so yq reads the node it marks as untagged and prints it without the `!` (`a: ! x` is `a: x`, `a: !<!> x` is `a: x`, `a: !` is `a:`). `succinctly yq -o=yaml` printed it back on every route, and a write into the node made that visible: `.x = "12"` over `x: !` printed `x: ! 12`, which both tools read as the number `12`, and `.x = ""` over `x: ! a` printed `x: !`, which reads back as null. The cursor now reports a non-specific tag as no tag, which is how every reader and writer of a node's explicit tag asks, so the cursor writers and the tag of a written document agree. 43 rows over scalars, containers, keys, block scalars, anchors, comments, `-P`, bindings, numeric and boolean keys (`! 1: v` has the key `1` in `keys`, as in yq; it was the string `"1"`) and writes are pinned in `tests/yq_cli/i6948.rs`, all captured from yq v4.53.3; the old build agreed on 7 of them.
