- **yq: a string's `length` inside a loop body is read off the string instead of being written out and indexed again every round** (#6534).
  With `--jq-extensions`, `"abcd" * 1750000 | . as $t | [range(100) | . as $w | ($t | length)]` took the reindex bridge
  once per round, as jq mode did before #6508 and #6532; the owned stage now answers a string's `length` from the
  string (bytes in yq, as before), so a bound computed string is no longer serialised each round. A 7 MB string over 100 rounds
  takes 29 ms instead of 577 ms on an Apple M4 Pro (20.0x; 1 MB 12.2x, 10 MB 19.4x) and 464 ms instead of 1070 ms on an
  AMD Ryzen 9 7950X (2.3x at every size: the per-round copy of the bound string that the pipe makes before the stage runs
  remains, and is dearer under WSL2, #6832). The output is unchanged.
