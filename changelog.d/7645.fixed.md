- **jq: a data import with `{raw: true}` binds the file's text** (#7645). `import "r" as $r {raw: true};` parsed `r.json` as JSON, so a file that was not JSON was `error loading data file` (exit 3) and one that was imported as `[value]`, where jq 1.7.1 and 1.8.2 bind its text as one string (`"abc def"`), read as `--rawfile` reads its file. Only `raw: true` itself does this, as in jq: `raw: 1`, `raw: "true"` and `raw: null` still parse the file.
