- **yq: a stream with no content reads as yq reads it: a tab-led comment or a `%YAML` directive alone is a null document, a `...` met before any content is refused** (#6342). yq's header slurp sets aside every leading blank, comment, `%YAML` directive and `---` line before go-yaml sees the rest, so `⇥ # c` and `%YAML 1.2` are one null document that print back as written, where `succinctly yq` read no document and printed nothing; and `...`, `---` / `...`, `# c` / `...` and `%YAML 1.2` / `...` hand go-yaml a `...` as the first token of an implicit document, which it refuses with `did not find expected node content` where `succinctly yq` read nothing or a null document. A `%TAG` (or any directive other than `%YAML`) with no `---` after it is refused too (`did not find expected <document start>`). A `---` that is not in the head still starts an empty document a `...` can close (`a: 1` / `---` / `...` is `{"a":1}` then `null`). Every stream is pinned against yq v4.53.3 in `tests/yq_cli/i6342.rs`; the library loader keeps the YAML test suite's reading (`HWV9`, `QT73`: zero documents).
