- **jq: a computed index of an array with no element but a comma is an error** (#6270). `printf '[,]' | jq '.[0+0]'` answered `null` (and `.a[1-1]` the same inside an object) where jq 1.7.1 refuses the document at parse time, as the literal `.[0]`, `length` and `.[]` do here (exit 5). The walk of an array sees no gap when it has no element, so the check is made where the target's cursor is held, as #6257 did for the computed slice.
