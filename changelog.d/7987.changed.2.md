- **`succinctly jq` reads the edges of its input through the model of jq 1.7.1's reader on the routes that read a window at a time too** (#7987). The default route over a file of 1 MiB or more, several of 1 MiB or more between them, or a pipe longer than 512 KiB holds a window, never the input, so the model (ADR-0033, step 7) is fed the bytes as read of the window it needs, a read at a time, and entered where the window says the reader stands: at a line start no value holds its state is a closed form of the window's line and offset counters. The stream's fault is read by the model from its start (over files by position, a chunk at a time; over a pipe by the thread that certifies each window), and a window with invalid UTF-8 is read as step 6 reads a file read whole: from the line start before the substituted byte to the first sync point after it, validating what it reads. On these routes a mark that breaks off (`printf '\xef\xbf\xbd1\n'` before a megabyte of JSON) is now `Malformed BOM`, as jq 1.7.1 and 1.8.2 word it, where it used to say `Invalid numeric literal` (#5804), and so it is on the lazy route of a lone pipe or file longer than 256 KiB that a program reading `input` takes, which now reads nothing past its front for it; a malformed value on a substituted line is jq's fault rather than printed past (`.a?` over `["\xff",]`). The materializing route's eager loop stops at its first fault instead of reading on to the end of the input for the model to read again (#8082). Over four differentials of 2,200 generated cases of 300 KiB to 4.3 MiB (edges at the stream's start, at window boundaries, at file seams and near the end, two of them dense with substituted strings beside faults) and 13 programs, the 1,419 answers that changed moved to what both releases print (1,415: 1,170 the mark's wording, 106 a fault where the windows printed past it, 90 which values there are, 49 the fault's message or position), differ from both only at a NUL (2, ADR-0018's E2), or print fewer of the values a lazy read let through before jq's first fault (2, #3035); none moved away from both, and `--slurp`, `--seq`, `--stream` and `-R` changed on none. `SUCCINCTLY_READER_MODEL=0` selects the old reader.
