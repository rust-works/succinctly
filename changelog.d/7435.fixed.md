- **`succinctly jq` runs a program with long operator chains or deep nesting, as jq does** (#7435). A chain of more than 256 `or`, `and`, `+`, `-`, `*`, `//` or postfix `?` links (`select(.a == 0 or .a == 1 or ... or .a == 299)`), or more than 256 levels of brackets, parentheses, `try`, `if`, `reduce`, string interpolation or local `def`s, was refused with `expression nesting exceeds depth limit of 256`; jq 1.7.1 and 1.8.2 run them. The parser now charges each level of nesting and each chain link against the native stack's room instead (about 9,360 levels and 21,840 links in a release build), and a program past that is refused with jq's own `memory exhausted` (exit 3) rather than overflowing the stack. `succinctly yq` keeps the 256-level limit.
