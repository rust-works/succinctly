- **`succinctly jq --seq --stream` and `--seq --stream-errors` report a directory given last when a read reaches it, as jq does** (#6661). A `--seq` text that faults at its end (`Unfinished abandoned text at EOF`, which a file with no record separator or no final newline ends in) sends jq's reader into the directory: the read that returns the fault counts the failure, and the program's next read now prints `jq: error: Is a directory` (`jq -n --seq --stream-errors '[inputs]' p.json dir`, `jq --seq --stream-errors input p.json dir`). Before, the stream-reader routes counted the directory up front and never printed it; plain `--seq` already placed it (#6643).
