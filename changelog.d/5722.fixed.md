- **jq: a long pipe with a few `def` calls in it evaluates in linear memory** (#5722). A pipe of more than 128 stages that held a stage with evaluation state (a call of a user `def`) was copied whole per call, so it kept the quadratic memory #5679 removed for stateless pipes. The chain now links each run of blocks with no such stage and clones only the blocks that hold one, so a call copies the stateful blocks plus a link per run. Peak RSS of `-n 'def f: . + 1; 0 | . + 1 | … | f | …'` (AMD Ryzen 9 7950X, release build, output identical), one `f` in 200 stages: 1,500 stages 411 MB to 17 MB, 3,000 stages 1.59 GB to 23 MB (1.5 s to 0.01 s); one in 1,000: 3,000 stages 1.59 GB to 23 MB. A pipe with an `f` in every block of 16 stages, or in every stage, is copied as before (3,000 stages of `f`: 468 MB, unchanged). jq mode only. Apple silicon was not measured.
