- **A command-line argument that is not valid UTF-8 no longer panics** (#7426). `succinctly jq -nc --arg x $'a\xff' '$x'` and every other such argument (the program, an `--arg`/`--argjson` name or value, an `--args`/`--jsonargs` word, a file name, an unknown option) exited 101 with a Rust panic, in every subcommand and multi-call alias. `succinctly jq` now reads a text word as jq 1.7.1 does, each bad sequence one U+FFFD by jq's rule (`$'"\xed\xa0\x80"' | explode` is `[65533]`), and opens a file by the bytes of its name, naming it in `input_filename` and in its error messages as jq does. `succinctly yq` reads a word as yq v4.53.3 does, one U+FFFD per bad byte.
