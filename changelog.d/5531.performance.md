- **jq: the regex builtins compile a pattern once, not once per input value** (#5531). `test`, `match`, `capture`, `sub`, `gsub`, `scan`, `split` and `splits` built their regex again for every value, and `regex::Regex::new` dominated a short-string match. The last 16 `(mode, pattern, flags)` results are now kept per thread (errors too, so a refused pattern is not translated and compiled again per input; a pattern over 1 KiB is never kept). Over a 20,000-element array of short strings on an Apple M5 Max (user time, interleaved, identical output): `test("[a-z]+[0-9]{2,}x?")` 1,248 ms to 14 ms, a literal `test("item5")` 73 ms to 16 ms, `sub("[0-9]+";"#")` 693 ms to 24 ms; a pattern that is different for every input (7,919 distinct) is unchanged at 1.00x.
