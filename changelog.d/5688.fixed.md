- **jq: `fromjson` reads to jq's parse-depth ceiling** (#5688). `fromjson` refused a text nested more than 128 levels deep with an `Invalid numeric literal` error, where jq reads 256 nested arrays and refuses the 257th (`Exceeds depth limit for parsing`). It now takes jq's ceiling, counted jq's way (an object is two entries of it, so 128 nested objects read and 129 do not), and words the refusal as jq does. `tonumber`'s probe, which shares the check, follows. A text nested 128 levels or less is read exactly as before.
