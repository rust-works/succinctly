- **yq: a line holding only a tab is refused after every completed node, as yq refuses it** (#6295). go-yaml skips a tab only where a simple key is not allowed, which is never at the start of a block-context line, so ` ⇥` after a flow collection (`a: [x]`), a quoted scalar, a comment (`a: x # c`), a key with no value (`a:`), a property (`a: &x`) or an anchored flow collection, in a sequence, after a later document's `---` and after a `...` end marker is `found a tab character that violates indentation` at any column where `succinctly yq` read an empty line (#6286 did the plain-scalar case). The same line before the first content line of a block scalar (`a: |` / ` ⇥` / `  x`) is refused as well. A plain scalar before it (`a: x`), a block scalar's content, a flow collection's own lines and the head of the first document (`---` / `⇥` / `a: 1`, which read as yq's header) are unchanged, or newly read in the last case.
