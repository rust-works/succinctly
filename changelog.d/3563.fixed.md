- **yq: a computed or multi-key index reads its target's explicit tag before its text** (#3563). `.[$k]`, `.["b","c"]` and `.[0,1]` tested the target's text for null, so `a: !!null foo | .a | .[0,1]` answered nothing where yq answers `null null`, and `a: !!str null | .a | .[0,1]` answered `null null` where yq answers nothing. The index now carries the cursor the target was read from and asks `cursor_is_null`, as the literal field and index arms have since #3533. Checked against yq v4.53.3 on 17 rows. Still different: a container tagged `!!null` (`a: !!null {b: 1}`) is read as the mapping it holds (#4111).
