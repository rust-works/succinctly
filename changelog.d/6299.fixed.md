- **yq: a plain scalar under an unknown `!!` tag is its text, as in yq** (#6299).
  `a: !!str: 1`, `[!!int: 1]` and `a: !!foo 1` read the number `1` where yq answers the string `"1"`: the `:` of `!!str:` belongs to the tag, and a tag of the secondary handle that names no core type (`!!binary`, `!!set`, `!!foo`) makes the scalar its text. A custom `!foo 1` still resolves like the untagged text, and the core tags force their own kind.
