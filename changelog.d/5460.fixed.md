- **yq: a number, object or array key read off a `+` or `*` result answers nothing when the mapping lacks it** (#5460). `(.a + {})[0]`, `(.a * {})[-1]` and `(.n + {})[1.0]` printed `null`, and `(.a + {})[.a]` / `(.a + {})[[0]]` failed with `Cannot index object with object`, where yq prints nothing, so `[(.a + {})[0]]` collected `[null]` instead of `[]`. A write or `del()` through the same spelling stays the no-op it is in yq, and an array head (`([1,2] + [3])[-1]`) reads as before.
