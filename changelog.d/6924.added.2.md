- **yq: `-o ini`** (#6924, slice 2 of #6850).
  The results are written as INI by a port of yq's go-ini encoder: the root's scalars first, then a `[section]` for each mapping, keys padded to the longest and quoted as go-ini quotes them, arrays and nested mappings dropped, an empty key or section name an error.
  Checked against yq v4.53.3 over 3,200 random JSON documents (no difference) and a YAML matrix (only a null written `~` differs, #2802).
