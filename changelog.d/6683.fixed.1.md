- **`succinctly jq` exits 2 when a halt follows a last value read on into a directory given last** (#6683). With plain JSON (`jq halt_error p.json dir`, `p.json` holding `1` with no newline) the bare number is read on into the directory, which counts the failure as it does for a missing last file, so `halt`, `halt_error` and `halt_error(3)` exit 2 as jq does, where they kept their own status (0, 5, 3).
