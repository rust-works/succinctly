- **`add` and `flatten` stay linear in a program that holds a path target the shipped evaluator cannot take** (#7564). Such a program (`1 |= 1`, `del(1)`, `path(1)`, `path(tostream .[0])`, even in a branch that never runs) runs through the path-mode interpreter, whose `reduce` copied its array state on every `. + $x` step, so `add` and `flatten` of an array of arrays were quadratic in the result. `[range(1600)|[range(1600)|0]] | if false then (1 |= 1) else . end | add | length` was quadratic in the size of the result where jq 1.7.1 is linear, and is now linear. A step that only appends to an array state now appends in place, as jq's `f_plus` does.
