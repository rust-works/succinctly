- **yq: an explicit key inside an explicit key's value is read as the mapping it opens** (#6340). The node after an explicit key's `: ` can be a compact mapping whose first entry is an explicit key (`? a` / `: ? x` / `  : y` is `{"a": {"x": "y"}}`); `succinctly yq` read `? x` there as a plain scalar (`{"a": "? x"}`) and refused the `: y` after it, in a mapping, a sequence item and a nested mapping, with any depth of nesting (`: ? x` / `  : ? p` / `    : q`). A key sequence whose first item opens one (`? - ? x` / `    : y` / `: v` is `{"": "v"}`) was `inconsistent indentation`. A property before the inner `?` (`: &t ? x`) is refused, as yq refuses it.
