- **jq: `--stream -s` evaluates the slurped event array where it is** (#5744). The array of `tostream` events was
  written out as JSON text, indexed and read back before the program ran: 31% of the instructions of
  `--stream -s 'length'`. It is now handed to the owned evaluator as the tree it already is. On an Apple
  M-series (interleaved, min of 7, output identical) over a 30 MB `users` file: `length` 0.66x of the old time,
  `fromstream(.[])` 0.50x, `.[0:3]` 0.44x, `tojson|length` 0.46x, `map(length)|add` 0.86x. Programs whose stages the
  owned evaluator declines re-index the array as before, and two of them read slower: `[limit(5;.[])]` 1.18x and
  `[.[]|select(length==2)]|length` 1.05x of the old time at 30 MB (x86_64 not measured).
