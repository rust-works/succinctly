- **yq: block scalars survive a write, and `style = "literal"`/`"folded"` work** (#2707). Any DOM
  write to a document holding a block scalar (`.b = 1` on `a: |\n  x\n  y`) re-rendered it as
  `a: "x\ny\n"`; it now stays `a: |` with its chomping (`|-`, `|+`), indentation (`|2`) and folded
  (`>`) forms, a trailing comment on the header line and an anchor before it. `.a style = "literal"`
  and `"folded"`, which exited with `not yet supported`, write a block scalar (a non-string scalar
  becomes a string), and a string with a line break and no style of its own is written as one too
  (`.b = "x\ny"` is `b: |-`), as go-yaml does. A string go-yaml cannot write as a block (a trailing
  space or a space before a break, a character it will not write raw) keeps double quotes, in the
  go-yaml spelling. Ported from libyaml's emitter and checked against yq v4.53.3 on about 5,000
  random strings, in a literal and a folded block, in a mapping, a sequence and a flow collection.
  `style = "tagged"` is still refused.
