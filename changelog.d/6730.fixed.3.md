- **`succinctly jq --seq -s --stream` and `--seq -s --stream-errors` meet the fault of a record left open across files at the read jq does, when a file after it did not open** (#6730, family 1, the `--seq` form). `jq -c --seq -s --stream . trunc pa missing` (`trunc` = `\x1e[1,`, `pa` = `[1]`) printed nothing and said `ignoring parse error: Unfinished JSON term`; it now prints the array and says only `Could not open file missing`, as jq does, because the read of the failed file brings out the closing event `pa` held back and the fault waits for a read the main loop never makes. A directory last is the same read: `--seq -s --stream-errors . trunc pa dir` no longer prints the fault as a second output, and `--seq -s --stream` over the same files prints the array, as jq does.
