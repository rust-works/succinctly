- **jq: `--seq` prints each ignored parse error when the main loop reaches it, for every program** (#6147). A program that never reads `input`/`inputs` printed every `jq: ignoring parse error: ...` up front; jq prints each after the values before it, so `halt` on an earlier value suppressed it and a runtime error on an earlier value came ahead of it. A differential of 1,500 random `--seq` streams over eleven programs and five flag sets against jq 1.7.1 differed on 103 before and on none now.
