- **jq: a comment after a quantifier, then a second repeat operator, repeats the quantified item inside a loop body, as in Oniguruma** (#6303).
  `b*(?#)*` is `(?:b*)*` and `b+(?#)?` is `(?:b+)?`, not the lazy `b+?`, but the comment was kept for the engines to repeat, so `"bab" | [match("(?:b*(?#)*|a)+"; "g") | .string]` was `["bab",""]` where jq answers `["b","","b",""]`. A greedy `*`, `+` or `?` followed past the comments by another is now the one quantifier with the same language and the comment is left out. Over 68,970 generated cases 544 were fixed and none broken; a capture group, an interval or a lazy `*?` as the second repeat still differs (`docs/compliance/jq/limitations.md`).
