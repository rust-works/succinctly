- **yq: a `select` over `key` in the target of a write** (#6206). `(.. | select(key == "x")) = 5`, `|=`, `+=` and `del(.. | select(key == "x"))` resolved to no target, so the write did nothing and exited 0, where yq writes to every node whose key matches. The `select` condition is now judged against the key of the node it stands at, so `(.. | select(key == "x") | key) = "q"` renames too. `succinctly jq`'s own `key` takes the same path. A `key` that names another node's key (after the head of a pipe) and a negative index in the path are evaluated as before and recorded in the yq limitations page.
