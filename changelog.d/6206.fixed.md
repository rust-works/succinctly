- **yq: a `select` over `key` in the target of a write** (#6206). `(.. | select(key == "x")) = 5`, `|=`, `+=` and `del(.. | select(key == "x"))` resolved to no target, so the write did nothing and exited 0, where yq writes to every node whose key matches. The `select` condition is now judged against the key of the node it stands at, so `(.. | select(key == "x") | key) = "q"` renames too. A `key` that names another node's key (after the head of a pipe, or inside a construct that is not a comparison, an operator or a comma) is evaluated as before.
