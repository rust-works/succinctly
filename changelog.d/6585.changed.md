- **jq: `--input-dsv` reports an unopened file where `-R` does** (#6585). A missing input file is now reported when a read reaches it and the main loop ends after the one row read from past the first one, so `--input-dsv , . missing a.csv missing2` prints the first row and reports `missing` only, where it reported both and printed every row. `-s` and `--validate` still report every missing file up front. Rows are not joined across files, so a record left open at the end of a file is a row of that file and a missing file behind it is not reported, where `-R` joins an unterminated line to the next file's.
