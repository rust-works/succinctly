- **jq: `--input-dsv` reports an unopened file where `-R` does** (#6585). A missing input file is now reported when a read reaches it and the main loop ends after the one row read from past the first one, so `--input-dsv , . missing a.csv missing2` prints the first row and reports `missing` only, where it reported both and printed every row. `-s` and `--validate` still report every missing file up front. A record still open at the end of a file is joined to the next file's and read from the file it ends in, so a missing file between them is reported when that row is read. A last row with no newline stays its own row, so when it is the row read past a missing file the run ends there and a second missing file behind it is not reported, where `-R` joins that line to the next file's and reports both.
