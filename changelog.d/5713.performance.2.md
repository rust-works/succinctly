- **jq: a named string argument is shared, not copied at each `$s` read** (#5713). `--arg`, `--rawfile` and a string `--argjson` were written into the expression as a literal, then copied again at each evaluation, so a program that read an 84 MB `--rawfile` twenty times held twenty copies. The string is now promoted to shared storage once when the arguments are read and a literal holds a refcount to it. On a Ryzen 9 7950X (interleaved min of 5, output identical) an 84 MB `$s|length` runs 130 -> 60 ms and peaks at 91 MB instead of 250 MB; `[range(20)|$s|startswith("a")]` runs 750 -> 50 ms and peaks at 95 MB instead of 1770 MB; `def f($x): [$x,$x]|length; f($s)` runs 220 -> 50 ms (490 -> 92 MB); `$s|test("zzzz")` runs 380 -> 270 ms. A 5000-byte `$s` in a fold (`.arr += [$i] | .s = $s`, 40000 steps) and a 10 MB haystack with a 5000-byte `startswith($p)` needle are unchanged or faster. `succinctly yq`'s own `build_args_var` and the `-R`/`-Rs` input bridge are still built as before.
