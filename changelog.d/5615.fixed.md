- **jq: a number literal with leading zeros keeps its decNumber spelling, and `1..e1` indexes the number** (#5615).
  `00e1`, `007e1` and `007.50` read as the double (`0`, `70`, `7.5`) because RFC 8259 forbids the leading zeros and the spelling failed the validity check; jq drops the redundant zeros and prints `0E+1`, `7E+1` and `7.50`.
  jq's lexer also takes the longest number match, so `1..e1` is `1.` followed by `.e1` (a runtime `Cannot index number with string "e1"`, exit 5), where `succinctly jq` stopped the number before the `..` and refused the program at compile time.
  `succinctly yq` is unchanged.
