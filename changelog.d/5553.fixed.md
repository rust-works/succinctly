- **jq: `-C` colors the line `debug` and `debug(msg)` write to stderr** (#5553). jq 1.7.1 prints `["DEBUG:",v]` the way it prints any value it outputs: compact, in the colors of `JQ_COLORS`, with `-S` and `-a` applied. `succinctly jq` wrote it plain, so `jq -C 'debug("m")' 2>err` differed from jq's bytes (`^[[1;39m[^[[0;32m"DEBUG:"^[[0m…`). The CLI now hands the library the colorizer it uses for stdout, so the line is byte-identical to jq's, including a NaN, non-ASCII under `-a`, and a value past the print depth, whose `<skipped: too deep>` marker takes the color of the value it replaced. Without `-C`, under `-M`, for `stderr` and an uncaught `error`, and in `succinctly yq`, nothing changes. Pinned against jq 1.7.1 in `tests/jq_cli/i5553.rs`.
