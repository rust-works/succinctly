- **yq: an expression is split into tokens on space, tab and newline only** (#5616). yq v4.53.3's
  lexer refuses CR, form feed, vertical tab, NBSP, U+0085, U+2028 and U+3000 between tokens with
  `lexer: invalid input text`; `succinctly yq` skipped everything `char::is_whitespace` accepts, so
  `1<NBSP>+ 1` printed `2`. Three of yq's token regexes take Go's `\s*` and so accept a CR or form
  feed beside them: the `:` of an object entry, the six comparison operators and
  `comments=` / `comments|=`; those stay accepted and nothing else does. `--from-file` now reads
  the file as yq does, with each CRLF turned into LF (inside a string literal too) and a lone CR
  left in place, where `succinctly yq` used to accept a lone CR as whitespace. A CR inside a
  comment is still part of the comment.
