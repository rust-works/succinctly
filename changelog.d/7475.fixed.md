- **jq: a program too long for the native stack is a compile error, not a crash** (#7475).
  About 48,000 chained `E as $x |` bindings, or 500,000 chained definitions, overflowed the stack and aborted the
  process (exit 134). A binding's body now checks the native-stack floor (ADR-0025), and a module-level chain of
  definitions, which the parser reads in a loop, is charged a share of the floor's room per definition for the
  walks after the parse; past either, the program is refused as jq refuses a program too long for its own parser,
  `jq: error: memory exhausted at <top-level>, line 1:` and `jq: 1 compile error`, exit 3. jq refuses far sooner
  (about 2,500 bindings, and between 5,000 and 10,000 definitions); succinctly from about 23,000 bindings and 65,000
  definitions in a release build. `succinctly yq` refuses the same chains (`Error: parse error: ... memory
  exhausted`, exit 1), where yq answers them.
