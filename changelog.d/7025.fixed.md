- **yq: a file with a UTF-8 byte-order mark and a first line `--- text` or `--- # comment` is read as yq reads it** (#7025). The default's header glue, which joins the line after a leading `--- text` marker line onto it, ran on such a file although a mark leaves yq no header to slurp: `--- # c` / `a: 1` lost its mapping (`.a` was empty) and `--- x` / `y` read as `"xy"`. They are `{"a": 1}` and `"x y"` now, as in yq.
