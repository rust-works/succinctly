- **jq: a computed integer compares as a double against a decimal literal, as in jq** (#6275).
  `jq_numeric_cmp` read a bare `Int` as a literal, so the result of `1+1`, `length` or `floor` was compared by its exact decimal digits: `(1+1) == 2.00000000000000000001` and `(0+0) == 1e-400` were `false` where jq answers `true`, and `(9007199254740992+0) == 9007199254740993` likewise.
  A bare `Int` is now a computed double, and the reindex bridge carries one within `2^53` as a token that reads back bare, so `[2.00000000000000000001,(1+1)] | unique` and `[1e-400,(0+0)] | sort` answer as jq does. Two literals still compare exactly. The first value of a `range` still reads as a computed one; the entry is in `docs/compliance/jq/limitations.md`.
