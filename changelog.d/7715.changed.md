- **`succinctly jq --run-tests` says the option is not supported** (#7715). jq 1.7.1's manual documents `--run-tests [file]`, jq's runner for its own test files, which `succinctly jq` does not implement; it refused it as `Unknown option --run-tests`, and now prints `jq: --run-tests is not supported: succinctly jq does not run jq's test files` (exit 2), recorded in `docs/compliance/jq/limitations.md`. As in jq, the words after it are not read as options.
