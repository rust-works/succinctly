- **`succinctly yq` prints an earlier entry of a repeated key as it was spelled** (#6335). A mapping with a repeated key keeps every entry, but the by-key presentation tree described only the last one, so a write printed `a:` (an empty value) as `a: null`, and `~`, `Null` and `True` as `null`, `null` and `true`, for every entry before the last (`printf 'a:\na: 2\n' | succinctly yq '.zzkey = 1'` now prints `a:` / `a: 2` / `zzkey: 1`, as yq does). The spelling is kept per earlier entry, in the key's metadata, through `=`, `|=`, `del`, `*`, `with_entries(.)` and a `to_entries | from_entries` with nothing between the two; of 570 rows (30 documents, 19 programs) compared with yq v4.53.3, 206 that differed now agree and none regressed. A filter between `to_entries` and `from_entries`, `*+`/`*d`/`*n`/`*?` and `pick` still lose it. A tag, quotes, a comment or an anchor on an earlier entry are still written plain (recorded in `docs/compliance/yq/limitations.md`).
