- **jq: `getpath` of a bound container reads one element, not the whole container** (#7721).
  `[range(n)] as $a | reduce range(n) as $i (0; . + ($a|getpath([$i])))`, its `foreach`, `until`, `limit` and
  `[range(n) as $i | $a|getpath([$i])]` forms, `$o|getpath(["k",$i])`, and the same reads of a document, an
  `input` or a `--slurpfile` value wrote the bound container out and indexed it again for every read, because
  neither the in-place fold step nor the owned evaluator's doors had a `getpath` stage: the time grew with the
  container's size times the number of reads, quadratic where jq 1.7.1 is linear. A `getpath` whose path never
  reads `.` now walks the bound value in place, with the walk the evaluator's own `getpath` takes; a path that
  raises or is not an array keeps the evaluator's route and its message, and the answers are unchanged.
