- **jq: a fold whose step is `[.]`, `[., <closed>…]` or `{k: .}` is linear in the number of steps** (#5875).
  The step used to write the whole accumulator out as JSON and index it again every time, so a fold that
  nested past 384 levels (#5832) was quadratic: `reduce range(40000) as $i (0; [.]) | length` took 16.7 s
  where jq takes 0.03 s. The new container is now built around the moved accumulator, and the same program
  runs in 0.09 s (an Apple M-series chip, release build; the time is flat from 5,000 to 400,000 steps, and
  10,000,000 steps take 1.2 s in 774 MB, where jq has long since crashed). Output is unchanged, byte for
  byte against jq 1.7.1 on 67 programs. `succinctly yq` is unchanged.
