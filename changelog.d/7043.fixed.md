- **yq: `key` after a `select` keeps the node of a key that only begins like a scalar** (#7043).
  `.x[] | select(true) | key | head_comment` answered `""` for a key such as `n1`, `no`, `t1`, `1a` or `.a`, and `line` answered `0`, where yq answers the key's comment and line; a key spelled `a1` was unaffected.
  The key is now handed on as its node whenever its node reads as the same string, so `head_comment`, `line` and the rest read the key's own metadata.
