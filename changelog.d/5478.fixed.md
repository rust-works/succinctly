- **`succinctly yq` reads an empty or whitespace-only JSON input as the empty document, as yq does** (#5478). `printf '  \n' | yq -p=json .` printed nothing (and `--eval-all` failed with `invalid cursor position`), and a zero-byte file printed `null`, where yq prints a blank line (`[.]` is `-`) and spells it `null` only for JSON output. A whitespace-only JSON file among others now reads no document, as an empty one does, so `file_index` and `filename` name the right file.
