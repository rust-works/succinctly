- **yq: a line holding only a tab after a plain scalar is refused when the tab is no deeper than the block that owns the scalar** (#6286).
  `a: x⏎⇥` (and one level down, after a sequence item, with spaces before the tab) was read as an empty line; go-yaml stops with `found a tab character that violates indentation` when the tab's column is at most the block's indent, and reads the line as empty when it is deeper.
  A document-root scalar has no block to violate and is unchanged.
  The same line after a flow collection, a quoted scalar, a comment or a key with no value is refused at any column by yq and is still read at a deeper column here.
