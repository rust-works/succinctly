- **`succinctly jq -n -s` says a directory given last after a text with one parse error at its
  end, as jq does** (#6671). `jq -c -n -s '(try input catch .), (try input catch .)' t.json dir`
  with `t.json` holding `[1,` printed the `Unfinished JSON term at EOF` error and `[]` but not
  `jq: error: Is a directory`, which jq prints on the read of the array. A slurp whose text
  faults now leaves its failures to the reads that follow the fault, as one with several faults
  did since #6625; it also covers `"abc` and `nul`, and a missing file after the text.
