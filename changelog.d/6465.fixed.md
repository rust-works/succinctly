  For `{"\xff":` followed by 300 `[`, a newline and `}`, `succinctly jq` named the refusal at column
  262, counting each invalid byte as the three bytes of the U+FFFD it is replaced by; it now names
  jq 1.7.1's column 260, under `input`/`inputs` and in the main loop alike, and the fault after it
  under `input` is placed from there as #6454 places it. An invalid byte in an earlier document on
  the same line is counted the same way.
