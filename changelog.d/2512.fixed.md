- **yq: a write pipe whose `del` renumbers an array keeps each element's comment and style** (#2512). `del(.arr[0]) | del(.arr[0])` over `arr: [a # ca, b # cb, c # cc, d # cd]` printed `c # ca` / `d # cb`, each survivor wearing the comment of the slot it moved into; it now prints `c # cc` / `d # cd` as yq does, and so do a write before or after a `del` of the same array (`.arr[2] = "Z" | del(.arr[0])`, `del(.arr[0]) | .arr[1].x = 9`), a `del` of a field of an element another `del` renumbers, and a replaced element that carries a node of the old one (`.arr[1] = (["new"] + .arr[1]) | del(.arr[0])`). Each stage's static indexes are now read in the array it saw; a negative index into an array a `del` renumbers and a single `del(...)` whose comma branches nest still print the old way, and a write past the end of the array, which pads it, still differs from yq.
