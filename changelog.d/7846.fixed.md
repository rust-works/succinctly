- **`succinctly jq` answers a tree recursion through a string interpolation or an object over a leaf with several outputs one level deeper again** (#7846). Since #7787 a part of a string interpolation, or an object's key or value, that holds a call to a recursive def asked whether it answers once in a frame of its own around the part's evaluation, so a part that streams kept that frame under every suspended level of the recursion: `def f($n): if $n <= 0 then (foreach (1,2) as $x (0; . + $x)) else "\(f($n - 1))\(f($n - 1))" end; first(f(12)) | length` was refused with `f/1 exceeded maximum recursion depth` where jq 1.7.1 and 1.8.2 print `4096`. The question is now answered before the part runs, and a part that streams runs from the construction's own frame, as it did before #7787.
