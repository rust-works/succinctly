- **jq: field lookups, `@tsv`, `--stream` and `inputs` over NDJSON cost less per record** (#7260).
  A field lookup compares an unescaped key's bytes with the name instead of decoding every key, twice;
  `inputs` over a run of plain documents checks each one in a single non-allocating pass instead of
  splitting it and then validating it again; `@tsv` writes each row in one pass; and `--stream` hands
  events to the program as it makes them, sharing each path's keys. At 10 MB, on an AMD Ryzen 9 7950X
  and an Apple M4 Pro: `[.id,.name,.score]|@tsv` is 16% and 23% faster, `reduce inputs as $u (0;.+$u.score)`
  18% and 23%, `select(.score>500)|.id` 9% and 16%, `-r .name` 10% and 14%, `.users[].name` 9% and 18%, and
  the `--stream` reduce 6% and 3%.
