- **jq: `length`, `startswith` and `endswith` of a lone last-stage string no longer write the string out and index it again** (#5691).
  `--rawfile s big '$s|length'` took the string through the re-index bridge: an escape pass over every byte to write its JSON text, an index over that text, and a second UTF-8 validation to read it back, only to count it or compare its first bytes. The string is now answered from directly when the call is the last (or only) stage; a document string and a `-R` line are served the same way. A composed use (`$s|length|tostring`, a `select` condition) is covered separately (#5712). On a 84 MB `--rawfile` on an AMD Ryzen 9 7950X, `$s|length`, `$s|startswith("zzz")` and `$s|endswith("zzz")` take 131-133 ms instead of 382-385 ms (2.9x), peak memory 337 MB instead of 528 MB; 10 MB: 18 ms instead of 49 ms, 1 MB: 3.1 ms instead of 6.1 ms. Output is identical in both modes. Measured on one machine (x86_64); ARM64 was not.
