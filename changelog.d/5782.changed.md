- **`ArrayOf<V>` and `ObjectMapOf<V>` now require `V: Teardown`** (#5782). The element type of the public `jq::ArrayOf` and `jq::ObjectMapOf` (and `ObjectBuilder`) carries a `#[doc(hidden)]` marker trait, implemented for `OwnedValue`, `JqValue` and `()`, so a downstream `ArrayOf<String>` or `struct W<V: Clone>(ArrayOf<V>)` no longer compiles, and both containers now have a `Drop`, which tightens drop check on code holding a `JqValue` that borrows from a shorter-lived buffer. Neither is reachable from the CLI.
