- **yq `-p xml -o xml` keeps the first comment's trailing blank** (#7202). The comments before a document's first element are that first key's head comment, as yq's XML decoder gives them, so `<!-- ` followed by a line break is written back as `<!-- ` and not `<!--` (the commonest difference of a sweep of 1,500 real XML files). A comment after a closing tag is still attributed by the YAML reader (#7212).
