- **jq: a compound stage (`,` `//` `if`, a parenthesised pipe) whose every branch leaves the path register alone leaves it alone as a whole, so `path(. as $x | 5 | (select(.), 7) | $x)` is `[]` twice** (#3767, part 5).
  jq backtracks to the fork each branch starts from, so after `5 | (select(.) // 7)` or `5 | if . then select(.) else last(.a) end` the register is back at the root and the frozen `$x` is still
  accepted. `stage_is_register_keeping` now recurses through `,`, `//`, `if` and a pipe, asking each branch `cannot_move_register`, the leaf verdict and the stage rule itself, so a `try (select(.), error("e")) catch .`
  over a compound body is read too. `path`, `=`, `|=` and `del` through such a `$x` answer as jq does. A branch that navigates (`(select(.), .a)`), a navigating tail (`(select(.) | .a)`) and a `def` call
  (`def g: last(.a); g | $x`, which `cannot_move_register` never admits) still refuse. jq mode only (ADR-0018). Pinned by `test_register_compound_stage_of_register_keeping_branches_3767`.
