- **yq: a copy into a parenthesized comma of spelled bracket keys takes the source's comment** (#8062). In a document with an alias, `(.m[0x1], .m[01]) = .s[0]` left each target's own comment where yq puts the source's (`"0x1": first # t0`, not `"0x1": first # f`): the resolution of spelled keys that #7999 added read a bare comma but not one in parentheses, which is how a comma is written, so its keys stayed unresolved. It now matches the static `(.m["0x1"], .m["01"]) = .s[0]` and yq v4.53.3.
