- **`-e` changes the exit status and nothing else** (#7757). A fault the program reached did not end the document under `-e`: `printf '[2,]\n' | succinctly jq -c -e '.,1'` printed jq's parse error and then `1`, and `.,.` reported the fault twice, where jq 1.7.1 and 1.8.2 print the error alone, as `succinctly jq` without `-e` did. `-e` materialized every output to learn whether it was truthy, and on a fault reported it and went on with the document; it now records the truthiness of each output once it is written, on every route, so it no longer raises on a string the run without it forwards (#5308) either. Over a matrix of 7 faults, 5 contexts, 15 programs and 11 routes, 381 of 5,775 runs printed something different with `-e` than without it (jq: none); none do now.
