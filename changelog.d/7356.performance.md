- **jq: an indented echo no longer holds a long string token twice** (#7356). `.` over an 80 MB object holding one 50 MiB string peaked at 149.6 MB on a 7950X and now peaks 53 MB lower (96.2 MB), 20% faster in wall-clock; a write of 64 KiB or more now goes to the writer as it is instead of being gathered into the chunk buffer first, and every smaller write is chunked as before. Other shapes (`users`, `numbers`, `wide` at 10 and 100 MB) time 1.00x-1.02x of before (an A/A control reads 0.99x-1.01x) with the same output, and 0.5% fewer instructions.
