- **yq: `-o xml` writes the comments of the nodes it prints, where it dropped every one** (#7117). A head comment goes above its element, a line comment inside it after its text, a foot comment after its end tag, and the first document's leading comments ahead of the first element, as yq's XML encoder places them (`printf '<a><!--h--><b>1</b><!--f--></a>' | yq -p xml -o xml .` keeps both comments). `succinctly yq -p xml -o xml .` and `-o xml` over YAML with comments no longer strip them. Pinned against 59 rows from yq v4.53.3 and 1,900 random YAML documents with no difference; a write (`-i`), a value the filter builds and a comment block a blank line splits still differ (limitations.md).
