- **jq: a slice bound computed from the array no longer re-indexes it on every call** (#7110). `$a[$a | length - 5:]` evaluates its bound as `$a | (length - 5)`, a stage with no door of its own, so each evaluation wrote `$a` out as text and indexed it again to read one length (3.7 ms per call over 100,000 elements, linear in the calls: 3.7 s for 1,000 slices, against jq 1.7.1's 0.03 s). Arithmetic over a container's count and number literals (`length - 5`, `2 * length`, `(length - 1) * (length + 1)`) is now answered from the owned container, as `($a | length) - 5` already was; an operation that raises (`length / 0`) or reads a non-count still goes through the evaluator, which keeps its error.
