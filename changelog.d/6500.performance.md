- **jq: a `--seq` stream with one malformed record no longer holds ten times the stream in memory** (#6500).
  A stream with any diagnostic built an owned value for every record before the program ran; it now converts each record when the `input` queue is read, as `-R`'s lines are, so the values of the whole stream are never held. On an AMD Ryzen 9 7950X, a 100 MB stream whose last record is malformed peaks at 156 MB instead of 1,172 MB (jq 1.7.1: 3 MB) and runs in 3,281 ms instead of 4,089 ms (-20%; the 1 MB and 10 MB streams are -18% and -22%), and a clean 100 MB stream is unchanged (831 ms against 840 ms).
  That is still 0.29-0.33x of jq 1.7.1's speed on such a stream, because the walk runs twice and each record is indexed again (#6620). The M4 Pro was not idle for the measurement, so ARM is not measured.
