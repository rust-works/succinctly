- **jq: `-R` over 2 to 32 files reads a file to its end when the run reaches it** (#7223). A `-R` run over several regular files (4 MiB or more between them) read each file to the length it had when the run opened it, so a line appended to a later file while the run was still in an earlier one was dropped, where jq, which opens each file when its reader reaches it, reads it, and where a list of 33 or more files already did (#7024). Each file is now read to the end it has then, with its descriptor still held from the start, so the answer no longer depends on how many files are named. The same change #7217 made for `input`/`inputs`.
