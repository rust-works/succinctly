- **`succinctly yq -p ini`** (#6925). Reads an INI file as yq v4.53.3 does: a port of go-ini v1.67.0's reader (comments, `[section]`, `=` and `:`, quoted keys and values, `\` continuation, `"""` and backtick multi-line values, `-` auto-numbered keys, `%(name)s` expansion, its errors), a mapping per section with the keys before the first section at the root and every value a string; `--ini-preserve-quotes` is read too. Under `-p auto` a first file named `*.ini` picks the format and prints in it, and `-i` writes it back. It agrees with yq on 4,200 random files, apart from the rows recorded in `docs/compliance/yq/limitations.md`.
