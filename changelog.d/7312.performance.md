- **jq: a `--seq` file that does not open with an RS holds a megabyte less** (#7312). A lone regular
  file with no RS byte (or text, a BOM or white space before the first one) is handed on to the
  whole-stream route at its first byte, but the windowed start of #7262 first read a 1 MiB window of
  it, found it to be all tail and freed it, and the allocator kept that block resident beside the
  file. The first read is now a page when the first byte is not an RS (judged where the run reads
  from, so a file on standard input counts from its offset). Output is identical, and a stream that
  opens with an RS is read as before. `--seq .` over a 7.1 MB users file (peak memory footprint,
  11 interleaved runs) went from 9,776 to 8,752 KB on an Apple M4 Pro, the figure before #7262
  (8,736 KB), and over 70 MB from 74,784 to 73,792 KB. On an AMD Ryzen 9 7950X peak RSS went
  from 16,964 to 15,988 KB at 7.1 MB (41 runs; 15,596 KB before #7262) and is unchanged at 70 MB.
  Time is unchanged within the noise on both.
