- **yq: `style` of a node with an explicit tag is `"tagged"`, or `"<unknown>"` when something else styles it** (#6881). yq reports `"tagged"` for `a: !foo x`, `a: !!str x` and a tagged block collection, and `"<unknown>"` for a tag with quotes, a block scalar or a flow collection (`!foo "x"`, `!foo |-`, `!foo [x]`, a CloudFormation `!Sub "..."` or `!GetAtt [a, b]`); `succinctly yq` answered the style without the tag (`""`, `"double"`, `"flow"`). The non-specific `!`, an alias node and an untagged node are unchanged. Found by a differential sweep of real YAML files (15 `!string |-` scalars in Go's simdgen tables counted as `literal`).
