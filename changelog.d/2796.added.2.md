- **yq: `. head_comment = "x"`, `. foot_comment = "x"` and `. comments = "x"` set the document root's comments** (#2796, part 2). `succinctly yq '. head_comment = "single"'` on `a: cat` raised `head_comment = ... is not yet supported`; it now prints `# single\na: cat`, as yq v4.53.3 does (`. foot_comment` prints the lines after the document, `. comments` sets head, foot and, for a flow or empty container root, the line comment; a multi-line text becomes one `# ` line each; `|=` works too). The lines that belong to the document's entries stay where they are, and a scalar root takes none of it, as in yq. A metadata write whose filter asks `di`/`fi` before it is still refused, but one after it no longer is. Other targets (`.a head_comment = "x"`, `.. head_comment = "x"`) and `tag =` still raise `not yet supported`: where yq prints a comment set on an inner node follows go-yaml's emitter state, which the emitters here do not model. Checked by 11 pinned-yq goldens and a differential fuzz of about 2,800 root writes over random commented documents, none differing.
