- **jq: `-s` prints no array before a fault at the end of the text** (#7807). Over a text whose last byte completes a value while the parser still holds an unfinished one, `-s` printed the array and then the error, as jq 1.7.1 does: `printf '2[' | jq -c -s .` printed `[2]`, `--stream -s` printed `[[[],2]]` for `2"` and `[[[0],1]]` for `[1,`, and a file that did not open before the text hid the error altogether. Now the error is printed alone, as jq 1.8.2 does (jqlang/jq#3279, the change #7523 adopted for `--stream -s`), on every route that slurps: plain `-s`, which had answered `2"` that way already and `2[` the old way, `--stream -s`, `--stream-errors -s` (the fault event is the array's last) and `-n -s` (the first `input` raises the fault, the second returns the array). Positions stay jq 1.7.1's (#7607). The difference from the pinned 1.7.1 is recorded in `docs/compliance/jq/limitations.md`.
