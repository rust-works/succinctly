- **jq: `test`, `index`, `rindex` and `inside` of a string literal are answered from a string input without writing it out and decoding it again** (#5816). `-Rs 'test("zzz")'` over an 18 MB file is 87% faster on an Apple M5 Max (56.8 ms to 7.7 ms, jq 1.7.1 is 30 ms), `index("zzz")` 84%, `rindex("id")` 87% and `inside("x")` 87% faster, `-n --rawfile s F '$s|test("zzz")'` 90% faster (54.2 ms to 5.6 ms), and `-R 'test("9")'` per line over 200k lines 41% faster. The same shapes inside `[...]`, `select`, `and`/`or` and `if` conditions are answered too: `[.users[]|.name|test("a")]` over a JSON document is 23% faster. A pattern or flags that is not a string literal, a pattern that does not compile and every error keep the evaluator's route and text. A program that reads the string more than once through a composite (`[test("a"), test("b")]`) still decodes it once per read, as before.
