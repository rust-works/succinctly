- **jq: a `reduce` UPDATE that hands the accumulator back after a register destructure now answers in path position as jq does** (#3953, a #3940 residual). `path(reduce 1 as $k (.; (. as {a:$a} | .)))` refused (exit 5) where jq answers `[]`, as did `del()` (`null`) and `= 5` (a root write), and so did a `foreach` in UPDATE whose source destructures or navigates the register (`path(reduce 1 as $k (.; (foreach .[]? as $k (.; .; .))))` on `[true]`). jq backtracks a `reduce`'s source and UPDATE, so the register its final check reads is INIT's however far UPDATE navigated, and an UPDATE that emits the accumulator's own node leaves the accumulator at the register. The resolver now says so for a syntactically node-preserving UPDATE (`.`, a pipe of such, a single-pattern bind of `.` whose body is one, a `foreach` whose INIT, UPDATE and EXTRACT hand the state on), and a no-op bind body is no longer refused inside the UPDATE of an outermost `reduce` whose source, INIT and loop pattern cannot move the register. A destructured `$var` handed back, an array pattern on an object, a literal INIT, an UPDATE that navigates after the bind, and a `reduce` whose own source navigated (where `.` is not the register: `del(reduce .[]? as $k (.; foreach (. as {a:$a} | .) as $k (.; .; .)))` still raises) are unchanged. A `foreach` outer fold, which emits from inside the loop, is unchanged too.
