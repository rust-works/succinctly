- **yq: overwriting a flow container with a scalar keeps the container's trailing comment** (#5258). `.b = 5` over `b: [1, 2] # t` printed `b: 5` and dropped `# t`; yq prints `b: 5 # t`. A write that changes a node's kind now leaves the node's same-line comment beside its new value whenever the value fits on the line: a scalar, a multi-line string (`b: |- # t`) or an empty `{}` / `[]`, from a flow sequence, a flow mapping, an empty one or a scalar. 55 rows match yq v4.53.3 byte for byte. A non-empty block container written over the node still drops the comment where yq moves it to the next line, recorded in `docs/compliance/yq/limitations.md`.
