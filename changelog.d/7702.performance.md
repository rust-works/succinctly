- **jq: a fold or loop step whose update calls a `def` no longer copies the state at each step** (#7702).
  `def f($v): .a = $v; {x: [range(k)]} | reduce range(400) as $i (.; f($i))`, and the same update in `foreach`
  (EXTRACT included, a call there too), `until`, `while`, `recurse`, `limit(n; recurse(..))` and a pipe of a call
  and a write, wrote the whole state out as JSON and indexed it again at every step, so the run's time grew with
  the size of `x`, a member the steps never touch, where jq 1.7.1's does not. The step now hands the state to
  the owned evaluator's door for a call (#7483), which writes in place: on an x86_64 box under cachegrind the
  `reduce` at k = 100,000 retires 78 million instructions where it retired 22.3 billion, and every shape above is
  now flat in `k`. The answers are unchanged.
