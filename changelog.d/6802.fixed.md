- **yq: an `ireduce` folds a list of accumulators, as yq's does** (#6802). An UPDATE with several outputs kept only its last (`. as $i ireduce (0; (. + $i, . * 10))` over `[1, 2]` printed `0`; yq prints `3 2 10 0`), an UPDATE with no output left `null` where yq prints nothing, and an INIT with several outputs (`ireduce ((0, 100); . + $i)`) folded the later ones over a `null` source (`3 100` for yq's `3 103`). Each output of UPDATE is now an accumulator of the next step, a union in it is branch-major over the list, an empty one drops its accumulator, and every INIT output folds the one source. A fold with one accumulator answering once is stepped as before. jq's `reduce` is unchanged. An absent key read through the loop variable (`. + [$i.a]`) and an UPDATE that answers the loop variable still differ (limitations).
