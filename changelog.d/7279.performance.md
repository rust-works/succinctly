- **jq: `--seq` over 2 to 32 files reads the files before a bad one a window at a time** (#7279).
  A `--seq` run over several regular files (4 MiB or more between them, held open by the run) was
  read whole, every file of it, if any one file was not plain `RS value LF` records ending in an LF.
  The files before the first that is not are now read a window at a time, and only that file and
  the ones after it are read whole, as a list of more than 32 files already was (#7221). Over
  100 MiB of records in 8 files, `--seq -r .name` with a bad record in the last file went from
  1249 to 803 ms (-35.7%) and 245.9 to 41.4 MiB peak RSS on an AMD Ryzen 9 7950X, and from 1068 to
  727 ms (-31.9%) and 252.6 to 38.0 MiB on an Apple M4 Pro; in the fourth file, 245.7 to 158.5 MiB
  and 252.6 to 167.3 MiB. A bad record in the first file costs what it did. Output is identical.
