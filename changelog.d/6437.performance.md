- **jq: `-R` makes each line a string when the program gets to it** (#6437).
  A `-R` program that reads no `input` built every line's string before it ran, holding about 3.5
  times the input: `-R length` on a 95 MB file peaked at 331 MB. Lines now come from the producer
  `input` already reads them through, so the run holds the file and the line being read: 95 MB, the
  JSON route's share (jq 1.7.1: 2 MB). On an Apple M5, `-R length` went from 152 to 123 ms and
  `-r -R .` from 148 to 118 ms at 95 MB (jq: 473 and 348 ms); `-R fromjson|.id` is 1.09 to 1.06 s
  (jq: 1.21 s). Output, locations and `input_filename` are unchanged.
