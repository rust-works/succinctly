- **yq: a comment between a lone dash and its container, in an explicit key's first item, is written on the dash line** (#6593). `? -` / `# c0` / `   - y` / `: v` printed `? # c0` / `  - - y` / `: v`; it now prints `? - # c0` / `    - y` / `: v` as yq does, and the comment heads the first node of the container below the dash (`.[0][0]`), as it does for an ordinary item. The key branch's own lookahead had recorded the comment lines as pending, so the shared routine that places them counted them as lines above the dash. Across 450 shapes (a key, a nested key and a value's dash x five bodies x one or two comment lines x comment columns 0-4 x three indents) the output differs from yq in 0, where it was 240; a scalar below the comment (`? # c` / `  - x`) is unchanged.
