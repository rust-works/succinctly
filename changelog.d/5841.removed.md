- **The `unshared-containers` cargo feature** (#5841). It was the measurement-only A/B holdout for #2999's shared (`Rc`) containers: it rebuilt the pre-#2999 layout (object map behind a `Box`, array `Vec` inline, every clone a deep copy) and was never meant to ship. ADR-0024 recorded that experiment's numbers in 2026-09, and nothing has measured with it since. Removing it also deletes 1,240 `ignore = "holdout ..."` test attributes, about 270 `cfg` sites in `src/jq` and the x86_64 `holdout` CI leg. A build that names the feature now fails to resolve it, and `--all-features` builds the shipped container layout.
