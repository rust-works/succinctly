- **yq: a `%YAML` directive outside the head is checked, and a directive after a document's content ends the document** (#6419). yq's header slurp takes a `%YAML` line only in the head of the stream, before any other directive; every other one reaches go-yaml, which accepts `1.1` alone (`found incompatible YAML document` for `1.2`), once for a document, with only blanks and a `#` comment after it, and `succinctly yq` skipped them all. A directive at column 0 where a node would start is not an error either: it closes the document as a `...` does, whatever it held (`!!str` is the empty string, `a:` a null value, a block scalar its text), so `a: 1` / `%TAG !e! w` / `---` / `b: 2` is two documents, as in yq, where #6402's refusal read it as an error; a `---` has to follow, and one is also wanted after a directive that ends the stream after a `...`. 42 streams are pinned against yq v4.53.3 in `tests/yq_cli/i6419.rs`, and `scripts/yq-directive-name-sweep.py` (21,000 random streams) broke none that the build before read as yq does.
