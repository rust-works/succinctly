- **yq: a tag on a flow collection, an empty flow collection or a mapping key is kept on YAML output** (#4088). `a: !!seq [1, 2]` printed `a: [1, 2]` (and `.a` printed `[1, 2]`) on the cursor-streaming route, because only a block container's tag was written there; `a: !Foo {x: 1}`, `- !Foo [1]` and a tagged root collection lost theirs the same way. On the DOM routes (`-P`, `=`, `|=`, `del()`) a tag on a mapping key (`!Foo k: v`, `!!str 1: v`, the key of an implicit pair `[!Foo k: v]`) was dropped outright, and `-P` also dropped a core tag on a container it does not restate (`!!str []`, `!!seq {}`, `!!int {a: 1}`), keeping only `!!seq` on a sequence and `!!map` on a mapping as yq does. Output now matches yq v4.53.3 on all of these; a core `!!null` on a container is still dropped by `-P` (#4111).
