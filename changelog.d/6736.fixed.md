- **yq: `map(.)`, `sort`, `reverse`, `unique`, `select` over `.[]` and an array of nodes keep the comments between a sequence's items** (#6736).
  `printf -- '- a\n# c\n- b\n' | yq 'map(.)'` prints `- a` / `# c` / `- b`, where `succinctly yq` printed the items without
  the `# c`: the cursor streamers wrote only each item's own trailing comment, so only a query that built an owned value
  kept the others. They now write each item's head and foot comments, the blank line after a foot when another item
  follows, and the comment on a bare `-`, as the sequence arm of `.` does. Over 14,768 document x filter x option rows
  (comment placements above, between and after items, blank lines, nested sequences, anchors, tags, multiple documents,
  CRLF) against yq v4.53.3, 619 rows that differed now match and none that matched changed. Still not written: a document's
  own foot comment after a reordered root sequence, and the comments of a chain of two reordering stages
  (`sort_by(.id) | reverse`).
