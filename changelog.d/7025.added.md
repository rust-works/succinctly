- **yq: `-c` / `--yaml-compact-seq-indent`** (#7025). A block sequence under a mapping key is written two columns left of where the default puts it, at the key's own column for `-I 2`: `a:` / `- d` / `- e: 1` instead of `a:` / `  - d` / `  - e: 1`, the kubectl style. The default column is the next multiple of the indent width past the key, so the rule holds for a key inside a sequence item and for `-I 3`, 4 and 6 (measured against yq v4.53.3 over ten nestings, and over 588 YAML files of the repository with no difference the flag causes). It takes its value after `=` only (`-c=false`), JSON output is unchanged, and the run is written by the emitter that keeps comments, anchors and styles.
