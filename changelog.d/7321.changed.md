- **macOS release binaries no longer run on macOS 11** (#7321). The `succinctly-macos-arm64` archive is now built for
  macOS 12.0 (`MACOSX_DEPLOYMENT_TARGET` in `.cargo/config.toml`), not rustc's default of 11.0 on arm64. `cargo install
  succinctly --features cli` builds for the default target and still runs on macOS 11. `succinctly dev compare jq` now
  times a copy of the binary stripped as the release archive's is, not the unstripped `target/release/succinctly`.
