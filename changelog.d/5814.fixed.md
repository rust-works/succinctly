- **yq: a tab between a quoted or alias key and its `:` is read as yq reads it** (#5814).
  `- "k"\t: 1` was a parse error ("mapping values are not allowed in this context"), and `"k"\t: 1` in a block mapping was reported as "tab character used for indentation".
  A tab there is separation, as a space is, so both now parse (`[{"k": 1}]` and `{"k": 1}`).
  A tab that indents block structure is still an error.
