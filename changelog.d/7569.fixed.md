Every route counted from the text after the mark, so values near the end of such a line reported line 0 where jq reports 1 (`BOM` + 2,048 `1 ` values + a newline: 2,047 values on line 0 here, 2,046 in jq). Fixed on the routes that read the files whole, a window at a time and through the stream reader (`--stream`, `--stream-errors`, `-n`), on standard input, and for a mark cut across files.
