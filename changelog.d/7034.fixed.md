  `- # m` / `  a: 1` has `.[0].a | key | head_comment` = `"m"` and `- # m` / `  - q` has `.[0][0] | head_comment` = `"m"`, as in yq (both were `""`), with the item's own head lines after it and one empty line for any blank lines between them.
  `a:` / `  #c1` / `` / `  n1: 3.5` has `"#c1\n"` where it was `"#c1"`, and `-o=props` writes the `# ` line yq writes for it, and the bare `-` comment of a scalar item, which it dropped; the YAML output is unchanged, since yq prints no blank line there either.
