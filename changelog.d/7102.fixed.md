- **yq: a run of backslashes before a character other than `(` collapses twice, as in yq** (#7102). yq collapses backslash pairs once in its lexer and once more when the string is read, so `n` backslashes before an ordinary character keep `ceil(n / 4)` of them (`"a\\\x"` and `"a\\\\x"` are `a\x`, `"a\\\\\x"` is `a\\x`); `succinctly yq` collapsed once and kept `ceil(n / 2)`, and agreed only for one and two. Before an escape letter (`n t r b f a v`) or a quote an odd run decodes the escape and keeps `ceil((n - 1) / 4)` backslashes before it, and an even run keeps the letter as text. A string with an unclosed `\(` and a program run with `--string-interpolation=false` collapse once, in yq and here, and are unchanged.
