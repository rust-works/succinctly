- **jq: a slice of a built array is a view, not a copy, so a loop that peels one element per step is linear** (#6659).
  `.[a:b]` of an array the program built (or a loop carries) copied the range; it is now a refcount bump on the
  same storage, as jq's slice is (ADR-0029), and `def`'s tail loop settles a `length > 10`-style condition without
  writing the array out as JSON. On `[range(100000)]` (AMD Ryzen 9 7950X), `def f: if length>10 then .[1:]|f
  else length end; f` went from 233 s to <A/B pending>, `until(length<10; .[1:])` from 1,258 ms to <A/B pending>, and
  `[while(length>10; .[1:])]`, which aborted on an allocation failure, now answers in <A/B pending>. Output is
  unchanged, and a slice now has jq's identity: `[1,nan,2] as $a | $a[1:] == $a[1:]` is `true`, as in jq.
