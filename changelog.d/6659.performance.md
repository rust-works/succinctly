- **jq: a slice of a built array is a view, not a copy, so a loop that peels one element per step is linear** (#6659).
  `.[a:b]` of an array the program built (or a loop carries) copied the range; it is now a refcount bump on the
  same storage, as jq's slice is (ADR-0029), an append to such a view writes in place, and `def`'s tail loop
  settles a `length > 10`-style condition without writing the array out as JSON. On `[range(100000)]` (AMD Ryzen 9
  7950X, before) `def f: if length>10 then .[1:]|f else length end; f` took 233 s, `until(length<10; .[1:])`
  1,258 ms, and `[while(length>10; .[1:])]` aborted on an allocation failure; all three now grow linearly with the
  input. Output is unchanged, and a slice now has jq's identity: `[1,nan,2] as $a | $a[1:] == $a[1:]` is `true`,
  as in jq, where it was `false`.
