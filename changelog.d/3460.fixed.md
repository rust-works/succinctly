- **jq: a `foreach` step now carries the accumulator's node identity across source elements, and a full slice of it** (#3460).
  `path(foreach (1, .a) as $k (.; .a))` on `{"a":{"a":1},"b":{"c":2}}` raised `Invalid path expression near
  attempt to access element "a"` on its second step where jq answers `["a"]` then `["a","a"]` -- step 1's UPDATE leaves
  the accumulator on the very node element 2's `.a` moves the register onto, so jq's `jv_identical` holds. The same gap
  made `path(foreach (..) as $k (.; .a))` (and `recurse`) raise one element early, and `(foreach (.[0:]|tostring) as $k
  (.; .[0])) = 9` on `[1,2]` refuse where jq writes `[9,2]` (a full slice is the same `jv` as its input). A different
  path holding an equal value, a string slice and an empty-array slice still refuse, as in jq. jq mode only.
