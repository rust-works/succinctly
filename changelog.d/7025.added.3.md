- **yq: `--header-preprocess=false`** (#7025). The input is read as an ordinary stream, with no header slurped: the comments above the first node are its head comment (`# lead` / blank / `a: 1` prints `# lead` / `a: 1`), a first `---` is read and not echoed, and the break after a leading `--- text` line is kept (`--- x` / `y` is `"x y"`, the default's `"xy"`). A text of only comments is printed back as it was. It takes its value after `=` only, and every input of a run is read this way. Pinned against rows from yq v4.53.3 in `tests/yq_cli/i7025_header_preprocess.rs` and 10,360 generated runs; a comment or text on a `---` line, a `%YAML` line with no `---` after it, and the `line` of an empty document still differ (limitations.md).
