- **jq: `tojson`, `tostring`, `@json`, `@text` and `"\(.)"` render a built value past 384 levels** (#5554). `def f(n): if n == 0 then 0 else [f(n-1)] end; f(400) | tojson | length` raised `nesting depth exceeds limit of 384` where jq 1.7.1 answers `533`: the pipe's rest was evaluated through a re-index of the value, which refuses one that deep, before the writer could stop at jq's 256 levels and print `<skipped: too deep>`. When the re-index refuses a value and the first stage of the rest only renders it as text, the text is now written from the tree and the rest of the pipe runs on it. A value the re-index accepts is not touched. The same stage inside `try`, a comma, an `as` source or `map`, and the `reduce`/`foreach` accumulator rows of #5554, still read the refusal.
