- **jq: the `$ARGS` object is built only for a program that names `$ARGS`** (#5713). It holds a copy of every named argument and was built and spliced for every run, so a large `--rawfile`, `--arg` or `--slurpfile` was copied into it even when the program never read it. A program that names `$ARGS` (a binder of that name included) builds it as before. `-n --rawfile s <35 MB file> 1` peaks at 38.5 MiB instead of 72.2 MiB (0.53x) and runs 16.8 -> 13.2 ms; `$s|length` and `$s|startswith("zzz")` over the same file peak at 106 MiB instead of 140 MiB (0.76x) and run 12-13% faster (Apple M5 Max, interleaved min of 7, output identical); a program that reads `$ARGS.named.s` is unchanged. The literal splice and the second copy of a string argument, and the `$ARGS` object of `succinctly yq`, are still built as before. x86_64 and the M4 Pro were not measured.
