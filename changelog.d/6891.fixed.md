- **yq: `style` of the single `key: value` pair of a flow sequence is `"flow"`** (#6891). `[cron: "40 1 * * *"]` holds a mapping of its own that begins at its key, which carries no `{`, so `style` answered `""` where yq answers `"flow"` (`[.. | select(style == "flow")] | length` over a GitHub Actions `schedule: [cron: ...]` file was one short). A pair's value, a scalar element, a block sequence item and a block mapping are unchanged. Found by a differential sweep of real YAML files.
