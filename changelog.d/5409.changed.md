- **`bench run jq_bench` and `dev bench jq` interleave the two tools** (#5409). Each repetition now runs both jq and `succinctly jq`, alternating which goes first, instead of all of jq's runs followed by all of succinctly's (rule 1 of `docs/guides/benchmarking.md`, the ordering that once made an improved binary read up to 2x slower). A new `dev bench jq --jq <path>` picks the jq to compare against (default: `jq` on `PATH`; the pinned build is `target/compare/jq-1.7.1/bin/jq`), and the generated markdown names that jq's version, its path and the method. The committed tables in `docs/benchmarks/jq.md` predate the change and say so.
