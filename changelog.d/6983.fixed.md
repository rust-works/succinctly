- **jq: `limit` and `nth` compare a count literal too small for a double with `0` as jq does** (#6983).
  `jq -nc '[limit(1e-1000; 1, 2)]'` is `[1]`, and `succinctly jq` answered `[]`: jq's `$n > 0` and `$n == 0` compare two number literals exactly, so `1e-1000` is above `0` although its double is `0.0`, and `-1e-400` is below it (`limit` passes every output through, `nth` raises `nth doesn't support negative indices`).
  The same holds for a count read from the document, `--argjson` or `tonumber`; a computed count (`1e-1000 * 1`) is a double and still zero, as in jq.
