- **yq: a comma-grouped `del()` stops at a bare root slice whose bounds are computed, as it does for literal bounds** (#5397). `del(.c, .[(1+1):3])` over `{"a":{"x":1,"y":2},"b":6,"c":9}` deleted `.c`; yq deletes nothing, because a slice of the root has no parent and the delete stops there (#1325). The bounds are read against the root and the slice is the stop when each is exactly one integer (`(1+1)`, `(.b)`, `(4/2)`); a bound that gives none, several, `null`, a string or a fractional number is resolved as before. A computed bound on a slice that follows another (`.[0:1][(1+1):3]`) is still not recognised. 23 rows over an object and an array root match yq v4.53.3 byte for byte (two more that raise agree on the exit status, not the wording).
