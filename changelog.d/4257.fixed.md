- **yq: `pick` on an array reads its keys as yq does, and `omit` leaves a scalar alone** (#4257). `[1,2] | pick(["1"])` is `[2]` in yq (a string key is parsed as an integer, Go's `ParseInt`) and was `[]` here; a key that is not an index (`"a"`, `null`, `true`, a float such as `1.0`) is an error in yq and was skipped here; a negative index does not wrap in yq (`pick([-1])` is `[]`) and wrapped here. `1 | omit(["a"])` (also `null`, `true`, a string) is the scalar unchanged in yq and was an error here. jq mode is unchanged.
