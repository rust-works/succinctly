- **yq: `pick` on an array reads its keys as yq does, and `omit` is exact about indices and scalars** (#4257). `[1,2] | pick(["1"])` is `[2]` in yq (a string key is read by yq's own integer parser: `"0x1"`, `"0o1"` and `"1_0"` work too) and was `[]` here; a key that is not an index (`"a"`, `null`, `true`, `1.5`, `1e30`) is an error in yq and was skipped here; a negative index does not wrap in yq (`pick([-1])` is `[]`) and wrapped here. `omit` removes only non-negative integer indices from an array (`omit([-1])`, `omit([1.5])`, `omit(["1"])` leave it alone; they used to remove elements), and `1 | omit(["a"])` (also `null`, `true`, a string) is the scalar unchanged in yq and was an error here. jq mode is unchanged. A YAML-sourced or literal `1.0` is an error in yq and an index here, since a JSON-sourced one is an index in both and the two cannot be told apart.
