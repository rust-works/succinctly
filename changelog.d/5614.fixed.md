- **jq: a number literal with an empty fraction and an exponent keeps its decNumber spelling** (#5614). `1.e1` is the decNumber `1e1`, so jq prints `1E+1` (and `10.e1` as `1.0E+2`, `0.e5` as `0E+5`, `1.e1000` as `1E+1000`); `succinctly jq` collapsed the spelling to the double and printed `10`, `100`, `0` and `1.7976931348623157e+308`. A trailing dot with no exponent (`123456789012345678901234567890.`, `9007199254740993.`) keeps its digits the same way, where it printed the rounded double. The spelling now goes through the same literal path as `1e1`, in a program, `tojson` and string interpolation alike; arithmetic and comparison still see the value. `succinctly yq` is unchanged. Pinned against the jq 1.7.1 source build in `tests/jq_cli/i5614.rs`.
