- **jq: a lone input file named through a descriptor is read to its new end too** (#7446). `jq -c . /dev/fd/7 7<app.log` (and `-R`, and `/dev/fd/0 < app.log` on macOS) read the file whole before the program ran, so lines a writer appended while the run went were dropped, where jq 1.7.1 and 1.8.2 print them. Such a path of 1 MiB or more is now read a window at a time like a named file, from where the descriptor's offset stands when the path shares it (macOS), and its fault is worded from there.
