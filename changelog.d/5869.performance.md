- **jq: `..` and `recurse` over a deeply nested document are linear in its depth, not quadratic** (#5869).
  Through the library `eval` entry, each level of a linear nest `[[[...1...]]]` re-walked the run of
  closing brackets after the innermost value to find its own end for the trailing-comma check. The run is
  now walked once and each level reads its end from it. `last(..)` over 80,000 levels takes 29 ms instead of
  5.3 s, `[..] | length` 35 ms (an Apple M-series chip, release build; the curve is now flat from 10,000 to
  320,000 levels), and `tests/jq_library_eval_nesting_depth_tests.rs`, which cost every CI test leg
  200-256 s, runs in under a second. Output is unchanged.
