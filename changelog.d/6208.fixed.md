- **yq: a flow mapping key that continues on the next line, `{x⏎ y: 1}`, is refused as in yq** (#6208). `printf '{x\n y: 1}\n' | succinctly yq -o json .` printed `{"x y":1}`, where yq stops with `did not find expected ',' or '}'`: a simple key has no line break between its first character and its `:`. The same holds for `{x⏎: 1}`, `{"x"⏎ : 1}`, a quoted key that spans lines, a nested-collection key (`{[a,⏎ b]: 1}`, which was `{"": 1}`) and a key with an anchor. Text across a break that has no `:` is still a multi-line plain entry (`{x⏎ y}` is `x y: null`), and an explicit `? key` may span lines, as in yq. JSON documents read as JSON (`.json` files, `-p=json`) are unaffected.
