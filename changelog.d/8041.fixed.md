- **yq: a string-valued flag takes the next argument even when it starts with `-`, as in yq** (#8041). yq's flag parser gives `--expression`, `--from-file`, `--split-exp`, `--split-exp-file`, `--properties-separator`, `--shell-key-separator`, `--lua-prefix`, `--lua-suffix` and the `--xml-*` name and prefix flags the next argument whatever it looks like, so `yq -n --expression -1` prints `-1` and `--from-file -f.yq` reads a file named `-f.yq`; `succinctly yq` read the word as an unknown flag and refused the command line. It now takes the word as the value. A `-1` that no flag takes (`yq -n -1`, `yq . f.yaml -1`) is still refused, as in yq, and `succinctly jq` is unchanged.
