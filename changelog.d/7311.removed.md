- **`jq::document::collapsed_fields_checked` is removed** (#7311).
  Its two callers, the JSON writer's object arm and `map(f)` over an object, now take a plan of the fields a
  repeated key changes instead of the materialized field list it returned. A downstream caller can take
  `effective_fields_checked(fields, true)`, which returns the same collapsed list for an object that repeats a
  key and every field otherwise.
