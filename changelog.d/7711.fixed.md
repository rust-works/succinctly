- **`succinctly jq` names the line jq names for a syntax error at the end of a program** (#7711). A program, `-f` file or module ending in a newline or blank lines reported its end-of-text syntax error on the empty line after the last one (`printf '[1,\n 2,\n\n\n'` as a `-f` file: line 5 with an empty echo); jq places it at the start of its lexer's last match, the trailing whitespace run or else the last comment or token, so jq 1.7.1 and 1.8.2 say line 2 and echo ` 2,`. `succinctly jq` now places it the same way, with jq 1.7.1's echoed line and padding; in a 3,000-program sweep the first error's line now differs from jq 1.7.1 in 35 of 2,638 compile errors (none at the end of the text), where 800 differed.
