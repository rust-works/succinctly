- **`succinctly yq`'s `map(f)` over a flow-style sequence or mapping prints its result in flow, as yq does** (#6986). `printf '[1, 2]\n' | yq 'map(. == 1)'` is `[true, false]`, not a block list, for every body (`map(.)`, `map(tag)`, `map([.])`, `map(select(...))`, ...), and `.m | map(.)` over `m: {x: 1, y: [2]}` is `[1, [2]]`; the result takes only the node's style, not its line comment or anchor. A block document after a first document that opens with `[` no longer reads as flow (`style` answered `flow` for it). A document with no comment keeps the streaming route for these queries; one with a comment takes the DOM route, as `--arg` does.
