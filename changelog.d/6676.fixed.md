- **`succinctly jq -s --seq --stream` keeps the slurped array when a warning is met before a directory given last, and places open failures among the warnings** (#6676, #6681). jq reads a directory given last at the end of the stream, after every warning of the stream reader, so `jq -c -s --seq --stream . mix.seq dir` (`mix.seq` = `\x1e{]\n\x1e2`) prints `\x1e[[[],2]]` and the warning; succinctly counted the directory first and printed no array. A file that does not open is now said when the reader gets to it, among the warnings by source (`... mix.seq missing.json dir`), and a warning met after a failure was said stops the loop with the array lost, as it does for the record reader (#6589).
