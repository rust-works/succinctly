- **yq: a write keeps the first document's `---` marker** (#4086). Any DOM write (`=`, `|=`, `del()`,
  `-P`, `-i`) dropped a leading `---`, so editing a Kubernetes manifest, an Ansible playbook or a
  generated file that opens with it changed the first line (about 220 of the file/filter pairs that
  differed from yq in a sweep of 2,178 real YAML files). The text before the first document's content
  is now printed back when it holds a `---` on a line of its own: the comments and blank lines above
  it, verbatim, and the marker. Only the first document of a file gets it, `-N` drops the marker lines
  and keeps the comments, and a root that a write replaces keeps it too. Content on the marker's own
  line (`--- 5`) and `%YAML` directives are not handled.
