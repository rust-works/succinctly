- **`OwnedValue::as_array` returns `&[OwnedValue]`, and `as_array_mut` a guard that derefs to `Vec<OwnedValue>`** (#6659).
  An owned array is now a window on shared storage (ADR-0029), so its elements are a slice of a `Vec`, not the
  whole `Vec`. `ArrayOf` derefs to `[V]`; a write that changes the length goes through `ArrayOf::make_vec`
  (the new `ArrayVecMut` guard), and `ArrayOf::slice` makes a view. Code that only reads, indexes or
  pushes through `as_array_mut` compiles unchanged; code that names `&Vec<OwnedValue>` needs `&[OwnedValue]`.
