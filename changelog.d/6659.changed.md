- **`OwnedValue::as_array` returns `&[OwnedValue]`, and `as_array_mut` a guard that derefs to `Vec<OwnedValue>`** (#6659).
  An owned array is now a window on shared storage (ADR-0029), so its elements are a slice of a `Vec`, not the
  whole `Vec`. `ArrayOf` derefs to `[V]`; `ArrayOf::push` and `Extend` append, a write that otherwise changes the
  length goes through `ArrayOf::make_vec` (the new `ArrayVecMut` guard), and `ArrayOf::slice` makes a view. Code
  that reads or indexes through `as_array` compiles unchanged once it names `&[OwnedValue]` instead of
  `&Vec<OwnedValue>`. Through `as_array_mut`, a call chained on the result (`v.as_array_mut().unwrap().push(x)`)
  compiles unchanged; a binding that writes needs `mut` (`if let Some(mut items) = v.as_array_mut()`), and the
  guard has no `PartialEq`, so compare `as_array_mut().is_none()` rather than `== None`.
