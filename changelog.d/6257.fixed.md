- **jq: a computed-bound slice of a malformed array is an error, as the literal spelling is** (#6257). `printf '[1 2 3]' | jq '.[0+0:0+2]'` answered `[1,2]` (and `[1,,2]` with `.[1+0:]` answered `[2]`, `[,]` answered `[]`) where jq 1.7.1 refuses the document at parse time and `.[0:2]` has exited 5 since #6231. The computed spelling swallowed the structural error its own walk found (#4287); it now raises it, and checks an array with no element for a stray comma. The text inside an element the slice drops is still unread (see `docs/compliance/jq/limitations.md`), and a computed index of such an array (`.[0+0]` on `[,]`) still answers `null`.
