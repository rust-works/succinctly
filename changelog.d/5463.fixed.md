- **yq: a YAML file whose size is an exact multiple of 64 bytes and whose last node is a null no longer fails with `invalid cursor position`** (#5463). The interest-bit vector behind the node-to-text map had no word for the null's sentinel position (the text length) at a 64-byte boundary, so the bit was dropped and every later lookup read one entry off. Every write (`.zzkey = 1`), `length` and similar DOM route over such a file (a trailing `key: # comment`, a comment-only file, `a: &x` with an alias) errored where yq answers; the end-position vector had been sized for this already. A differential run of 40 trailing-null shapes across 60-67 and 124-131 byte sizes failed 40 times before and 0 after; found by the real-file sweep of #4099 (a 640-byte `FUNDING.yml` from the cargo registry).
