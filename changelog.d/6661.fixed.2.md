- **`succinctly jq --stream-errors` reports every directory at the end of the file list, as jq does** (#6661). Without `-n`, or with a program that reads `input`, a directory given last behind another failure (`jq -c --stream-errors input p.json dir dir2`, `... p.json missing.json dir`) was counted but only the first was said: jq prints `jq: error: Is a directory` once per directory, the last one from the program's read after the one that reached it. A plain `--stream-errors .` still says only what its main loop reaches.
