- **jq: the path-mode interpreter parses a prelude definition when a program first calls it, not all ~110 up front** (#5858).
  Without the `std` feature nothing cached the parsed prelude, so every `eval` of a program the interpreter takes
  (a non-static `path`, `del`, `pick` or assignment target) re-parsed all of it first: 0.8-1.0 ms per eval on a
  5-element document (Apple M5 Max, release build), 200 times the evaluation itself. It now costs 7-16 µs there.
  With `std` the first such program on a thread no longer pays the ~0.7-1.3 ms parse either; hot interpreter
  loops (20,000-element `|=` and `setpath` reductions) are unchanged and print identical output.
