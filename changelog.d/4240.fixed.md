- **yq: a key or index on a scalar is an empty entry of `{...}`** (#4240). yq yields nothing, not `null`, for `.m.id` when `.m` is a string, so `{"a": .m.id, "b": .n}` is `{"b": 2}` there; `succinctly yq` treated every path as non-empty, kept the cross product and printed nothing. A path now counts as possibly empty, so a record whose construction comes out empty is rebuilt as yq's fold, as #4193 does for `select` and the like. jq is unchanged.
