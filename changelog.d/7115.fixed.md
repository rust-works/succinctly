- **yq: `-o json` of a scalar forced to `!!float` that Go reads as a non-finite number fails as yq does** (#7115). `a: !!float inf` (also `-inf`, `+inf`, `infinity`, `nan`, in any case) wrote the text as a string; yq's JSON encoder refuses it (`json: unsupported value: +Inf`, `-Inf`, `NaN`, once per node from the scalar up to the root), a signed `nan` is `strconv.ParseFloat`'s syntax error and `1e999` its range error. Found by the `-p toml` differential fuzz, where `a = inf` is exactly this node. A hexadecimal float (`!!float 0x1p4`, yq `16.0`) and the DOM routes (`-P`, a write) are still written as before.
