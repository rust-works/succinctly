- **jq: `recurse(.[]?; cond)` over a live document walks cursors instead of materializing it** (#3867). For a `cond` that yields
  at most one value, the walk now delivers each node as its cursor and asks `cond` of each non-root node as it is popped (the owned
  walk's order and error rules, and jq's), where it first built the whole document as an owned tree. `first(recurse(.[]?; true))`
  over a 7 MB `users` document, Apple M4 Pro, release: 0.09 s and 81 MB peak RSS -> 0.01 s and 18 MB (what `first(..)` costs);
  collecting every node is unchanged (0.11 s, 117 MB). jq mode only; `succinctly yq` keeps the owned walk.
