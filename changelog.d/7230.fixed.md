- **`succinctly yq` keeps a scalar's line comment when a write replaces the scalar with a block collection, and writes it where yq does** (#7230). `- 5 # own` / `- 6` written `.[0] = {"a": 1}` is `- a: 1` / `- 6 # own`, as in yq v4.53.3, and so is the comment of an empty flow `[]` / `{}` that a write fills (`a: [] # c` / `b: 6` written `.a = [1]` ends `b: 6 # c`); both were dropped. go-yaml's encoder holds the comment of a block collection in two slots, the pending comment that the next sequence item writes and the one a mapping key moves aside to wait for a later value, and `-P`'s placement of a flow collection's comment (#4377) now follows the same two slots, which also puts it on the dash of a later item a write gave a new kind (`- [1, 2] # ec` / `- 5` with `-P '.[1] = {"a": 1}'` is `- # ec` / `  a: 1`, #6954): an item of a block sequence that has a comment of its own replaces the held one, and one a key moved aside waits past a sequence's items. `-o xml`, `-o lua`, `-o kyaml` and `-o toml` write the comment on the node, as yq's encoders do. A random fuzz of 3,483 documents and writes against yq fixed 208 cases and changed none that already matched.
