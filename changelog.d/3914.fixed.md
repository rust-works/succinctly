- **jq: path register kept through a by-value `if` branch and a `def` call after a recursion** (#3914).
  `path(. as $x | 1 | if false then .. else 1 end | $x)` and `path(. as $x | 1 | def f: ..; f | $x)`
  refused with `Invalid path expression with result ...` where jq 1.7.1 answers `[]` (the `def`
  form then raises jq's iterate error on the recursion's next output), and so did their
  `del`/`=`/`|=` forms. An `if` branch that runs now states the register the `if` was entered
  with, as a `//` alternate does, and a zero-argument `def` call forwards its body's statements.
  A pipe nested in a forwarder, a fold inside an `[E]`, an `if` with no recursion in it and a
  `def` call with arguments still refuse loudly, never with a silent write.
