- **jq: `--seq` over several regular files is read a window at a time, so its peak memory no longer grows with the input** (#7218, the remainder of #6920). `jq --seq -c . a.seq b.seq ...` read every file whole: 248 MiB at 100 MiB of RFC 7464 records split into 8 files on a Ryzen 9 7950X and 255 MiB on an M4 Pro. A run is now windowed when every file is, on its own, plain records (`RS value LF`, the check of one file, #7082) ending in an LF, since the join of two such files is framed as each is; the 8-file case reads in 8.3 MiB on an M4 Pro. Any other list (a file that does not start on an RS, ends mid-record or without a final LF, is empty, or is opened by its path past 32 files) is read whole by the route that walks jq's reader across the seam, as before. Checked against the same files read as descriptors by `scripts/jq-windowed-file-fuzz.py --seq --files K`, which cuts the stream at record starts and anywhere else.
