- **jq: an alternation beside a `(?#...)` comment that spans a line takes its first branch's match too** (#6149). The guard #6134 put in front of an alternation whose branches share a prefix that can match more than one way could not read such a pattern, so `"aab" | match("(?#a\nb)a*a|a*b")` still took the second branch's `"aab"` where jq 1.7.1 gives `"aa"`; so did a pattern whose guarded form the `regex` crate refused for its size. `succinctly` now requires `regex-syntax` 0.8.12 and `regex` 1.13.2, which keep such a prefix in each branch (rust-lang/regex#1400), and the guard is gone, so every pattern gets the first branch's match without a rewrite.
