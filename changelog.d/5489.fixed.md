- **jq: `fromstream` emits a value it has completed before it reaches a malformed event** (#5489). `fromstream(([[0],1],[[0]],["x",[1]]))` printed nothing and raised `array (["x"]) and string ("x") cannot be added`; jq 1.7.1 prints `[1]` and then raises, and `try ... catch`, `?`, `first` and `limit` see `[1]` too (`try fromstream(...) catch "caught"` is `[1]` then `"caught"`). The builtin collected its events, then returned a bare error that dropped the values it had completed; it now returns them as the prefix of the error. 14 rows captured from jq (stdout and exit status) match, and a 16-shape differential found no other difference.
