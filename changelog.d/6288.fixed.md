- **yq: a block-mapping `:` with no `?` before it is `did not find expected key`, as in yq** (#6288).
  `: a`, `a: 1` then `: b`, a second `:` after an explicit key's value and `- : b` were read as an entry with an empty key, and the value was dropped after a mapping entry (`a: 1⏎: b` answered `{"a":1}`); yq refuses all of them. A `:` is now only the value of a `?` key that is waiting for one, and a tag or an anchor before it (`!!str : 1`) stays an empty key. Six YAML test-suite cases that are valid YAML 1.2 but refused by yq (`2JQS`, `6M2F`, `NHX8`, `S3PD`, `SM9W/01`, `UKK6/00`) join the known-failures manifest.
