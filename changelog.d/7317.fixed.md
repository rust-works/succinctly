- **`json::simd::avx2::build_semi_index_standard` and `build_semi_index_simple` are sound on every x86_64 CPU** (#7317). Both are safe `pub fn`s but ran AVX2 instructions with no check, so a caller on a CPU without AVX2 (or a VM that hides it) hit an illegal instruction from safe code. They now check for AVX2 (at run time with the `std` feature; at compile time without it) and otherwise build the identical index with the SSE2 builder. Their signatures are unchanged, and the `json::simd` dispatcher, which already checks, calls the unchecked AVX2 builder directly, so the default path makes one check per build as before.
