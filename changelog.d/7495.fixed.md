- **jq: a fold that writes an array slot by a float-represented whole index is linear again** (#7495).
  `reduce range(1e4) as $i ([]; .[$i] = 1)`, and the same with `|=`, `+=`, `//=`, inside `foreach`, or with an
  index such as `$i * 1.0` or an element of `[range(1e4)]`, rebuilt the whole accumulator on every step, so
  the time grew with the square of the step count where `range(10000)` (an integer index) was linear.
  A whole float key now names the slot its integer spelling does and takes the same in-place write; a
  fractional, non-finite or out-of-range key keeps the evaluator's route, and the answers are unchanged.
