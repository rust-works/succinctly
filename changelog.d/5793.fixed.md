- **jq: an index or slice key that is a failing `map(f)` raises `f`'s error** (#5793). `.[(.a|map(error("x")))]`, `.[(.a|map(error("x"))):]` and `.[0:(.a|map(error("x")))]` over a file or stdin printed nothing and exited 0, and `try ... catch` never saw the error, because the key was read as an empty list. They now raise `x` and exit 5, as jq does; a key that came before the failing one is still indexed first (`.[("a",(.a|map(error("x"))))]` prints `[1]` and then the error). `-n` was already right.
