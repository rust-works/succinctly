- **yq: a node with an explicit tag and no value is the empty string whatever the tag, as in yq** (#6291).
  `k: !!seq`, `- !custom` and `--- !!str` read as `null` in `-o json` output and in a comparison with `""`, where yq answers `""` (`false` for `!!bool`; only `!!null` is `null`). `!!str` and `!!bool` already agreed, and `!!int`/`!!float` with no value stay the empty string where yq's JSON encoder fails (`docs/compliance/yq/limitations.md`).
