- **`succinctly jq` runs an `as` body on each input as `inputs` reads it, so an error stops after one read, as in jq** (#7845). A collected binding whose source has an effect (`[inputs as $v | B]`, `{a: [input as $v | B]}`, a destructuring `inputs as [$a]`) read every remaining input before its body ran once, so an error the body raised on the first value named `<unknown>`, the main loop found nothing left to read and the run ended with exit 5. #7474's binding of a builtin's generator argument made the same happen to `[.[] | join(inputs)]`, `has(inputs)`, `contains`, `inside`, `split`, `splits`, `sub`, `startswith`, `endswith`, `index`, `indices`, `rindex`, `getpath`, `flatten` and `scan` with `inputs` as their argument. Such a source now runs depth-first, as an indexed `inputs[...]` already did (#7572); a source without an effect is collected as before.
