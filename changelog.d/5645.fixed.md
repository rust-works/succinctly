- **jq: a number or literal where an object key belongs is met at the token after it, as jq does** (#5645). `printf '{1.5e3\n1"k":false' | jq -nc '[limit(6; repeat(try input catch "E"))]'` is six `"E"`s in jq, because its lexer takes `1.5e3` without complaint and meets the fault at the `"` on the next line, so the whole second line is discarded. This build resumed at the line after the number and read `1` and `"k"` as documents (`["E",1,"k","E","E","E"]`). The same holds for `true`, `false`, `null` and numbers after a comma, across any run of whitespace, and under `--stream`. A container in the same place (`{[1]`) still resumes where it did.
