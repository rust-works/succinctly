- **jq: `strftime` and `strflocaltime` word a non-string format as jq 1.8.2 does** (#7533). `0 | strftime([])` raised `expected string, got strftime format`; it now raises `strftime/1 requires a string format` (`strflocaltime/1 requires a string format` for the local-zone one), as jq 1.8.2 does (upstream commit 1411ce6), whose fix replaced jq 1.7.1's assertion abort. The array-input case already read that way. The difference from the pinned 1.7.1, which aborts, stays recorded in `docs/compliance/jq/limitations.md`.
