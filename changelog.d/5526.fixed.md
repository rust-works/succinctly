- **jq: a value the program built past 384 levels no longer crashes with a Rust panic** (#5526). `last(f)`, `+=`, `//=`, a fold's `$x` and `try error(<deep>)` on a 400-deep value exited 101 with `panicked at ... nesting depth exceeds limit of 384`; they now report `jq: error: nesting depth exceeds limit of 384` and exit 5, the refusal `reduce range(385) as $i (0; [.])` already gave, with no panic line, on both the `-n` and the document routes. A refusal on one input document leaves the next one running, and `try`/`catch` cannot absorb it. The library's `jq::eval` returns the same refusal as a resource-limit error instead of unwinding. Whether 384 stays a ceiling at all is #5497.
