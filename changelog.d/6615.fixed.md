- **`succinctly jq` reports a directory given last when a read reaches it, as jq does** (#6615). A
  last value that completes only at the end of its file (`1` with no newline, or a `-R` line with
  none) reads on into the directory, so the program's next read now prints `jq: error: Is a
  directory` (`jq input p.json dir`, `jq -n '[inputs]' p.json dir`), and so does a read after
  the one that found the stream at its end. A `-n` program that stops before either never
  reaches the directory and now exits 0, where it exited 2 (`jq -n input one.json dir`).
