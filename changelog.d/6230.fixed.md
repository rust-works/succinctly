- **yq: `-P` writes a mapping key that holds a line break as a literal block, as yq does** (#6230). `printf "? 'k\n\nz'\n: 1\n" | yq -P .` prints `? |-` with `k` and `z` indented under it and the `:` on a line of its own; `succinctly yq -P` printed `? "k\nz"`. The same holds for a double-quoted source key, a plain multi-line one and a key over 128 bytes with a break. A quoted key `-P` strips is a known string with no style left, which the explicit-key branch now takes as it does a plain one.
