- **jq: a fold step whose operand is an `if` over the loop variable is 2.1-370x faster** (#6574).
  A `reduce`, `foreach`, `until` or `while` step such as `. + (if $i % 2 == 0 then 1 else 0 end)`, or
  `.n += (if ... end)`, now answers from the branch the condition picks. Before, the whole step ran on the
  evaluator's general route every round, and where it built a string, array or object each round that route
  copied the accumulator: quadratic. On an AMD Ryzen 9 7950X (jq 1.7.1 in brackets), 4,000,000 numeric steps
  take 1,720 ms instead of 4,102 ms (1,463 ms); 400,000 steps that append a string take 177 ms instead of
  65,529 ms (158 ms), an array 187 ms instead of 2,933 ms (151 ms), and an object 202 ms instead of 4,257 ms
  (173 ms). Apple silicon was not measured.
