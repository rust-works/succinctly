- **jq: a fault a later chunk meets at the very end of the input is placed as jq places it** (#6455).
  Where the stream's last file ran past its first 64 KiB and ended in a number straight before an
  opener (`... 5[`), `input`/`inputs` reported `(at file:N)` for the `Unfinished JSON term at EOF`
  error; jq 1.7.1 reports `(at <unknown>)`, since that number completes in the read that reaches the
  end (#6004). The lazy route's handoff to the eager reader now knows the file ends the stream.
