- **jq: an uncaught `error("a\u0000b")` stops its stderr message at the NUL** (#7442). The message was written whole, NUL byte included (`jq: error (at <unknown>): a\0b`), where jq 1.7.1 and 1.8.2 print `jq: error (at <unknown>): a`, the text after the NUL never written and the line still ended. The error value is unchanged (`try error("a\u0000b") catch length` is 3), and a non-string value is still dumped as JSON with the NUL escaped.
