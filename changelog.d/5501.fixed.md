- **jq: a constant non-string object key is a compile error** (#5501). `{(0):1}` printed `jq: error (at <unknown>): Cannot use number (0) as object key` and exited 5 after the program had started; jq 1.7.1 refuses it while compiling (`jq: error: Cannot use number (0) as object key at <top-level>, line 1:` ... `jq: 1 compile error`) and exits 3, so a skipped branch, a `?` or a `try` does not spare the program. A key is constant when jq's `constant_fold` can reduce it: a literal, an operator over constants (`1+1`, `1>0`), an all-constant array or object, or a pipe of one constant and `.` (`1|.`); `(-1)`, `(1,2)`, `(.a)` and `(1|2)` stay run-time errors, as in jq. The pipe rule also reaches a destructuring pattern key, where `. as {(1|.):$x}` ran and now exits 3. 42 programs, stdout, stderr and exit status, match jq; `succinctly yq` keeps yq's stringified key (`{(1): 2}` is `{"1":2}`).
