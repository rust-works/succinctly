- **yaml: a `key: value` line indented between a sequence item and its compact mapping is rejected as yq rejects it** (#6385). `- k: a` / ` b: 1` read as `[{"k":"a","b":1}]`, `-   a: hello` / `  b: 2` as `[{"a":"hello","b":2}]`, `- k:` / ` x` as `[{"k":null}]` (the `x` gone) and `- ? a` / ` b: 1` as `[{"a":null,"b":1}]`, where yq stops with `did not find expected '-' indicator`. This was the #885 tolerance, which read such a line as another entry of the mapping so that it was not dropped; #5086 removed its `-` counterparts (#325/#485/#900) for the same reason, and an error loses nothing silently. A line on a sequence item's own virtual indent after the item's mapping closed is refused whichever line it is. Checked against 11,718 YAML files on disk (none changed) and 9,000 randomized dash/key/`?` documents against yq v4.53.3: 540 more documents match yq, and one that matched stopped matching (a `?` / `- ? a` / `  x` stray line that the `?`-column work of #6370 already accepted, see #6377). The remaining random differences against yq fell from 25-40 per 1,500 documents to 0-1.
