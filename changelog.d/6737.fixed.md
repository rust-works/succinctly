- **yq: the cursor streamers quote a plain scalar that starts like a document marker, a lone `-` in flow context, and write a folded multi-line one as a block** (#6737).
  A source plain scalar was written back as spelled, which yq's emitter does not do when it cannot stay plain. `a: ---`, `b: ...`, `x: --- y` and `z: ...x` print as `a: '---'`, `b: '...'`, `x: '--- y'` and `z: '...x'` now (single quotes, in a mapping, a sequence and flow collections), a lone `-` inside `[...]` or `{...}` as `'-'` (it was `"-"`), and a plain scalar the source folded across blank lines (`a:\n  x\n\n  y`) as a literal block, `a: |-\n  x\n  y`, where it was one double-quoted line with `\n` (`a: "x\ny"`). All of it agrees with yq v4.53.3 on a 44-row matrix of contexts and spellings and on about 5,000 random plain scalars in seven contexts (no row that matched before differs now, 700 that differed match). A document with a trailing comment keeps the quoted spelling for a multi-line plain scalar, because the streamers write that comment after the value, which a literal block would read as text (yq puts it on the block's header, `|- # c`).
