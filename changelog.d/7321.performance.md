- **jq: macOS startup is 3.3% faster** (#7321). A 12.0 deployment target makes the linker emit chained fixups, which
  replace 22,214 rebase opcodes into 103 `__DATA_CONST` pages (a copy-on-write fault each, at every start). `jq -n 1`
  on an Apple M4 Pro, interleaved with an A/A control, 40 rounds of 100 spawns per build: 2.0434 ms to 1.9753 ms for
  the stripped binary (2.0546 ms to 1.9851 ms unstripped, -3.4%); the control pair, one binary at two paths, differed
  by 0.4%. The same builds' `/usr/bin/jq` 1.7.1 reads 1.8299 ms in this driver, so jq is still about 8% faster at
  startup on this chip; the remaining gap is clap and the loader's work on the image (not addressed here).
