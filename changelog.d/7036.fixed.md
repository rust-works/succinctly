- **yq: `--split-exp` names a file by the result, not by its encoding, under `-o=props|shell|csv|tsv|lua|xml|toml|ini|base64|uri`** (#7036). The encoder wrapped the program, so the name expression read the encoded text: `printf 'a: 1\n---\na: 2\n' | yq -o=props -s '"n" + (.a|tostring)' .` wrote `n.yml` twice (`.a` of a string is `null`), where yq writes `n1.properties` and `n2.properties`. The program now runs unwrapped and each result is encoded as it is written, after its name is known, so the name reads the node, `$index` is unchanged, and the files hold the same text as before. A result the encoder refuses (`-o=csv` over a mapping) leaves an empty file and ends the run with exit 1, as yq does; the second document used to be written as well. Pinned by 18 rows captured from yq v4.53.3 with their file names, contents and exit codes. yq starts the second and later `-o=yaml` and `-o=kyaml` files with `---`, which this does not (recorded in the limitations page).
