- **yq: the `alias =` setter** (#5483). `.b alias = "x"` (and `|=`, several targets) makes the node a `*x` alias, and `succinctly yq` answered `parse error: unexpected character 'a'`. It writes `*x` only where an earlier `&x` holds an identical value, and otherwise prints the node's value, where yq prints a `*x` it cannot read back (`.b alias = "z"` with no `&z` is `b: *z` in yq, `b: 1` here); an empty text writes nothing, a name with whitespace, `,`, `:`, a bracket, a brace or a non-ASCII character is refused as yq refuses it, and jq mode is unchanged. 4 rows captured from yq v4.53.3 match byte for byte; the divergences are listed in the yq limitations page. `explode(f)` for a path other than `.` is still a parse error.
