- **yq: a string repeated by a negative or fractional count raises** (#4269). `"s" * -1` was `null`, and `"s" * 1.5` and `"s" * 0.5` truncated (`"s"`, `""`), where yq raises (`cannot repeat string by a negative number`, `cannot multiply !!str with !!float`). A non-negative integer count is unchanged, and so is jq mode (`null` for a negative count, truncation for a fractional one). An integral float count (`2.0`) still repeats: yq accepts a JSON-sourced one and rejects a YAML-sourced or literal one, and the two cannot be told apart.
