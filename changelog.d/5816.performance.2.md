- **jq: `ltrimstr`, `rtrimstr`, `tostring` and `. + "lit"` of a string input are answered from the string, alone and at the head of a pipe** (#5816). `-Rs 'ltrimstr("x")|length'` over an 18 MB file is 86% faster on an Apple M5 Max (55.6 ms to 7.9 ms; jq 1.7.1 is 60 ms), `tostring|length` 86%, `. + "x"|length` 84%, `ltrimstr("{")|startswith("\"")` 87% and `-n --rawfile s F '$s|ltrimstr("x")|length'` 89% faster; `-R 'ltrimstr("{")|length'` per line over 200k lines is 24% faster. A pattern that is not a string literal, a non-string input and every other operator keep the evaluator's route, and a string stage in path position (`path(ltrimstr("x"))`) is unchanged. Closes the #5816 table: every row now runs at or below the cost of `length`.
