- **jq: `-n` with no input files reads a terminal on standard input when `input`/`inputs` asks** (#7742).
  The read was left out on purpose (#723), so `input` raised `break` and `[inputs]` printed `[]` before anything was typed, where jq 1.7.1 reads the terminal.
  A terminal is now read by the lazy route a line at a time and only once the program asks for its first input, so `-n input` answers the first line as it is typed (named as `-` or by its path too), and a program that never gets to `input` never waits for it.
