- **yaml: a run of nested explicit keys (`? ? ? ? a`) is a clean error past 128 levels, not a stack overflow** (#6956). Each `?` whose key is another explicit key is a call of the parser, and no depth limit counted it: 160,000 indicators (320 KB) took 17 seconds, 640,000 did not finish in two minutes, and about 1.5 million (3 MB) aborted the process with a stack overflow, for output of a few bytes. The recursion is charged like a flow collection now, so past 128 levels the run stops with `nesting depth exceeds limit of 128` and exit status 1, in a few milliseconds whatever its length. `- ? ` and `? ? - ` runs are covered the same way. yq reads up to 10,000 levels, so a document with 129 to 10,000 nested explicit keys is read by yq and refused here (recorded in `docs/compliance/yq/limitations.md`; no real document has them). Found by a scaling fuzz that repeats one unit in many parser contexts.
