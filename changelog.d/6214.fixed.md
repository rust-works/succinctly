- **yq: a tab after a U+2028, U+2029 or U+0085 break in a flow plain scalar is refused as after `\n`** (#6214). `a: [x⏎⇥y]` with the break U+2028 printed `{"a":["x y"]}`, where yq stops with `found a tab character that violates indentation`: the scalar decoder folds those breaks like `\n`, but the scanners read them as text, so the tab went unseen (#6059). It holds in a flow sequence or mapping under a block, in an explicit `? key`, and in a sequence item; a collection at the document root, a tab after spaces and a quoted scalar are still legal. The block-context twin (`a: x⏎⇥y`) and a flow collection under an empty key (`: [x⏎⇥y]`) still differ; #6214 stays open for them.
