- **jq: `[(.users, [1]) | .[0]]`, `[(.users, length) | .]`, `[(.users, .users)?]` and `[.users[] | (., 1) | .]` keep the nodes they hold instead of decoding them** (#4294). The `,`-head route took only a pipe of pure navigation, only the `,`-stage route recognised a `?` group, and neither ran a tail after a computed branch, so these shapes ran the owned route and decoded every node the array holds. Now:
  - A `?` around navigation branches is a guarded group as the whole body or at the head too.
  - A computed branch may be followed by further stages when no stage before the pipe's last has an effect or reads the input state (#4293's predicate) and none reads path context.

  On a 14 MB `users` document, release, Apple M4 Pro mini, interleaved A/B, 15 reps, identical output (min wall):

  | query | before | after | change | peak RSS |
  |---|---|---|---|---|
  | `[(.users, [1]) \| .[0]] \| length` | 176.6 ms | 25.0 ms | `-86%` | 158 MB -> 26 MB |
  | `[(.users, length) \| .] \| length` | 175.7 ms | 22.5 ms | `-87%` | |
  | `[(.users, .users)?] \| length` | 270.0 ms | 22.7 ms | `-92%` | 258 MB -> 26 MB |
  | `[.users[] \| (., 1) \| .] \| length` | 255.1 ms | 51.4 ms | `-80%` | 182 MB -> 46 MB |

  The #4166/#3922 holdouts read within `-1.9%..+0.2%` (median). jq mode only.
