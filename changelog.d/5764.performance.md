- **jq: a slurped `--stream` array is evaluated where it is only for a program the owned evaluator answers** (#5764).
  #5744 handed the array to the owned evaluator for every program, and a program none of its doors answers
  crossed the reindex bridge, which spells the array as reindex text, registers it for storage sharing and runs
  `eval.rs`'s evaluator over the index, where the old route read the same text with the lazier `eval_generic`
  one. Such a program now reads the array's own index, as before #5744. On an Apple M-series (interleaved, min of
  15, output identical, a control copy of the old binary at +0.5% and -2.2%) over a 21 MB `users` file,
  `--stream -c -s`, against the old route: `[limit(5;.[])]` 1.14x -> 0.99x, `[.[]|select(length==2)]|length`
  1.08x -> 0.99x, `map(select(.[1]!=null))|length` 1.01x -> 1.00x. The answered programs keep #5744's win
  (`length` 0.72x, `.[1000]` 0.72x of the old time). The price is the wins #5744 had on programs that bridge:
  `map(length)|add` 0.84x -> 1.00x and `map(.[0][0])|unique` 0.85x -> 0.96x of the old time. x86_64 not measured.
