- **jq: a `reduce`/`foreach` that stores a value read through a container named argument no longer rebuilds the whole value on every step** (#5803). `-n --slurpfile d users.json 'reduce range(200) as $i ({}; .[$i|tostring] = $d[0].users[$i].age)'` is 99% faster on an Apple M5 Max at 1 MB (880 ms to 11 ms), and a store of a record from a 4000-record lookup table (`.[$i|tostring] = $d[0][$i]`, 4000 steps) goes from 11.7 s to 12 ms. A read on the value side of `=`, `|=`, `op=` and `//=` is shared as #5774 does for a read; the target of a store, and anything before it, keeps the literal, as before. A container read through the shared value is stored in the accumulator as one handle, as jq's `reduce` stores the `jv`, so `reduce range(2000) as $i ([]; . + [$d[0][$i]])` is 97% faster (285 ms to 9 ms) and no longer quadratic over the accumulator.
