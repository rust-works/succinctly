- **yq: a slice of an unquoted timestamp, a `!!binary`, an explicit non-`!!str` core tag or an alias is an empty sequence** (#4569).
  yq cuts only a plain string as text; `a: 2024-01-01` with `.a[0:2]` is `[]` there and was `"20"` here, and
  `.a[0:2] | length` is `0`, not `2`. A literal and a computed bound (`.a[1+0:]`) answer alike, and a quoted date, `!!str` and a
  custom-tagged scalar still cut their text. A write (`|= .[0:2]`) and the `del(.a[0:2].x)` error still treat the scalar as a string.
