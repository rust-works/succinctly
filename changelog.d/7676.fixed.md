- **jq: a first use of a prelude definition at the native-stack floor refuses instead of panicking** (#7676).
  Since #7475 the parser refuses at the native-stack floor (ADR-0025), and two parses of the crate's own text can
  happen there: the path-mode interpreter parses a prelude definition (`to_entries`, `map`, `select`, `paths`,
  `walk`, ...) on its first use, and a program's `_nwise` call parses jq's template inside the program's own parse.
  Either one, reached within a few KiB of the floor, panicked (`prelude: ParseError { message: "memory exhausted"`,
  or `jq's _nwise template parses`) where the run should have been refused. Both texts are now parsed with the
  floor lifted, and a unit test pins that each parses at the floor within a stated stack bound, so the call is
  refused as every other at the floor (`exceeded maximum recursion depth`), or the program as a binding chain too
  long for the floor (`memory exhausted`).
