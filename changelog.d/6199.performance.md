- **jq: `path |= f` of a static path that reaches most of the document runs `f` on the document, not on a copy of all of it** (#6199).
  The update used to copy every node of the document into one owned value before it ran; now the containers on the
  path are rebuilt around the target, `f` runs on the target in the document, and its first output goes in. It is tried for
  a filter that starts by reducing the target (`map(..)`, `length`, `add`, `first`, `last`, `limit`, an index or a slice)
  on a target that is at least half of a document of 32 nodes or more; the answers are unchanged, and a filter that
  answers nothing, raises or breaks, a document that is malformed anywhere, a repeated key on the path and a path that does not
  land on a container all take the route they took before. Numbers are added when measured.
