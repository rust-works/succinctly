- **`succinctly dev compare jq` no longer exits 1 on Linux aarch64 over the `--seq` sweep** (#7256). jq 1.7.1's `check_literal` compares `tokenbuf[1]` with `u` for a bare `n` before any earlier token has written it, which reads uninitialised heap that differs between libc allocators; no implementation can match it. `scripts/jq-seq-oracle-sweep.py` now skips those streams (counted under `artifact-shapes-skipped`), and the `token_buf` comments and the limitations page no longer call the case deterministic.
