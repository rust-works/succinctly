- **`succinctly dev compare jq` no longer exits 1 on Linux aarch64 over the `--seq` sweep** (#7256). jq 1.7.1's `check_literal` compares `tokenbuf[1]` with `u` for a bare `n` before any earlier token has written it, which reads uninitialised heap that differs between libc allocators; no implementation can match it. `scripts/jq-seq-oracle-sweep.py` now skips those streams (counted under `artifact-shapes-skipped`), and the `token_buf` comments and the limitations page no longer call the case deterministic. On a Graviton4 (Amazon Linux 2023, source-built jq 1.7.1) the sweep now agrees on seeds 1, 2 and 7 and in `--slurp-location` mode, skipping 72, 69, 73 and 72 streams, the same counts as on macOS arm64 and Linux x86_64; `dev compare jq` runs all four, as `seq`, `seq-seed-2`, `seq-seed-7` and `seq-slurp-location` (#7258).
