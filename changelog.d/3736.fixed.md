- **jq: `walk(f)` over an array observes its trailing `f` inline in path position, so an effectful body is no longer refused and an empty-result walk no longer does a second pass** (#3736).
  jq runs `walk`'s trailing `f` on every array it rebuilds, and that array is never the path register, so `f` raises there iff it navigates. #3713 decided that by running `f` a second
  time against each rebuilt array after the by-value walk had produced nothing, which it could not do for a body with an effect (`debug`, `debug(msg)`, `stderr`, `input`, `inputs`,
  `halt`, `halt_error`, a call it cannot see into): such a body was refused wherever it *can* navigate, so `echo '[null]' | jq 'path(walk(debug | select(type == "object") | .a))'`
  exited 5 where jq answers. The by-value leaf now resolves `f` once on each rebuilt array in path position, in place of the by-value run, so `f` fires once per node, in the
  same order as in jq (but see the root level below), the false refusal and the second walk are gone, and the register bookkeeping of the leaf is unchanged. The same observation also raises where a navigating `f`
  *yields* on the rebuilt array (`path(walk(.[0]) | empty)` over `[null]` exits 5, as in jq, where the later `| empty` or `try` used to hide it) and where a `[walk(f)]` collect's
  refusal was swallowed by a later `try`. Over 84 bodies x 24 contexts x 14 inputs (28,224 rows, effectful bodies included) against jq 1.7.1: accepted-wrongly 464 -> 0,
  effect-count mismatches 838 -> 0, refused-wrongly 2,110 -> 7 (all `.[0] | walk(ltrimstr("a"))`, unchanged by this change).
  The empty-result walk now costs one pass: `path(walk(empty))` over a 500,000-element array 0.658 s -> 0.386 s (-41%), over 150,000 three-level records 1.333 s -> 0.718 s (-46%)
  (Apple M5 Max, release build, interleaved min of 9, identical output; a `length` control is within 3%).
  One difference remains: the root level's trailing `f` is collected before any output is delivered, so under `first(...)` an effectful `f` with several outputs runs to completion
  where jq stops (`first(path(walk(debug, debug)))` over `[null,[null]]`: 8 `DEBUG` lines, jq 7, before this change 9).
