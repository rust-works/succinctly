- **yq: a comma-grouped `del()` or write whose branch steps into a string, number or boolean no longer raises and loses its siblings** (#3039). `del(.c, .a[0])` on `{"a":"ab","c":1}` raised `Cannot index string with number`, so the `.c` deletion was lost too; yq answers `{"a":"ab"}`. yq's `traverse` yields no candidate for a field or index step into a scalar, so the static-tail navigator now prunes that branch in yq mode. `(.a.b, .x.y) = 99` on `a: 5, x: {}` now writes `.x.y` (#1419), and a failing RHS reports `boom` as yq does. `null` still autovivifies, a container of the wrong kind still raises, and jq mode still raises as jq 1.7.1 does. An iterate step into a scalar (`del(.c, .a[])`) is unchanged (#2376).
