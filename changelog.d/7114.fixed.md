- **yq: a block scalar with an explicit indentation indicator in a compact nested sequence is read as yq reads it** (#7114).
  `- - |2-` (the first element of a sequence that is itself a sequence item, on the same line) measured the scalar's content against the outer dash, so the next sibling's line (`- x`) became part of its text, the item `x` appeared twice, and the block was written two columns too far right.
  The content is now measured against the innermost dash, for a chain of any depth, with any spacing after the dashes, for `|` and `>` and with a chomping indicator (every input is checked against yq v4.53.3 in both JSON and YAML output).
