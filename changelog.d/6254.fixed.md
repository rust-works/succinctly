- **jq: `\k<name>` for a name several groups share tries each of them, as Oniguruma does** (#6254).
  `"aba" | test("(?<n>a)(?<n>b)\\k<n>")` was `false`: the reference read the last group of that name only. It compares the last group that is set, then the one before it, and so on, and does not give the match back once one fits.
  A reference to a name defined twice or more is now the atomic alternation of the numbered groups before it, so it composes with the case pin of #6196, and a name defined again after its reference no longer makes the crate refuse the pattern.
