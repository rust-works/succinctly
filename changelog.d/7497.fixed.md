- **jq: a postfix after a negated number literal negates the postfixed term** (#7497). `-1[0]`, `-1.5[0]`, `-1[]?`, `-1.[]?` and `-1 [0]` were refused as `unexpected character '['` (exit 3); they now parse as jq's `-(1[0])`: `-1[0]` is a run-time `Cannot index number with number` (exit 5) and `-1[]?` prints nothing. The same holds for an object value (`{a: -1[0]?}`). The `-` is no longer folded into the literal when a `[` follows it, as it already was not for a `.`, `?`, `as` or a multiplicative operator.
