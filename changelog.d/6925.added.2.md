- **`succinctly yq -p props`** (#6925). Reads a Java properties file as yq v4.53.3 does: a port of magiconair/properties v1.8.10 (its escapes, line continuations, comments, `${key}` check and `properties: Line N:` errors) and of the traversal yq's decoder assigns through, so each key is a path (an `int32` segment an index, a segment a key glob, `--properties-array-brackets` read too), each value a string, and each comment a head comment. Under `-p auto` a first file named `*.properties`, `*.props` or `*.p` picks the format and prints in it. It agrees with yq on 120 crafted files under four output modes, apart from the rows recorded in `docs/compliance/yq/limitations.md`.
