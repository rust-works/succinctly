- **jq: an array index write far past the end is refused** (#5500). `succinctly jq -n '[] | .[1e12] = 1'` spent over 10 s allocating 1e12 elements and has been seen to abort the process (jq 1.7.1 dies with SIGSEGV there too). A write that would grow an array past 536,870,912 elements (jq 1.8's `INT_MAX >> 2` bound) now fails with `Cannot grow array to <n> elements`, which `try` catches; every index jq 1.7.1 answers up to that bound still pads.
