- **yq: a write or `del()` through a metadata `select` and a fresh container no longer writes the document** (#8037).
  `(.b | select(kind == "map") | {"a": 1} | .a) = 9` set the top-level `a`, `del(.arr | select(kind == "seq") | [.[]] | .[0])` deleted `arr[0]` and `del(.b | select(kind == "map") | with_entries(.) | .c)` deleted the top-level `c`, where yq v4.53.3 changes nothing: the document route resolved such a target on the cursor to the `path` of the fresh node, which names a document node it is no part of. Only a target that navigates and filters is resolved there now; these shapes refuse with `Invalid path expression` instead, as they do on the owned route.
