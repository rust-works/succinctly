- **jq: a document holding one object that repeats a key is printed from its text around that object** (#7366). The canonical scan stopped at such an object unless it was the whole value, so `{"data": <1 M keys, the second repeating the first>}` (17.9 MB) and an array of 400,000 records one of which repeats a key walked and re-rendered every member. The scan now records the first such object below the value and goes on past it, and the printer writes the text before it, the object by its keys, and the text after it. On a 7950X, `-c .` over the 17.9 MB object takes 133.7 ms against 164.7 ms (0.81x; with the repeat at the last key 0.75x), and over the records 60.5 ms against 251.6 ms (0.24x); `.` reads 0.81x, 0.76x and 0.38x. Output and peak memory are unchanged, documents without a nested repeat are within noise, and a document with two such objects still walks.
