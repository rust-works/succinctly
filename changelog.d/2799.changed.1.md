- **yq: `unique`, `unique_by` and `group_by` key on text in first-occurrence order, as real yq does** (#2799, part 2). yq's `unique` family is an ordered map on a text key, not a sort followed by a dedup, so `[3,1,2,1] | unique` is `[3,1,2]` (was `[1,2,3]`), `[1, "1"] | unique` is `[1]` (was `[1,"1"]`), `[3,1,2,1] | group_by(.)` is `[[3],[1,1],[2]]`, and `[[1],[2]] | group_by(.)` is one group (every container shares the empty key). `unique_by(.a, .b)` and `group_by(.a, .b)` read the key filter's first output only, as yq does. A container's `unique` key is compact JSON here where yq's is the node's YAML (same equivalence classes, style-insensitive). jq mode is unchanged; `sort` and `contains` are the issue's remaining slice.
