- **`succinctly jq` treats a bare number or literal before a stream's last opener as a value, as jq does** (#6004). When the input ends in a number, `true`, `false` or `null` straight before one last `[` or `{` (`1[`, `true{`), jq's parser has completed that token when it meets the end of input. `printf '1[' | jq -cs .` now prints `[1]` before the parse error, as jq does (it printed nothing), and an `input`/`inputs` read that meets the fault names `(at <unknown>)` instead of the file. Only that exact shape: `1 [`, `"a"[` and `[1][` are unchanged.
