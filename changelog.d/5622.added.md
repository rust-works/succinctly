- **`json generate -p ndjson` and `-p json-seq`** (#5622). `succinctly json generate` writes newline-delimited JSON, one compact user record per line with no enclosing array (`ndjson`), or the same records each behind an RS byte, the input `jq --seq` reads (`json-seq`). `--verify` checks every line, and `--pretty` is refused since there is no single document to indent. Neither pattern is part of `generate-suite`. `succinctly dev compare jq` uses them to time the many-small-documents, `--seq`, several-input-file and `--slurpfile`/`--rawfile` paths that `perf.tsv` did not reach.
