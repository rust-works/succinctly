- **`succinctly jq` reads `--indent` as C's `atoi` does, and accepts `-L ""`** (#6017). `--indent -1` is a tab, `--indent " 2"` and `--indent 3x` are 2 and 3, and a value that does not start with a digit (`""`, `abc`) is 0, where each was a usage error (exit 2). Values outside -1 to 7 are still refused. `-L ""` is an empty search-path element, as in jq 1.7.1, not a missing value. Checked against `/usr/bin/jq` on 30 values and 17 option combinations.
