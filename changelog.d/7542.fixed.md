- **jq: `strftime("")` and `strflocaltime("")` return the empty string** (#7542). They raised `strftime/1: unknown system failure` (`strflocaltime/1: ...`), as jq 1.7.1 does; now `0 | strftime("")` is `""`, and so is a format that is empty once a NUL ends it (`strftime("\u0000x")`), as in jq 1.8.2, which fixed this with its `strftime` crash fix (jqlang/jq#3271). A non-empty format whose result is empty, or one past the `strlen(fmt) + 100` byte buffer, still raises. The difference from the pinned 1.7.1 is recorded in `docs/compliance/jq/limitations.md`.
