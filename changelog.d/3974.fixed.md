- **A `select(f)` comma sibling in a `foreach` UPDATE `try` no longer drops the write** (#3974). `del(foreach .x as $w (.; try (($w|.c), select(.a)); .))` and the matching `path(...)` read the pipe sibling's `$w` as a refusal that the `try` swallowed, so the write or path vanished with exit 0 where jq raises `Invalid path expression`; `select` now leaves the fold's register where the comma entered it, as a plain navigation sibling does (#3932).
