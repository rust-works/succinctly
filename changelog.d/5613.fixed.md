- **jq: a program is split into tokens on space, tab and newline only** (#5613). jq 1.7.1's lexer
  skips `[ \n\t]+` and `#` comments; CR, form feed, vertical tab, NBSP and U+2028 are
  `INVALID_CHARACTER` (exit 3), so a program saved with CRLF line endings is refused at its first
  `\r`. `succinctly jq` skipped everything `char::is_whitespace` accepts, and read a `-f` program file
  through `trim()`, so `1\r+ 1` printed `2` and a `-f` file ending in `\r\n` ran. A CR inside a
  comment is still part of the comment. `succinctly yq` is narrowed the same way (#5616).
