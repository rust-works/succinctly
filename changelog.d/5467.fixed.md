- **yq: `.` single-quotes a plain scalar that holds a `:` or `?` inside a flow collection, as yq does** (#5467). `a: [http://x.y/z, b]` printed back verbatim; yq prints `a: ['http://x.y/z', b]`, because go-yaml's emitter will not write such a scalar plain in flow context. The same goes for a flow-mapping value or key (`{k: 'x:y', 'p?q': 1}`), a nested flow collection, a root flow sequence, a multi-line one, a timestamp, and a scalar with an anchor or tag (`[&n 'x:y']`, `[!!str 'x:y']`). `-P` and every write already did this, so the same document printed differently depending on the route; found by the real-file sweep of #4099 in 34 of 2,831 YAML files on one machine. Cost on the path that gains nothing: a flow-heavy 9.7 MB document with no `:` or `?` reads +0.5% to +1.3% (Apple M-series, interleaved min/median of 15, output identical); one where every row holds such a scalar reads +16%, the new work. A timestamp inside a flow collection on the *write* route is still unquoted where yq quotes it (#5469).
