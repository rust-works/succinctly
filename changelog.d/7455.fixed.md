- **A run that stops early leaves a redirected standard input where jq does** (#7455). `-n input`, `first(inputs)`, `limit(n; inputs)`, `halt` and `halt_error` over a regular file on standard input used to leave its offset at the end of the file, or of the last 256 KiB window read, so `{ jq -n input; jq -n input; } < f` printed the first document and then failed (or began mid-line); the descriptor is now moved, when the run ends, to the end of the line (or of jq's 4095-byte read of a longer line) that completed the last value, `--stream` event or `-R` line the program read, as jq 1.7.1's stdio leaves it, so the second command reads the second document. A run that reads to the end, a pipe, a named file, `--seq`, `--stream-errors` and a run that ends at a parse error are unchanged.
