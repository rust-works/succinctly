- **Building with the `regex` feature (so `cli`, and `cargo install succinctly`) now compiles C** (#7965). The feature builds the copy of Oniguruma that jq 1.7.1 bundles, vendored in `vendor/oniguruma` at commit `d2f1a14ced`, through the `cc` crate. A host needs a C compiler, which Linux, macOS and Windows hosts already need to link. The stripped release binary grows by 2.8% on macOS arm64 (ADR-0031).
