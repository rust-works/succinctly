- **Building with the `regex` feature (so `cli`, and `cargo install succinctly`) now compiles C** (#7965). The feature builds the copy of Oniguruma that jq 1.7.1 bundles, vendored in `vendor/oniguruma` at commit `d2f1a14ced`, through the `cc` crate. A host needs a C compiler, which Linux, macOS and Windows hosts already need to link. jq mode keeps its current engine by default. With `SUCCINCTLY_REGEX_ONIG=1`, it compiles and matches with Oniguruma as jq 1.7.1's `f_match` does: on a corpus of 459,678 pattern, flags and subject rows, no answer differs from jq 1.7.1 outside the recorded adoption of jq 1.8.2's empty-match captures (#7520). The stripped release binary grows by 2.8% on macOS arm64 (ADR-0031).
