- **jq: a number literal directly followed by `else`, `elif` or `end` is read as the number and the keyword** (#7496). `if 1 then 2else 3 end` and `if 0 then 2 else 3end` were refused as `invalid number` (exit 3); they now run as in jq (`2`), and so do `.5end`, `3.end` and `1.5else`. The lexer took an `e` after a number for a malformed exponent; as jq's, it now reads an exponent only when digits follow (`[eE][+-]?[0-9]+`) and otherwise ends the number before the `e`, so `2e`, `1e1else` and `0x10` are still syntax errors.
