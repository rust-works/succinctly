- **yq: a space before the `:` of a sequence item's quoted or alias key parses** (#5469). `- "k" : 1`, `- 'j' : 2` and `- *a : 1` were a parse error (`expected ':' after key in compact mapping`) where yq reads `[{"k": 1}]`: the compact mapping's key parser left the space ahead of its colon check, which the block mapping's own parser skips. yq writes `- *a : 1` for an alias key opening a mapping in a sequence, so without this the alias keys above would have printed YAML succinctly could not read back. A plain key already took its trailing space.
