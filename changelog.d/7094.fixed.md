- **yq: a binding over several values in `with(PATH; SRC as $v | WRITES)` applies each value's writes** (#7094). `with(.k; .x[] as $v | .y += $v)` over `x: [1, 2]` wrote `y: 1`, the first value's write only; it now writes `y: 3` as yq does, `.y = $v` leaves the last value, a `select` in the body skips a value instead of ending the update, and chained bindings nest. A `|=` body that is such a binding (`.k |= (.x[] as $v | .y += $v)`) does the same. The values are the source's as the node stood before the first write, so a write to a node a later value is bound to is not seen by that value, where yq copies each node when its turn comes (`docs/compliance/yq/limitations.md`).
