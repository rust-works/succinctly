- **yq: a `\(` nested inside an open slot counts as an open paren, and a `)` after a backslash run does not always close** (#7105). `"\(z\(1)"` has two opens and one close in yq, so it is an unclosed interpolation and prints as written, where `succinctly yq` skipped the character after every backslash in that scan and refused it with a parse error. A `)` closes a slot unless the backslash run before it, collapsed once, is odd (`\)` and `\\)` do not, `\\\)` does).
