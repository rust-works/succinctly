- **jq: a missing input file no longer stops processing** (#5472).
  `jq -c .a missing.json data.json` reported the missing file and quit, so `data.json` was never read; jq reports it, reads on, and exits 2.
  Every file that will not open is reported, one `jq: error: Could not open file ...` line each, in the order the reader reaches it, and the exit status is 2 whatever else the run did.
  Past a missing file jq's main loop also ends after one more value, which `succinctly jq` reproduces for plain documents.
