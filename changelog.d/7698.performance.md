- **jq: `jq . /dev/stdin < big.json` reads a window at a time on Linux** (#7698).
  A lone regular file named by a path whose `stat` is the file standard input is open on (Linux's
  `/dev/stdin`, `/dev/fd/0` and `/proc/self/fd/0`, or the file's own name with the same file on standard
  input, on every platform) was read whole before the program ran, so the run held the whole file where
  `jq . < big.json` holds a window of it. The plain, `-R` and `--seq` routes now read such a path a window
  at a time wherever a new open of it does not share standard input's offset, as on Linux, where it opens
  the file again from its start. Output, errors, exit status and where standard input is left are
  unchanged, as jq 1.7.1 gives them; macOS's `/dev/stdin` and `/dev/fd/0` were already read a window at
  a time (#7446).
