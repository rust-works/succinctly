- **The published crate ships the library and the CLI only, and CI holds it under 8 MiB** (no issue). `tests/` and `benches/` left `include` in `Cargo.toml`, which took the `.crate` `cargo package` writes from 10,434,790 bytes, 51 KB under crates.io's 10 MiB upload limit, to 6,504,486 bytes (6.2 MiB); the `[[bench]]` targets are dropped from the packaged manifest, as the examples already were, and the tests run from a checkout. The `include` patterns are anchored at the root, so the `README.md` of every `docs/` directory no longer ships either. `scripts/crate_size.py check --verify` packages the crate, builds it from its own files with `--features cli` and fails over 8 MiB; it runs in a new `Crate package` CI job, in `release.yml` before the GitHub release is created (`cargo publish` runs last, so an over-limit crate used to leave a release half done), and in the pre-push `crate-size` gate.
