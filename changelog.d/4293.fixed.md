- **`succinctly jq` no longer runs an effect for an output jq never reaches** (#4293). A pipe ran each stage over every input before the next stage saw the first, so when a later stage raised on the first output, an earlier `debug`, `stderr` or `input` had already run for the rest: `[(1, ("x" | debug)) | .x]` wrote a `DEBUG` line, and `[.[] | (input, input) | error]` consumed an extra input, so the errors after it named the wrong line (`[(input, input) | error]` also reported a stray `break`). A pipe with an effect before its last stage now runs depth-first in jq mode, as jq does; `succinctly yq` keeps yq's left-side-first order.
