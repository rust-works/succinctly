- **jq: `INDEX(f)` and `transpose` raise `Invalid path expression` inside `path()` on an untracked value** (#3888). `path(([[1]] | INDEX(.)) | empty)`, `path(([[1,2],[3]] | transpose) | empty)` and the `del(...)`/`... = v` forms of them answered `[]` (or silently skipped the write) where jq 1.7.1 raises `near attempt to iterate through <input>`. `INDEX(f)` iterates its input first, so it raises for every input including scalars; `transpose` raises once some row has a length above zero (or every length is `NaN`), after its own `Cannot iterate over ...` / `... has no length` value errors, which still win. `INDEX(stream; f)` is unchanged.
