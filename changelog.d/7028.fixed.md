- **yq: `--split-exp` appends the output format's extension to a file name that has none, as yq does** (#7028). `printf 'a: 1\n---\na: 2\n' | yq -s '"x" + (.a|tostring)' .` writes `x1.yml` and `x2.yml` (`x1.json` under `-o=json`, `x1.properties` under `-o=props`, `.yml` for every other format, `xml`, `toml`, `lua` and `csv` included); `succinctly yq --split-exp` wrote `x1` and `x2`. A name that already ends in `.` and ASCII letters or digits is kept (`x1.txt`, `x1.1`, `x1.tar.gz`, `x1.YML`), and one that ends in `.`, `.a-b` or a non-ASCII letter is not (`x1..yml`, `x1.a-b.yml`), which is the regular expression yq tests, not a file-extension check. The extension follows the format the run resolves to, so JSON input read without `-o` writes `.json` files and stdin writes `.yml`. Pinned by 50 rows captured from yq v4.53.3.
