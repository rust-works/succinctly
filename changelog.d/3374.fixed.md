- **`succinctly yq` treats `*` and `?` in a mapping key as wildcards** (#3374). Pinned yq emits the value of every key a pattern matches, in document order: `.["x??"]` on `{"x??":3,"x?y":4,"xyz":5}` is `3`, `4`, `5` (it was `3`). `=`, `|=`, `+=` and `del()` follow every matching key, and a pattern that matches nothing reads `null` and writes the literal key. An unquoted `*` (`.a*`) and a computed string key are still not wildcards. `succinctly jq` keeps exact-key lookups.
