- **jq: a dash in a character class is read as Oniguruma reads it** (#6184). The `regex` crate takes `--` for set difference and a leading `]` for a literal that no range can start, so `"a-" | [match("[+--]";"g").offset]` and `[--{]` and `[]-b{]` came out as other sets, and the reversed `[?--]`, `[(?--)]` and `[]-(]`, errors in jq, were accepted. `[+--]` is now the range `+` to `-`, `[--{]` the range `-` to `{`, `[]-b{]` the range `]` to `b`, and the reversed ranges are errors. A range that starts or ends on a set (`[[:alpha:]-a]`, `[a-[:alpha:]]`) is an error too. Generated classes against jq 1.7.1 went from 40-65 differences per 8,000 to none.
