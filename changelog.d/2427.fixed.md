- **yq: `--eval-all` folds the whole document list, so `. as $item ireduce ({}; . * $item)` merges the files** (#2427). The recipe yq's documentation gives for merging several files folded each document on its own and printed one result per document; it now reads the source and the initial value over every document of every file, as yq does, and prints the merged mapping once. `. as $i ireduce (0; . + 1)` counts the documents, the loop variable's node reads (`$i | document_index`, `file_index`, `path`, `line`, `tag`) answer from the document each node came from, and an empty `{}` is one mapping under `--eval-all` (`yq ea '{}' f1 f2` printed one `{}` per document). An `ireduce` after a navigation, and the plain route, are unchanged; an absent key read through the loop variable, a multi-output UPDATE and `{}` after a fan-out outside `--eval-all` still differ from yq (limitations).
