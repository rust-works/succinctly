- **yq: `unique` keeps `~`, `null`, `Null` and an empty value apart, as yq does** (#6103). yq keys an element on its text, so `- ~` / `- null` / `- ~` / `- 1` / `- null` gives `~`, `null`, `1`; `succinctly yq` keyed a `null` by its decoded value and kept only the first (`~`, `1`). `unique` and `unique_by(.)` over a document's elements now key a `null` by the way the source spells it, and a container that holds one by the spellings of its nulls too (`[~]` and `[null]` are two elements). `unique_by(.a)`, `group_by`, an array the filter builds and an anchored or aliased element still read a decoded `null`; they are listed in `docs/compliance/yq/limitations.md`.
