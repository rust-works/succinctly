- **yq: `-C`/`--colors` streams its output instead of buffering all of it first** (#808).
  The colorizers now run over the cursor streamers' output as it is written, so colored output keeps the
  M2 fast path's memory and early output: `-C '.'` on a 100 MB document peaks at 278 MB instead of
  523 MB on an Apple M4 Pro and 259 MB instead of 414 MB on an AMD Ryzen 9 7950X (`-C -o=json '.'`:
  278 MB instead of 774 MB, and 259 MB instead of 665 MB), the same as uncolored output, and
  `-C '.' | head` sees its first output after 0.34 s instead of 1.43 s (M4 Pro; 0.49 s instead of 1.71 s
  on the 7950X). With `-0`, colored output is checked for NUL one result at a time, as uncolored output
  already was. The colors are unchanged except where a list item's "does it start with a key" lookahead
  used to read past its own line or result: with `.[]` over records that end in a list, the last item of
  each record (`- category_0` before the next record's `id: 1`) is no longer colored as a key, and
  neither is an item whose apostrophe (`- don't`) is closed by a quote on a later line.
