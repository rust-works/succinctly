- **yq: `-C`/`--colors` streams its output instead of buffering all of it first** (#808).
  The colorizers now run over the cursor streamers' output as it is written, so colored output keeps the
  M2 fast path's memory and early output: `-C '.'` on a 100 MB document peaks at 278 MB instead of
  523 MB (`-C -o=json '.'`: 278 MB instead of 774 MB), the same as uncolored output, and
  `-C '.' | head` sees its first output after 0.34 s instead of 1.43 s (Apple M4 Pro). With `-0`, colored
  output is checked for NUL one result at a time, as uncolored output already was. The colored bytes are
  unchanged.
