- **jq: a fold step that writes under an interpolated key no longer serialises its accumulator** (#5733).
  `reduce range(0;N) as $i ({}; .["k\($i)"] = $s)` evaluated its key through the re-index bridge, which
  rendered the whole accumulator as JSON and indexed it again to answer a key that never reads it, so the
  loop was quadratic in N when `$s` was long: 44 s at N=2000 with a 5000-byte value on an AMD Ryzen 9 7950X
  (jq 1.7.1: 0.00 s). A key whose `\(...)` slots are all closed is now answered from the slots, as a
  `"k" + ($i|tostring)` key already was; N=500 to 8000 takes 0.02 s on an Apple M-series.
