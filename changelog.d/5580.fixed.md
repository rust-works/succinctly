- **jq: `l` on an alternation of multi-byte branches now gives the longest one** (#5580). `"éé" | match("é|éé"; "l")` answered `é` (length 1) where jq answers `éé` (length 2), and `"aééé" | match("aé|aéé"; "l")` stopped at `aé`. `fancy-regex`'s longest-match mode stops searching once a match is as long as the pattern's `max_size`, which it counts in characters and compares with a length in bytes, so any variable-length pattern whose shorter match is that many bytes lost its longer one, in a group or with `.` as well. A pattern whose matches differ in length now carries a branch that never matches and has no length bound, so the stop never fires; a fixed-length pattern is unchanged.
