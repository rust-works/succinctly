- **`YamlError` loses `MultiDocumentNotSupported` and `FlowStyleNotSupported`, and becomes `#[non_exhaustive]`** (#5954).
  Both variants have been `#[deprecated]` and never constructed since 0.3.0 (multi-document streams and flow style are parsed),
  so no release has returned them. A downstream `match` that names either must drop the arm, and one without a wildcard arm
  needs one, since the enum is now `#[non_exhaustive]`: a later removal is then not a break. `TagNotSupported` was returned by
  0.7.0 and earlier, so it stays for one more release: it now says `since = "0.8.0"` and that it is removed in 0.9.0.
