- **jq: a `def` named like an operator jq compiles into a call replaces the operator, as in jq** (#7739). jq's parser turns `+`, `-`, `*`, `/`, `%` and the comparisons into calls to `_plus` ... `_greatereq` (unless both operands are constants), unary minus into `_negate`, `@name` and string interpolation into `format`, `..` into `recurse`, `|=` and the update-assignments into `_modify` and `=` into `_assign`, so a definition of that name and arity in scope takes the operator's place: `def _plus(a;b): "P"; 1 | . + 2` is `"P"`, `def format(f): "<" + f + ">"; "id=\(1)"` is `"id=<text>"` and `def recurse: "R"; [..]` is `["R"]`, where succinctly ran the operator. Only a program that defines one of these names parses differently; `label`'s comparison through `_equal` is recorded rather than followed.
