- **jq: `--stream` walks each document's events one at a time** (#4397). The first cut kept every event of every document before the program ran; a program that reads `.` now takes the next event out of its document as it asks for it (memory proportional to the depth on top of the document), and one that uses `-s` or `input`/`inputs` still keeps them. On a 10.8 MB array of 120,000 records `jq --stream -c .` peaked at 622 MB with the events kept and 310 MB walked one at a time (jq 1.7.1: 2.4 MB, which streams the parse as well); the output is byte-identical to jq's (md5).
