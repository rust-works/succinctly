- **jq: `=` through a negative index that names no element, followed by `.[]`, collects the path before refusing the write** (#7559). `.[-2][]? = 0` on `[1]` (or `null`, `[]`, `[[]]`) raised `Out of bounds negative array index` and exited 5; it is now the input unchanged, as in jq, because the `.[]` over the `null` at that index yields no path. Without the `?`, `.[-2][] = 0` now raises jq's `Cannot iterate over null (null)` instead of the bounds error. `|=`, `+=`, `//=` and `del` already agreed with jq.
