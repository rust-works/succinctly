- **jq: a chain of defs that each call the one below twice no longer takes exponential time before it runs** (#7786).
  `def g0: 1; def g1: g0 + g0; ...; def g60: g59 + g59; reduce empty as $i (0; g60)` and the same chain under `map`,
  `sort_by`, `any`, `.[] |= f`, `with_entries`, `empty as $x | f`, a Fibonacci-shaped chain and a layered module DAG
  (each module's def calling the three modules below) answered only after a walk exponential in the chain's length,
  where jq answers at once: the analyses run before a fold, a `map`, an update or an `as` body walked a called def's
  body again at every call that reached it. `walk::search_subexpr` now walks each shared def body and argument once
  per walk, and the two walks that count occurrences count a shared subtree once and add it at each call, so the
  time is linear in the program's size where it was exponential; output is unchanged.
