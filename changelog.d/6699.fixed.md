- **yq: a space inside a quoted dotted name (`."a b"`) is a lexer error, as in yq** (#6699).
  yq's path-element token takes the opening quote of a dotted name and stops at the first space, so `."a b"` is `."a` followed by
  text no rule takes (`lexer: invalid input text "b\""`); `succinctly yq` read it as the key `a b`, in a read, as a write target and
  under `del()`. It now refuses it wherever the step appears, and reads every other quoted name (a tab, a newline, any
  punctuation) as before. `.""` is the key of two quote characters, as in yq (`.""` reads `null` over a document whose key is `""`,
  `.x."" = 9` creates it). `.["a b"]` still reads a key with a space, and `succinctly jq` is unchanged. Checked against yq v4.53.3
  over 70 runs of 35 programs.
