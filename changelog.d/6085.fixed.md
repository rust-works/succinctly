- **`succinctly jq` finds the match for the `l` flag with `\K`** (#6085). `"a1" | match("a\\K1";"l")` is `[[1,1]]` in jq and was empty, `"a1b" | match("1\\K|b";"l")` is `[[2,0]]` and was `[[2,1]]`: the longest-match search recorded each candidate by the start `\K` had moved, then searched again from there and found nothing, and compared lengths from that start. A pattern with `\K` under `l` is now searched one start at a time with the pattern anchored there (`\G(?:...)`), and a match is measured from the start of its attempt, as Oniguruma's `ONIG_OPTION_FIND_LONGEST` does. Still different: a pattern whose ways to match at one start keep different spans (`"baa" | match("b?\\K[ab]a*";"l")` is `[[1,2]]` in jq, `[[0,3]]` here), and `l` with the extended mode.
