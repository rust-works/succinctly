- **yq: a block scalar whose header follows a tag containing a colon is read as yq reads it** (#7130).
  `- !<tag:yaml.org,2002:str> |2` (and the same under a chain of dashes, and with `>`, a chomping indicator or an anchor after the tag) took the colon inside the tag for a key's and measured the scalar's content two columns too far right, so it read as empty (`["","x"]` where yq reads `[" lead\n","x"]`).
  A key's colon now has to end what stands before the header once its node properties are set aside, as it does for a header on a line of its own (`- k: !<tag:x> |2` is unchanged).
