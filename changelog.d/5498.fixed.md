- **jq: `--stream` under `-n` with `input`/`inputs` gives jq's events, lines, depth and error text** (#5498).
  Reading the events from jq's own streaming parser, rather than from a parsed document, removes four differences on that route: each event carries the line jq had read when it yielded it (`printf '{"a":\n1,\n"b":[2,\n3]}\n' | jq --stream -nc '[inputs|input_line_number]'` is `[2,3,4,4,4]`, not `[4,4,4,4,4]`), a repeated object key is emitted every time (`{"a":1,"a":2}` gives `[["a"],1]`, `[["a"],2]`, `[["a"]]`), a document more than 256 levels deep is read, and a parse error is raised with jq's text and position (`Expected separator between values at line 2, column 7`, not `Invalid JSON text: expected ':', found '2'`).
  6,040 stream-by-program runs over well-formed and malformed streams in one or two files matched `/usr/bin/jq` 1.7.1 on stdout, stderr and exit status, where the previous route matched 2,829.
