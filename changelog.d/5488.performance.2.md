- **jq: a body rebuilt for each value copies the rest of its pipe once, not once per stage** (#5488, second step).
  A copy of a pipe's tail now holds its stages in storage it can share, and each tail of that copy is a view of it (an offset into the same stages) instead of another copy, unless a stage of that tail holds a `def`, whose node remembers what evaluation did to it (#3148).
  A pipe of the program, or one a substitution rebuilt, still owns its stages, so a pipe that is never copied pays nothing for this.
  For one value down a pipe of `n` stages, the copies of its rest drop from `n - 1 + n - 2 + ...` stages to one copy of `n - 1` (two for `floor` stages), in jq and yq mode alike.
  Not yet covered: a rest entered through one of the owned evaluator's doors (a projection, `select`, a path) and a stage that yields several values ahead of the rest are still copied at every stage, as before.
  On an AMD Ryzen 9 7950X (release, min of 7 interleaved wall-clock runs, `[range(0;20000) | . as $x | (<n stages>)] | add`) at n = 10 / 20 / 40 / 80: every stage reading `$x` -19% / -42% / -62% / -78% (4.81 s to 1.07 s at 80, now linear), `[.][0]` stages with the read last -25% / -45% / -60% / -71%, `floor` stages with the read last -9% / -22% / -33% / -42%.
  Those two read-last rows are still superlinear, which the #5488 prototype's profile attributes to a re-entry re-walking the rest of the pipe at each stage (`reentry_can_observe`), the next step of #5488.
  The read-first controls move +1% to +3% (`. + 1` stages) and +1% to +7% (`[.][0]` stages) in wall-clock at instruction counts within +1.4% to -1.1% of the base, which reads as code layout on that machine (not confirmed with a padding holdout); ARM64 was not measured.
  **Breaking for library callers** that edit `Expr::Pipe`'s stages: `PipeStages` now derefs to `[Expr]` rather than `Vec<Expr>`, so `push`, `insert`, `extend` and `retain` go through `make_mut()`, which returns the `Vec` (and forgets what the pipe remembered, as `DerefMut` does), and `as_slice()` is an inherent method.
