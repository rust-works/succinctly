- **yq: a mapping or sequence in a string interpolation is its YAML text, not JSON** (#6092). `"I \(.m)"` over `m: {an: apple}` printed `I {"an":"apple"}`; it now prints `I {an: apple}`, as yq does, and a block mapping interpolates as its block text (`I a: 1` / `b: two` over two lines). Each `\(...)` slot is now a `to_string` stage, so a container reads as `to_string` makes it, and a node written in flow style stays flow for a slot of plain navigation or `//` of it (`"\(.m)"`, `"\(.a // "d")"`). A slot that is a call, `..` or a write's right-hand side is read from an owned copy and prints a flow container as block (`.x = "got \(.m)"` writes `got an: apple`; yq `got {an: apple}`). jq mode keeps `tostring`'s JSON text, as jq does.
