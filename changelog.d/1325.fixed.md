- **yq: a comma-grouped `del()` stops at a bare slice of the root, as yq's delete does** (#1325). `del(.a[0:1], .[2:3])` over `{"a":{"x":1,"y":2},"b":6,"c":9}` deleted `.a`; yq deletes nothing. yq walks the matches from the last to the first and returns at the first one without a parent, and a slice of the root has none, so the branches written before the bare slice are never deleted (`del(.[2:3], .a[0:1])` still deletes `.a`, `del(.b, .[2:3])` deletes nothing, `del(.a[0:1], .[2:3], .b)` deletes only `.b`). Nested groups, `?`, parentheses, a run (`.[2:3][0:1]`) and a pipe of slices all count; a tail after the run (`.[2:3][0]`) does not. 43 rows over an object and an array root match yq v4.53.3 byte for byte (the 4 that raise differ in wording only). A group whose earlier branch could create nodes while it resolves (an index past the end of an array, an index or `.[]` on `null`) keeps its earlier behaviour.
