- **jq: a `--stream` walk stops one event past a file that did not open, as jq does** (#6006). jq's main loop reads no further input once its reader has moved past a missing file, after processing the input that took it there, so `jq -c --stream . missing a.json` over `[3]` prints `[[0],3]` and exits 2; succinctly printed every event of the files after it. `--stream -s` over only files that do not open is `[]` and exit 2, where it panicked. `-R` and `--stream-errors` still read on (`docs/compliance/jq/limitations.md`).
