- **yq: `load("f.yaml")` keeps the presentation of the file it loads** (#5439). `yq -n 'load("l.yaml")'` printed the loaded document without its comments, `&anchor`s, `!tag`s, quote style or flow style (`a: 1` for `a: &x !Foo 1 # c`), where yq prints the file as it is. `load`, `. * load(..)`, `. + load(..)`, `. *= load(..)`, `. += load(..)`, `.a.b = load(..)` and navigation after it now take the file's comments and styles from a replay of the operation over its comment tree, with a file input and under `-n`; the evaluator's result is still what is printed and the replay is used only when its value is the evaluator's.
