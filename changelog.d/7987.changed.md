- **`succinctly jq` reads the edges of its input through a model of jq 1.7.1's reader on the route a program that reads `input`, `inputs` or `input_line_number` takes over input read whole** (#7987). The semi-index still reads the input, and the model (ADR-0033, step 5) is entered only on a trigger: a byte-order mark that is not whole, several files not all UTF-8, or a fault (or the first substituted byte of a lone file that is not UTF-8), from the last sync point before it. A file seam is not a trigger. On that route a mark that breaks off (`printf '\xef1\n' | jq -n input`) is now `Malformed BOM`, as jq 1.7.1 and 1.8.2 word it, where the first read used to say `Invalid numeric literal` (#5804; the default route, `--slurp` and a pipe longer than 256 KiB keep the old wording until their own steps), and every position after a fault is jq 1.7.1's (`}`, a newline, `}` gives the second fault at line 1, column 2, as jq does). Over a 4,000-case differential of edge inputs and eight programs, the 8,092 answers that changed moved to what both releases print (6,986, 6,770 of them the mark's wording) or to jq 1.7.1 where the releases differ (490); the rest differ from both only after the first fault or at a NUL, which ADR-0018's #7963 amendment (E1, E2) leaves best effort, and `.`, `-s`, `-n -s`, `--seq`, `--stream` and `-R` changed on none. `SUCCINCTLY_READER_MODEL=0` selects the old reader.
