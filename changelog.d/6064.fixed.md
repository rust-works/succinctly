- **jq: `range(.; .+10)` over an integer past 2^53 emits the start unrounded** (#6064). `9007199254740993 | [limit(1;range(.;.+10))]` printed `[9007199254740992]` where jq 1.7.1 prints `[9007199254740993]`, and so did `-9007199254740993 | range(.;.+1)` and `range(.;infinite)` over `9223372036854775806`: when the upper bound is a float the range runs on doubles, and its first value started from the rounded double instead of the start's own literal. An exact-integer bound already kept it.
