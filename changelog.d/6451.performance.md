- **jq: `-n 'input'` and `first(inputs)` on one large file or stdin start on the front of it** (#6451).
  The lazy route used to read the whole source and check that it is UTF-8 before the first document;
  it now reads the first 256 KiB, starts the program on the documents there, and reads the rest when
  the program asks for more. On a 95 MB NDJSON file `-n 'input|.id'` takes 2.9 ms instead of
  12.3 ms (jq 1.7.1: 2.3 ms) and peaks at 6 MB instead of 101 MB (170 MB from stdin), on an Apple M5.
  A program that reads every document takes as long as before, and a source that turns out not to be
  UTF-8, or malformed, past the front reads as it did.
